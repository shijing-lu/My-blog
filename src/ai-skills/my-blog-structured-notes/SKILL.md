### 0.2 术语约定（全篇统一）

| 术语 | 含义 |
| --- | --- |
| 层级 | 语法出现的位置，三档：**行内** / **段落级** / **引用块级** |

| 黑幕 | `:spoiler[内容]` 行内隐藏语法：默认完整显示，文章页「黑幕」开关开启后才遮罩（悬停 / 点击揭示），见 3.6 |

### 0.3 模板锁定政策

> ⚠️ **本 skill 的核心是「逐字段复刻骨架」**。用户已明确认可某一版模板，之后生成的例题笔记必须与其**结构、字段、排版一致**，风格统一。
> 例题模板锁定不变；**转换模式**（普通 MD → 复习型笔记）在第 7 节：骨架原样保留，只追加「自测卡 + 复习索引」两个区段；**知识手册模式**（纯知识点笔记）在第 8 节：独立骨架，共用同一语法体系；**强化讲义模式**（知识点 + 例题 + 题型总结混合）在第 9 节：原子单位是例题，题干可见、解析折叠。设计依据见第 12 节附录。

## 2. 字段规则

### 2.1 字段表（每个字段在哪、怎么填）

| 字段 | 位置与写法 | 规则 |
| --- | --- | --- |
| 本篇说明 | `> [!info]【本篇说明】` + 一段正文 | 先列考点清单，再写「每题标题栏含完整题干，解析折叠于卡片内，拓展知识独立于卡片外，默认可折叠查看」 |
| 分隔线 | 每题之间、小结之前各一条 `---` | 独占一行，前后留空行 |
| 题号标题 | `## 【3.X】<题型名>` | 正文从 `##` 起（不写 `# H1`）；题型名用中文概括，公式写在里面也可以（`## 【3.3】$AB$ 型方程组的解判定`） |
| 题目卡 | `> [!tip]- 【题目】…` | **固定 `tip` 类型 + `-`（默认收起）**；标题必须含**完整题干 + 全部选项** |
| 选项分行 | 选项之间 `<br />` | **必须自闭合**；写法 `A. $x_2, x_3$　<br />B. …`（保留全角空格 `　` 做视觉分隔） |
| 解析 | `> **【解析】**` | 加粗方头括号行，不是标题 |
| 关键点 | `> ==…=={.tip}` | 紧跟解析，固定 `.tip` 变体 |
| 思路分解 | `> **【思路分解】**` + `> **① …**` 步骤 | 步骤用加粗序号 `**①**`/`**②**`/`**③**`；**步数按内容需要 3~5 步**，不必凑数 |
| 拓展知识 | `**【拓展知识】**`（**卡片外**，段落层级）+ `:::collapse` | 一个知识点一个面板；**1~3 个面板**，按需 |
| 勘误面板 | 放在该题 `:::collapse` 里 | **按需出现**：仅当原始笔记确有错误时才加，没错就不加 |
| 小结 | `> [!summary]【小结】` + 一段正文 | 概括各题考点与主线 |
| 小结选项卡 | 段落级 `:::tabs#summary`，三个 `@tab` | 固定顺序：`@tab:active 知识点映射 #km`（无序列表）/ `@tab 通用流程 #gc`（有序列表）/ `@tab 必记结论 #jl`（无序列表） |
| 易错提醒 | `> [!tip]【最容易失分的地方】` + 无序列表 | 每条以 `【3.X】` 开头，对应题号 |
| 自测卡 | `> [!question]- 自测：…`（卡片**外**，与拓展知识同级） | 仅转换模式：每单元 1~2 张，按需；**问题写进标题行**（折叠时可见），卡内 `**【答案】**` 一句话 + 指回题号；只出"能检索"的问题（结论回溯 / 条件辨析 / 反例判断），不出"复述原文"题 |
| 复习索引 | `> [!info]【复习索引】`（全篇最后、易错提醒之后） | 仅转换模式：每单元一条钩子问题 + 指回题号 + 间隔建议（当天 / 3 天 / 7 天 / 考前）；不写公式推导，只做"不读正文也能跑一轮"的重入点 |

### 2.2 排版硬约束

8. **知识块 callout 一律"可折叠、默认展开"**（用户偏好，2026-09-30）：讲义 / 精讲课 / 学习类笔记的每个知识块 callout 都写成 `> [!type]+`——想复习哪块就收起哪块，默认全展开不打断阅读。`-`（默认收起）只用于答案卡 / 想默认藏起来的内容。

1. **`<br />` 必须自闭合**——写成 `<br>` 会报 `Expected a closing tag for <br>`，整篇渲染失败。
2. **标题不能在源文件里换行**：标题 = 引用块**首段第一行**，源码换行会让后续内容掉进折叠正文。需要分行只能用 `<br />`。
3. **`:::collapse` 闭合围栏必须独占一行**（不要写成「…正文。 :::」）。
4. **公式一律用 `$…$` / `$$…$$` 包裹**，块级公式 `$$` 独占一行。裸 `\begin{…}` 是本项目最高频故障（见第 5 节排错）。
5. **公式记号照模板**：`(A|b)`、`\{1,2\}`、`\min\{r(A), r(B)\}`（`|` 与 `\{` 在 `$…$` 内都能正常渲染）。
6. 列表项正文缩进 **2 空格**；`:::collapse` 内嵌 `$$` 同样缩进 2 空格。
7. 卡片内可放 `$$` 块级公式、`-` 列表、表格；**不能放 `:::tabs`**（引用块内不解析，见第 4 节）。

### 3.1 Admonition（提示块）

**用途**：不折叠的整段提示，带默认标题。
**层级**：段落级。
**写法**：

```markdown
:::note
正文
:::
```

**取值**（5 种类型，默认标题固定）：

| 类型 | 默认标题 | 语义 |
| --- | --- | --- |
| `note` | 备注 | 中性说明 |
| `info` | 信息 | 补充信息 |
| `tip` | 提示 | 技巧、建议 |
| `warning` | 注意 | 注意事项 |
| `danger` | 危险 | 禁令 |

**约束**：
1. **不支持同行标题**：`:::warning 注意安全` 整行降级为普通段落。
2. **不支持同行闭合**：开 / 闭标记各自独占一行。
3. 不要内联写 `<Callout type="warning">` JSX——报 `Expected a closing tag`，整篇失败。

**模板映射**：骨架未使用，按需补充（如全篇适用的一句话提醒）。

### 3.2 Obsidian Callout ⭐ 主力

**用途**：一切「标题常显、内容可折叠」的卡片——题卡、知识卡、自测卡、小结、易错提醒。
**层级**：引用块级（每行以 `> ` 开头）。
**写法**：

```markdown
> [!tip]- 标题（默认收起）
> 内容
```

**取值 A —— 折叠标记**（紧跟类型名，中间无空格）：

| 标记 | 行为 |
| --- | --- |
| （无） | 不可折叠，永远展开 |
| `-` | **可折叠，默认收起**（题卡 / 自测卡用它） |
| `+` | **可折叠，默认展开**（渲染器实证：foldable=true 且无 collapsed；2026-09-30 用户偏好：精讲/讲义类知识块一律用它，见 §2.2 第 8 条） |
| `+` | 可折叠，默认展开 |

**取值 B —— 类型**（11 种规范类型 + 归一别名）：

| 规范类型 | 归一别名（写别名按右列处理） |
| --- | --- |
| `note` `info` `tip` `success` `question` `warning` `failure` `danger` `bug` `example` `quote` | `hint`→tip；`caution`→warning；`error`→danger；`summary`/`tldr`→info；`faq`/`help`→question；`check`/`done`→success |

**约束**：
1. `[!type]` 与 `-` / `+` 之间**不能有空格**；`[! tip]`（`[!` 后带空格）**完全不识别**，原样显示成文本。
2. 折叠时**仅标题行可见** → 完整题干与全部选项必须写进标题行。
3. 标题支持加粗、行内代码、**行内公式**（含 `\begin{bmatrix}`）、`<br />`；但**不能放块级 `$$`**。
4. 标题源码换行规则见 2.2 硬约束 2。

**模板映射**：题卡 `> [!tip]-`；知识卡 / 自测卡 `> [!question]-`（仅转换模式）；本篇说明 / 复习索引 `> [!info]`；小结 `> [!summary]`；易错提醒 `> [!tip]`（展开）。

### 3.3 Collapse（折叠面板）

**用途**：卡片外的多面板折叠知识区（拓展知识）。
**层级**：段落级容器。
**写法**：

```markdown
:::collapse
- 面板标题

  面板正文（缩进 2 空格）

- 面板标题

  面板正文
:::
```

**取值**（容器参数 + 单项覆盖）：

| 参数 | 行为 |
| --- | --- |
| （省略） | 非手风琴：多面板可同时展开（**默认用这个**） |
| `accordion` | 手风琴：同组互斥，只能开一个 |
| `expand` | 全部默认展开 |
| `- :+ 标题` | 单项强制展开（优先级高于组参数） |
| `- :- 标题` | 单项强制收起 |

**约束**：
1. 容器内必须**恰好一个顶层无序列表**（`-`）；**有序列表 `1.` 不被识别**。
2. 面板标题 = 列表项首行；标题后**空一行**再写正文；正文缩进 2 空格。
3. 闭合围栏 `:::` 独占一行（见 2.2 硬约束 3）。
4. **写进 callout（`> :::collapse`）时必须省略全部参数与 `:+` / `:-`**——违规症状见 5.2 类别②。
5. 模板政策：一律写在**卡片外**（段落层级），参数可用但默认不用。

**模板映射**：拓展知识面板（1~3 个，一个知识点一个）；勘误面板也放这里。

### 3.4 Tabs（选项卡组）

**用途**：同层多视角切换（小结三分区：知识点映射 / 通用流程 / 必记结论）。
**层级**：段落级容器。
**写法**：

```markdown
:::tabs#summary

@tab:active 知识点映射 #km

内容

@tab 通用流程 #gc

内容

:::
```

**取值**（四个构件）：

| 构件 | 写法 | 行为 |
| --- | --- | --- |
| 稳定标识 | `:::tabs#id`（`#` 紧跟 `tabs`） | 同标识的组选中状态互相同步 |
| 初始激活页 | `@tab:active 标签 #锚点` | 同组只认第一个 |
| 普通页 | `@tab 标签 #锚点` | — |
| 锚点 | 行尾 `#km`，不显示在按钮上 | 跨组对齐；不能写成 `#k m` |

**约束**：
1. **`:::tabs#id` 必须独占一行**：写成 `:::tabs#summary @tab` 会让开标记正则失配 → **整块降级，`:::` 与 `@tab` 全部裸泄漏**。
2. **不能写在 callout 内部**——引用块 `> ` 前缀会让它整体失效。
3. **少于 2 个 `@tab` 或不闭合 → 降级为普通 Markdown**。
4. 嵌进 `:::collapse` / `:::note` 时，**外层必须写成 4 个冒号**（`::::collapse`），否则页面多出一行 `:::`。
5. 标签支持行内 Markdown。

**模板映射**：仅小结一处（`:::tabs#summary`，三页固定顺序见 2.1）。

### 3.5 Mark（荧光高亮）

**用途**：行内跳出重点——关键结论 / 判定依据 / 红线易错。
**层级**：行内。
**写法**：

```markdown
==重点内容==          默认主色（primary）
==提示内容=={.tip}    后缀式（模板统一用，位置随意）
==tip:提示内容==      前缀式（仅段首可靠，避免使用）
```

**取值**（5 种变体 + 归一别名）：

| 变体 | 归一别名 | 本模板语义 |
| --- | --- | --- |
| `primary` | main / default | 默认主色 |
| `secondary` | sub | 次级重点 |
| `tertiary` | third | 三级重点 |
| `error` | danger / warning / warn / caution | 红线易错（易错清单用） |
| `tip` | success / info / note / hint | 关键结论（关键点用） |

**约束**：
1. **模板统一后缀式** `==…=={.tip}`。
2. 前缀式只在文本节点开头生效，句中会失效并原样泄漏。
   ⚠️ **还有一种「参数前置」的错写：`=={.tip} 正文==`**（把 `{.tip}` 写在**开标记**后面）——**它不是本项目支持的语法**，既非后缀式也非前缀简写。渲染器会吞掉 `{.tip}` 并把整段当成默认主色，语义变体丢失；若该行漏写闭 `==`，还会连带把后续内容污染。
   **正确写法只有两种**：`==正文=={.tip}`（推荐）或 `==tip:正文==`（仅段首可靠）。
   2026-09-14 实测：一次 21 题的量产稿中误用此形 27 处，需专门写脚本回改——**务必一次写对**。
   排查：`grep -n '^> *=={\.' file.md`，命中即为参数前置。
3. 不支持嵌套；想显示字面 `==` 写 `\=\=`。
4. 高亮正文含 `=`（含公式）已支持（`encodeMarkSyntax` 2026-09-10 修复）；生产环境未部署修复时会在 5.5 报 acorn 错。
5. 高亮只做**导航信号**，不替代自测结构（第 12 节原则 4）。
6. ==**必须同行闭合**==：`==` 开标记与闭标记**必须在同一源码行**。跨行写（开 `==` 在行首、闭 `==` 在数行之后）**不报错、不警告，但整段高亮静默失效**——是最隐蔽的失效点，且**同一行内多个 `==` 对时行数仍为偶数，无法靠 grep 报错发现**。
   排查方法：**逐行统计该行 `==` 的出现次数，奇数即为跨行**；发现后把闭 `==` 提前到开标记所在行，其后的正文另起一段（段间仍需空引用行 `>`）。
   典型误写（`:::collapse` / 工具箱 / 方法卡的说明段最常见——因为这类段落天然想分点排版）：

   ```markdown
   > =={.error} 三个高频陷阱：
   > ① ……；
   > ② ……。==
   ```

   正确写法：

   ```markdown
   > =={.error} 三个高频陷阱：==
   >
   > ① ……；
   >
   > ② ……。
   ```

**模板映射**：解析关键点 `==…=={.tip}`；易错清单条目 `==…=={.error}`。

### 3.6 行内指令：`:note[]` 行内标注 与 `:spoiler[]` 黑幕

**用途**：`:note[]` = 随文小备注；`:spoiler[]` = 答案 / 剧透「先猜后看」遮罩（2026-09-15 实装）。
**层级**：行内（两者同为 remark-directive 行内指令）。
**写法**：

```markdown
:note[行内备注]

最终的答案是 :spoiler[42]。
黑幕内部支持 :spoiler[`行内代码` 与 **加强调**]。
```

**约束（`:note[]`）**：
1. 单个冒号 + 方括号；与 3.1 的 `:::` 双冒号不同。
2. 已验证形式为 `:note[…]`；其余行内指令名未验证，使用前先过第 10 节自检。

**约束（`:spoiler[]`）**：
1. **label 内支持完整行内 Markdown**（行内代码 / 加粗 / 高亮均可）。
2. **默认整篇完整显示**——含该语法的文章页右上角会渲染「黑幕」开关，开启后才遮罩：悬停 / 键盘聚焦 / 点击揭示，再点收回；开关状态存 localStorage 跨页保持；不含该语法的文章不出现开关。
3. `[...]` 必须与 `:spoiler` 同行闭合；避免在内容里写未配对的 `]`（嵌套方括号行为未验证）。
4. 裸 `:spoiler`（后面没紧跟 `[...]`）不渲染黑幕、也不报错——按普通文本处理；代码围栏内的写法是纯示例不解析（与所有语法一致）。
5. **模板锁定政策：骨架默认不用**。适用场景：知识手册的默写自查（面板里逐条答案遮罩）、转换模式「先猜后看」的补充答案、影评 / 题解的剧透遮罩。它与折叠卡（3.2/3.3）的分工：折叠是**块级整段收起**、黑幕是**行内小块遮罩**——正文行文不被打断时用黑幕。

### 3.7 数学公式

**用途**：行内与块级公式（KaTeX）。
**层级**：行内（`$…$`）与块级（`$$` 独占行）。
**写法**：

```markdown
行内：$|A| \ne 0$

块级（开 / 闭各独占一行）：
$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}
$$
```

**约束**：
1. 公式可放在段落、列表、引用块、表格、折叠面板内。
2. 表格单元格内 `$…$` 由 `rehypeTableMath` 二次渲染；公式里的 `|` 自动转 `\vert`。
3. **引用块内块级公式**：`$$` 独占一行且带 `> ` 前缀；**公式行不要以 `|` 开头**（见 5.3 类别③）。
4. 裸 `\begin{…}`（漏 `$` 定界符）是本项目最高频故障 → 整篇 500，见 5.1 类别①。
5. 显示字面美元符号写 `\$`。

### 3.8 表格 / 代码块 / 图片 / 分隔线

| 语法 | 规则 |
| --- | --- |
| GFM 表格 | 直接写；**表头行必须填真实列名**（空表头会让列名掉到第一行数据）；单元格内 `$…$` 可用 |
| 代码块 | 自带行号与复制按钮，不必手动写行号；展示语法示例一律放代码围栏（围栏内不解析） |
| 图片 | `![说明](url)` → 灯箱；**正文内不显示说明文字**（只在灯箱里显示，兼做无障碍文本），仍应写有意义的描述 |
| 分隔线 | `---` 独占一行、前后留空行；模板用途 = 题与题之间、小结之前各一条 |

## 4. 组合规则：容器嵌套

### 4.1 围栏长度铁律

**`:::` 容器互相嵌套时，外层必须比内层更长**——外层 `::::`（4 个冒号），内层 `:::`。
两层都用 3 个冒号时，第一个 `:::` 被外层吃掉，内层照样渲染，但**外层的闭合行会残留成页面上一行 `:::`**（无声、不报错，最难发现）。

### 4.2 兼容矩阵（全部实测）

| 外层 ＼ 内层 | `:::tabs` | `:::collapse` | callout | 高亮 |
| --- | :---: | :---: | :---: | :---: |
| callout `> [!x]` | ❌ 完全失效 | ✅（省略参数与标记） | ✅ | ✅ |
| `::::collapse`（4 冒号） | ✅ | ✅ | ✅ | ✅ |
| `:::collapse`（3 冒号） | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ | ✅ |
| `::::note`（4 冒号） | ✅ | ✅ | ✅ | ✅ |
| `:::note`（3 冒号） | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ | ✅ |
| 段落层级 | ✅ | ✅ | ✅ | ✅ |

### 4.3 记忆法

**要往容器里塞选项卡，就把外层写成 4 个冒号；callout 里塞不了选项卡。**

## 5. 排错手册

### 5.0 症状分流

| 页面症状 | 去哪查 |
| --- | --- |
| 整篇 500 / `Could not parse expression with acorn` / `ReferenceError` | 5.1 类别① |
| 页面出现裸 `:::` / `@tab` / `[!x]` / `==` | 5.2 类别② |
| 公式不渲染 / `katex-error` / `No such environment: \{` | 5.3 类别③ |
| 内容错位、面板消失、表头异常（**不报错**） | 5.4 类别④ |

⚠️ **已知实现缺口**：`encodeMarkSyntax` 的 JSDoc 承诺「非代码区域剩余 `{` `}` 用哨兵兜底保护」，但实际代码没有这一步——正文里任何裸花括号都会崩，没有自动兜底。

### 5.1 类别①：整篇渲染失败

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| **`ReferenceError: bmatrix / cases is not defined`** | **块级公式漏写 `$$` 定界符**——`A = \begin{bmatrix} … \end{bmatrix}` 裸写，`{bmatrix}` 被当 JS 标识符求值 | 补 `$$` 独占行 / 行内补 `$…$`。**这是该报错的唯一常见原因** |
| 正文裸 `{花括号}` | 与上同源（实现缺口，见本章导语） | 转义 `\{` `\}`；示例放代码围栏 |
| **`Expected a closing tag for <br>`** | 标题内换行写了 `<br>`（未自闭合） | 改 `<br />` |
| HTML 注释 `<!-- -->` | `Unexpected character !` | 改 `{/* */}` |
| 带 `style` 的内联 HTML | React style prop 报错 | 正文不写内联 HTML（`<br />` 除外） |

### 5.2 类别②：语法泄漏（标记原样可见）

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| **页面多出一行 `:::`（容器渲染了）** | **`:::` 闭合行与正文写成同一行** | 闭合围栏独占一行 |
| **页面多出一行 `:::`（容器没渲染）** | 外层容器只有 3 个冒号却内嵌 `:::` 容器 | 外层改 4 个冒号（第 4 节） |
| `:::tabs#summary @tab` 之后整块泄漏 | 开标记未独占一行 | `:::tabs#id` 独占一行 |
| `> :::collapse expand` 整块泄漏 | callout 内不能带参数 | 省略参数 |
| callout 内出现空 `<div></div>` | `> - :+ 标题` 的 `:` 被当 textDirective | callout 内不用 `:+` / `:-` |
| `[! tip]` 原样显示 | `[!` 后有空格 | 写 `> [!tip]` |
| `:::warning 注意安全` 整行泄漏 | admonition 不支持同行标题 | 开 / 闭标记都独占一行 |
| `==tip:文本==` 在句中泄漏 | 前缀式只在文本节点开头生效 | 改后缀式 |
| **`==…==` 高亮完全不生效、正文原样显示**（**不报错**） | **开 / 闭 `==` 跨行**（见 3.5 约束 6）——`:::collapse` 面板、工具箱、方法卡的**分点说明段**最高发 | 闭 `==` 提前到开标记同行；后续内容另起段（段间加空引用行 `>`）。**排查：逐行数 `==` 出现次数，奇数即跨行** |
| `:spoiler[内容]` 原样显示、没有黑幕按钮 | 裸 `:spoiler` 没紧跟 `[...]`；或写进了代码围栏（示例不解析）；或查看场景是轻量预览管线（日记悬浮预览等不加载该语法） | 检查 `[...]` 成对且紧跟指令名；预览以正式文章页为准 |

### 5.3 类别③：公式与数学

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| **`No such environment: \{` / 公式内 `{` `}` 显示异常** | **公式行以 `|` 开头**（如 `\|B\|=\begin{vmatrix}...`），被误判为 GFM 表格行，`tableLineToSafe` 把 `{` `}` 转义成 `\{` `\}`（2026-09-10 实测；行中 `|`、`\det(...)` 开头、`bmatrix` 均正常） | 公式行不以 `|` 起行：改成 `B=` 或 `\det(...)` 开头，或行首加文字 |
| 公式处显示残缺、出现奇怪数字（**不报错**） | 漏 `$` 但花括号内是合法 JS（`\frac{1}{2}` 的 `{1}` `{2}` 求值成数字） | 补 `$…$` / `$$…$$`——**能跑通 ≠ 公式正确** |
| 引用块内 `$$` 块级公式吞后续正文 | `normalizeMathFences` 曾丢 `>` 前缀（**已修复**） | `$$` 独占一行；生产环境未部署修复时仍会复发 |

### 5.4 类别④：静默错乱（不报错，结果不对）

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 表格表头是空的 | 表头行写成了空行 | 填真实列名 |
| 折叠面板静默消失 | 列表项续行缩进被剥 → "恰好一个列表"校验失败 | 面板正文缩进 2 空格 |
| 标题里分行的内容被折叠起来 | 标题源码里换行 → 后续行被判为正文 | 标题内换行用 `<br />` |

✅ **标题内的行内高亮可用**：`## 关于 ==重点== 的说明` 正常渲染。但标题内仍建议只用纯文本 + 行内代码。

### 5.5 两大典型报错的定位流程

**错误 A：`Could not parse expression with acorn`**
首查裸花括号（5.1 类别① / 本章导语的实现缺口）。报错行的**列号**是 acorn 位置，真实原因常在同一行或**前一两行**。排查顺序：
1. 该行是否有裸 `{` / `}`（含 `{#id}`、`{2a}`）→ 改 `\{` `\}`，或确认在 `$…$` 内
2. 是否有 `==...=={.variant}` 且正文含 `=` → 确认 `encodeMarkSyntax` 已修
3. 是否有 `$$` 与正文同行且位于引用块内 → `$$` 独占一行
4. 是否有 `:::tabs` 写在 callout 内 → 移到段落层级

**错误 B：`ReferenceError: bmatrix / cases is not defined`**
这是「花括号被当 JS 表达式求值」的信号，不是 JS 变量问题。栈里出现 `_createMdxContent` + `renderMdx` 即可确认。两种诱因：
1. **公式漏写 `$` 定界符**（首要）→ 给每处 `\begin{…}` 补 `$…$` / `$$…$$`
2. `$$` 块级公式写在引用块内且拆行时丢了 `> ` 前缀 → 确保 `$$` 独占一行且带 `> ` 前缀

**生产环境（Vercel）仍报已修复的错** → 修复未部署，push 后等分钟级传播。

## 6. 写作流程（七步）

1. **读原始材料**：按"题"切块，标出每题核心考点与题型名（题型名用于 `## 【3.X】<题型名>`）。
2. **抄骨架**：先把第 1 节骨架整段复制，再逐题替换占位内容。**不要边写边想结构**。
3. **填题目卡**：完整题干 + 全部选项写进 `> [!tip]-` 标题行；选择题每个选项用 `<br />` 分行。
4. **写解析**：`**【解析】**` → `==关键点=={.tip}` → `**【思路分解】**` → `**①…**` 步骤（3~5 步，每步具体到"下一步做什么"）。
5. **写拓展知识**：卡片**外**用 `**【拓展知识】**` + `:::collapse`，一个知识点一个面板（1~3 个）。
6. **写小结**：`> [!summary]【小结】` + 段落级 `:::tabs#summary` 三个 tab + `> [!tip]【最容易失分的地方】`。
7. **渲染自检**（第 10 节），全绿才算完成。

### 需要"勘误"时

原始笔记若有明确错误：在**该题的 `:::collapse`** 里加一个面板，标题写 `原笔记勘误` 或 `原笔记批注勘误`，正文说清「原笔记写的是什么 / 错在哪 / 正确是什么」。
**按需出现**——原始笔记没错就不加，不要为了凑格式而加。

## 7. 转换模式：普通 MD → 高效复习笔记

触发：用户给出普通 MD 文档 / 讲义 / 笔记草稿，要求「转成笔记 / 美化 / 提高复习效率」。

在**第 1 节骨架**基础上追加两个区段（骨架其余不变，保持模板锁定）。

### 7.1 转换八步

1. **切块**：把原文切成「可出题」的最小单元（结论 / 方法 / 易错点 / 反例），标出单元名（用于 `## 【X.Y】<单元名>`）。
2. **主卡化**：有题的走题目卡（`> [!tip]-`）；纯知识单元转**知识卡**——`> [!question]- <单元名>：<核心问题>？`，卡内 `**【要点】**` + 原文要点重排（标题行必须能当问题用，折叠时可见）。
3. **补自测卡**：每单元 1~2 张 `> [!question]- 自测：…` 放卡外，与拓展知识同级；优先出**条件辨析 / 反例判断**型（这正是交错辨析的载体）。
4. **提炼拓展**：跨单元的通用结论、对比、易错点 → `:::collapse` 面板或 `:::tabs` 对照（注意第 4 节嵌套规则）。
5. **写小结**：summary 正文用一句话外行化主线；三 tabs 不变，「知识点映射」的考点列写成辨析短语。
6. **复习索引**：全篇最后加 `> [!info]【复习索引】`——每单元一条钩子问题 + 指回题号 + 间隔建议（当天合上笔记自测 → 3 天 → 7 天 → 考前，只扫索引与小结）。
7. **易错清单**：`> [!tip]【最容易失分的地方】`，每条配 `==…=={.error}` 高亮保证可扫读。
8. **渲染自检**（第 10 节），全绿交付。

### 7.2 追加区段骨架（替换 `<>` 占位）

```markdown
（每题/每单元之后，与拓展知识同级；数量按需 1~2 张）

> [!question]- 自测：<能检索的问题>？
>
> **【答案】** <一句话答案>（指回：【3.X】）

（全篇最后，易错提醒之后）

> [!info]【复习索引】
>
> - <钩子问题一>？（【3.1】）
> - <钩子问题二>？（【3.2】）
>
> 复习路径：先只看本索引口头作答 → 展开对应题卡核对 → 答错的顺带扫正文 ==红== 高亮。间隔：当天 / 3 天 / 7 天 / 考前。
```

### 7.3 约束

⚠️ 自测卡是折叠 callout，**计入 callout 与 callout-foldable 计数**；问题必须在标题行（折叠时可见），答案与指回进卡内。
⚠️ 复习索引里**只放钩子问题与指回**，不写公式推导——它是复习入口，不是第二份讲义。
⚠️ 钩子问题合格标准：合上正文能口头作答（检索），而不是"3.1 讲了什么"这类复述题。

## 8. 知识手册模式：纯知识点笔记

**适用**：输入几乎全是定义 / 定理 / 公式 / 结论 / 注记，没有（或极少）例题；诉求 = 平时**查得快**（手册）+ 考前**背得牢**（复习）。典型：高数、线代、概率的知识点讲义。
**与例题模板的关系**：共用第 3 节语法、第 4 节组合规则、第 5 节排错与第 10 节自检；骨架不同——没有题目卡，最小单元是**知识块**。

### 8.1 四层结构

1. **章层**：`## 【F1】<章名>`（编号 = 科目缩写 + 章号，全篇稳定，供引用）。章首放**知识地图**表（编号｜类型｜名称），一眼看到本章全部知识块。
2. **块层（最小单元）**：一个知识块 = 一个类型徽章 callout，**一块只讲一件事**：

| 知识类型 | 徽章写法 | 默认状态 |
| --- | --- | --- |
| 定义 | `> [!note] 定义 F1-01｜<名词化标题>` | 展开 |
| 定理 / 性质 | `> [!tip] 定理 F1-05｜<名词化标题>` | 展开 |
| 常用结论 / 运算律 | `> [!tip] 结论 F1-07｜<名词化标题>` | 展开 |
| 易错注 / 辨析 | `> [!warning] 注 F1-08｜<错在哪>` | 展开 |
| 口诀 | `> [!quote] 口诀｜<主题>` | 展开 |
| 方法 / 步骤 | `> [!example] 方法 F1-09｜<步骤名>` | 展开 |

3. **索引层（三索引，全篇末尾）**：① **公式速查表**——段落级表格，按主题列公式 + 知识编号；② **必背清单**（`> [!info]`）——口诀、高频结论、易错点集中区；③ **复习索引**（`> [!info]`）——每章 2~3 条钩子问题 + 指回知识编号。
4. **导航标题层（TOC 跳转的关键）**：知识块是 callout（blockquote），**不会出现在文章目录里**。因此必须在每组知识块之上加 `### <组名>` 分组标题——组名 = 检索词（如「定义与单侧导数」），不写叙事句；「考试要求与知识地图」、每个索引、自测卡区、整理说明也各配一个 `###` 标题。目标：文章目录提供「章 h2 → 组 h3」两级跳转，任何知识块从目录起 2 次点击可达。

### 8.2 公式大组的处理

同主题连续公式（如三角恒等式族）**不逐条开 callout**：
- **分组展示**：段落级 `:::tabs#<科目>-<主题>` 按公式族分页（如两角和差 / 二倍角 / 积化和差 / 和差化积），tab 标签 = 检索词；
- **默写自查**：或用 `:::collapse`（面板标题写"先默写再展开"）——主动回忆；
- **对照型知识**（定义域值域、无穷小比阶）直接 GFM 表格；
- 块内 `$$` 独占一行；**公式行不要以 `|` 开头**（见 5.3 类别③）。

### 8.3 检索与关联

- **知识编号**：`<科目缩写>-<章号>-<序号>`（如 F1-03、F2-01）；编号一经使用不再变更；
- **粒度（单节成文）**：输入若只是「某章下的一节」（如高数第二章第一节），把该节当作一个独立章单元处理——`## 【G8】<节名>`，编号 = 科目缩写 + 节序（如 GS8 = 高数第 8 节）；**默认独立成篇**：不做「承接 / 同族」声明、不写跨文件参见、不与已有笔记互链，除非用户明确要求关联（2026-09-11 用户反馈：两份笔记不连在一起）；
- **交叉引用**：相关块末尾加一行 `> 参见：F1-05、F2-01`——替代双链笔记的 `[[链接]]`；
- **标题名词化**：块名用检索词（"奇偶性"），不写叙事句（"关于奇偶性的讨论"）；
- **术语统一**：同一概念全篇同名，别名首次出现时括注。

### 8.4 复习通道

- 每个大公式组 / 结论组配 1 张自测卡：`> [!question]- 自测：默写…？`，答案（该组公式）放卡内，块级 `$$` 每行带 `> ` 前缀；
- 必背清单内的易错点用 `==…=={.error}` 保证扫读可见；
- 复习路径：钩子问题口头作答 → 展开对应知识块核对 → 错的扫红高亮（第 12 节原则 2 / 3）。

### 8.5 目录增强模式（论文式编号 + 可折叠知识块，用户偏好）

适用：用户要求「目录更多、方便定位知识点」的知识手册。在 §8.1 基础上做三处调整：

1. **论文式编号标题**：章层 `## 1 <章名>`，组层 `### 1.1 <组名>`、`### 1.2 …`（不写 `## 【F1】` / `### 组名`）。组要**拆细**——每个可检索主题（一个定义组、一条定理、一张总表、每个索引）各占一个 `###`，让目录条目覆盖到所有主要知识点；`【F1】` 章号仍可保留在知识编号体系（F1-XX）中，只是不进标题。
2. **知识块默认可折叠但默认展开**：知识块 callout 用 `+`（`> [!note]+ 定义 F1-01｜…`）——点击标题行可收起/展开，初始展开不打断阅读。自测卡仍用 `-`（默认收起）。
3. **大表格可折叠**：知识地图表、逐步扩展总表等超过 ~8 行的查阅性表格，包进默认收起的折叠 callout：`> [!info]- 知识地图（点击展开/收起）` + 表格（callout 内允许表格）。小表格保持裸露。

自检口径补充：`callout` 总数额外计入口径 = 折叠大表格的 callout 数；折叠态要求 = 知识块全 `open=1`（`+`）、自测卡与折叠表格 `open=0`（`-`）。


### 8.7 自检口径（补充 10.2 表）

- `callout` 总数 = 知识块数 + 索引卡数（必背清单 + 复习索引）+ 说明卡（若有；速查表若做成卡也计入）；
- 知识编号唯一，且与知识地图逐块对应；
- `collapse` / `tabs` 数 = 公式组实际组数；
- 其余指标（katex-error 0、无语法残留、折叠默认态等）与 10.2 相同。

## 9. 强化讲义模式：知识点 + 例题 + 题型总结（混合型）

**适用判据**：输入同时出现「知识点 / 公式罗列 + 编号例题（例 1.x）+ 题型归纳（题型 N）+ 工具箱 / 二级结论」→ 强化 / 冲刺阶段讲义。分界线：**出现成套例题且按题型组织 → 本节；纯定义定理公式、无例题 → §8；单题逐篇 → 第 1 节锁定模板。**

### 9.1 与知识手册的分工

| 维度 | 知识手册（§8） | 强化讲义（本节） |
| --- | --- | --- |
| 原子单位 | 知识块 | **例题** |
| 编号 | `F1-01`（块） | `Q1-01`（例）/ `Q1-M1`（方法）/ `Q1-T1`（工具）/ `Q1-C1`（结论） |
| 组织逻辑 | 定义 → 定理 → 公式（是什么） | 题型 → 方法 → 例题（怎么考、怎么做） |
| 自查方式 | 默写自查折叠面板 | **题干可见、解析折叠**（遮答案做题） |
| 末尾索引 | 公式速查 + 必背清单 + 复习索引 | 题型速查表 + 二级结论清单 + **错题回顾** |

### 9.2 四层结构

1. **章层**：`## 【Q1】<考点名>`，开头放**考点地图**表（题型 | 方法一句话 | 例题编号）——MOC 作用，快速查阅入口；
2. **工具箱层**：公式 / 表格 / 恒等式等查阅性内容，默认折叠 `> [!info]- 工具箱 Q1-T<n>｜<名称>`；大公式族用 `:::tabs` 分组；
3. **题型层**：`### 题型N｜<题型名>`（导航标题，目录可跳）→ 每个题型配一张**不折叠的方法卡** `> [!tip] 方法 Q1-M<n>｜<题型名>`：方法步骤 + 适用条件，关键判定 ==高亮==；
4. **例题层**：题干卡 + 解析卡成对出现（见 9.3）。

全篇末尾（索引层）：**题型速查表** → **二级结论清单** → **错题回顾**。

### 9.3 例题块写法（核心模板）

**单折叠题卡**（与第 1 节锁定模板同款）：==题干完整放在折叠卡标题行==，解析折叠于卡内：

```markdown
### 题型1｜<题型名>

> [!tip] 方法 Q1-M1｜<题型名>
> <方法步骤 + 适用条件；关键判定 ==高亮==>

> [!tip]- 【题目】例 Q1-01｜<完整题干；选择题选项用 <br /> 独立成行>
>
> **【解析】**
>
> **思路**：<一句话切入点>
>
> <步骤；关键步 ==高亮=={.tip}>
>
> **答案**：<结论 ==…=={.tip}>
>
> **易错**：<易错点，一行>
```

**硬规则**：
- **题干进标题行、整卡折叠**（`> [!tip]-`）：标题行只放题干 + 来源标签；复习时先想后展开（testing effect）；
- **callout 内换行铁律**：逻辑块之间必须插入空引用行 `>`——题干各问 / 选项、解析各步骤、工具箱各条目一律独立成段，==禁止挤同一段==；
- 多小题例题（判断 (1)~(5)、求 (1)(2)(3)）：标题行放概述标签，完整小题在卡内用 `<br />` 或分段逐行列出；
- 编号一经使用不再变更；解析内**不嵌套 callout**（易错需展开时用平级 `:::collapse` 面板）；
- 同题型多例题按方法变体排序（基础 → 变式 → 综合），标题标签写清来源与变式点。

### 9.4 工具箱与二级结论

- **工具箱**（定义域、代数公式、不等式、图像变换等查阅性内容）：`> [!info]- 工具箱 Q1-T1｜<名称>`，默认折叠；内部用表格组织，公式 `$$` 独占一行；
- **二级结论**（由例题提炼的可复用结论，如"$\lim\sqrt[n]{a_1^n+\cdots}= \max$"): `> [!tip] 二级结论 Q1-C1｜<内容>`，不折叠；全部二级结论收进章末「二级结论清单」；
- **易错**：写进解析卡末行 `**易错**：`；跨题通用的易错升级为 `> [!warning] 易错 Q1-W1｜<主题>` 独立块。

### 9.5 复习设计（三遍复习法）

1. **第一遍（学）**：按题型读方法卡 → 遮住解析做题 → 展开核对，错的进错题索引；
2. **第二遍（忆）**：只看题型速查表，口头回忆方法要点与例题结论，卡壳回跳对应方法卡；
3. **第三遍（考）**：考前只过错题回顾索引（spaced：当天 / 3 天 / 7 天 / 考前）。

**错题回顾**格式（全篇末尾）：

```markdown
> [!info]- 错题回顾
> | 例题 | 错因 | 重做 |
> | --- | --- | --- |
> | Q1-01 | <错因一句话> | 当天 / 3 天 / 7 天 / 考前 |
```

## 12. 附录 A：学习科学依据 → 笔记设计原则

证据基础（内化为结构，不必在笔记里复述文献）：

| 方法 | 证据要点 | 对笔记结构的含义 |
| --- | --- | --- |
| 检索练习（testing effect） | 先自测再核对：一周后保持率约 80%，重读仅 34~40%（Roediger & Karpicke 2006；Karpicke & Roediger 2008, Science） | 每个知识单元都要有「问题在前、答案折叠在后」的形态 |
| 间隔重复（spacing effect） | 分散复习比集中好 10~30%（Cepeda 2006 综述）；最优间隔随目标保留期变化（Cepeda 2008） | 笔记必须有「不读正文也能跑一轮复习」的重入点（索引 + 小结） |
| 康奈尔笔记（Pauk 1962） | 线索栏提问（24h 内补）+ 盖住作答 + 底部总结；对照实验提升理解与保持率（Evans & Shively 2019） | 三分区映射：题卡标题 = 线索栏、卡内解析 = 笔记栏、小结 = 总结栏；**折叠 = 「盖住」** |
| 费曼技巧 / 自我解释 | 用外行话讲得出才算懂，卡壳处即盲区（生成性学习，Fiorella & Mayer 2015） | 小结正文与关键点要求「一句话外行化」；讲不出 = 面板没写清 |
| 交错辨析（interleaving） | 混排相似题型，延迟测试 61% vs 38%，d=0.83（Rohrer 2020） | 相邻题考点在知识点映射表里写成「能互相区分」的辨析短语 |
| 低效手段警示 | 重读 / 划线 / 摘抄被评为 low utility（Dunlosky 2013）；流畅感 ≠ 掌握 | 高亮只做**导航信号**（扫读定位），绝不替代自测结构 |

设计原则（写作与转换共用）：

1. **每个单元可自测**：例题 → 题目卡（题干=问题、解析=答案）；纯知识 → 知识卡（`> [!question]-`，标题即问题）；补充自测 → 卡外 `> [!question]-` 自测卡。
2. **两层重入点**：小结三 tabs（理解层）+ 复习索引（行动层）。复习可以只走这两层 + 高亮，不必重读全文。
3. **先答后翻**：一切自测形态默认收起（`-`）——折叠即盖住答案，展开即核对。
4. **高亮 = 导航**：`==…=={.tip}` 标关键结论、`==…=={.error}` 标红线易错；复习时扫高亮 ≈ 过一遍考点。
5. **辨析优先**：易混概念必须出现在同一个对照结构里（映射表 / 面板 / tabs），不允许散落在两处各说各话。

## 14. 背单词模式：词汇黑幕自测笔记

> 2026-09-30 新增。首个落地样本：《考研英语核心高频词汇串讲》335 词黑幕自测版（`.diag/V1-考研英语核心高频词汇-黑幕自测.md`）。

### 14.1 与其他模式的分工

| | 知识手册（§8） | 强化讲义（§9） | **背单词（本节）** |
| --- | --- | --- | --- |
| 知识单元 | 概念 / 定理 / 公式 | 题型 + 例题 | **词** |
| 学习动作 | 理解 + 系统复习 | 会做 + 举一反三 | **回忆 + 提取** |
| 核心容器 | 标注块 + 对照表 | 例题块 + 题型速查 | **行内黑幕 `:spoiler[]`** |

判定信号（配合 `note-normalizer` §3）：词条结构高度统一（词[音标] + 词性释义，一行为一词）、考点 / 派生 / 例句栏、按主题或字母序成表。

### 14.2 方法论骨架（写进笔记头部，来源：检索共识）

| 原则 | 依据 | 在笔记里的落点 |
| --- | --- | --- |
| 测试效应（主动回忆） | Roediger & Karpicke：提取比重看的长期保持率高 50%–100% | 释义与答案全部 `:spoiler[]` 遮罩，**先猜后看** |
| 间隔重复 | 艾宾浩斯遗忘曲线，先密后疏 | 头部复习节奏表：当天 → 1 / 2 / 4 / 7 / 15 天；只标记失败词 |
| 语境绑定 | 以句带词，记忆牢固度数倍于孤立词表 | 每词保留真题考点短语；挖空轮直接在考点短语上出题 |
| 多维检测 | 三模式轮换防"练习效应" | 英译中（识别）→ 中译英（提取）→ 真题挖空（语境调用） |

### 14.3 结构骨架（卡片式：主题 = 折叠卡片，照抄结构，替换 `<>`）

用户偏好（2026-09-30）：**相同类型的词放同一张折叠卡片里，复习哪块展开哪块，不看就折叠下滑**——不要把全部词平铺。

```markdown
## 【V1】<词书名>（黑幕自测版）

### 使用说明：这份笔记怎么用
（卡片式定位 + 黑幕开关在哪 + 三轮检测 + 复习节奏表：检测轮 / 看什么 / 回忆什么 / 训练什么）

:::collapse accordion
- <主题组名>｜<N> 词

  **① 英译中｜看词回忆释义**

  - **<word>** /<音标>/　:spoiler[<词性释义，一条不删>]
    - 考点：<真题短语>（<年份 题型>）
    - 派生：…　　- 例句：…

  **② 中译英｜看义回忆拼写**

  - 〔adj.〕<中文释义> → :spoiler[<word>]

  **③ 真题挖空｜语境调用**

  1. <真题短语，原词挖成 ______>　→ :spoiler[<word>]

- <主题组 2>｜<N> 词
  …
:::

### 整理说明
```

要点：
- **一个主题 = accordion 的一个面板**；容器内恰好一个顶层无序列表，面板标题后空行、正文缩进 2 空格（§3.3）。
- 模式标题用**加粗段落**不用 `####`——标题进折叠面板会弄脏目录，且列表项内标题行为未验证。
- **中译英不用表格**：面板内嵌套表格行为未验证，统一用列表（`〔词性〕中文 → :spoiler[英文]`）。
- `accordion`（互斥）与默认多开二选一；按"复习哪块展开哪块"的诉求默认 `accordion`。

### 14.4 写作约束

| 项 | 规则 |
| --- | --- |
| 分组 | **按主题分组，不用字母序**（语义网络利于联想）；沿用原书分组 |
| 词条保全 | 词、音标、词性释义、考点（年份 + 题型）、派生、例句**一条不许丢**——词汇笔记的价值密度在词条本身 |
| 黑幕 | 释义 / 检测答案用 `:spoiler[...]`，同行闭合、内容不含未配对 `]`；音标放在黑幕**外**（发音是回忆线索） |
| 尖括号 | 释义里的 `<正式>` `<非正式>` 一律改全角 `＜正式＞`（裸 `<` 会整篇 500） |
| 挖空 | 原词及其常见变形（复数 / 时态，词形匹配）挖成 `______`；考点短语不含原词的词跳过（已由前两轮覆盖） |
| 检测轮 | 三轮齐全；每组都要有；中译英表覆盖该组**全部**词 |
| 词性提示 | 中译英表只给〔词性〕+ 中文，不给首字母提示（防提示泄漏答案） |
| 黑幕嵌套方括号 | **`:spoiler[...]` 内容里不得出现 ASCII `[ ]`**（含嵌套配对也不行——嵌套行为未验证）。词书常见的 `[ˈkɒnvɪkt]` 异形音标、`[~s]` 变形、`[= ensure]` 同义、`[常用被动]` 用法标注，一律转全角 `［ ］`。生成后跑括号深度扫描逐对转换 |
| 释义吞词 | 解析词表时单词字符类**不得含 `.` 和空格**——否则 "state n.中文" 会被上一条的"考点"行吞掉（含词性缩写的行必须判为新词条） |

### 14.5 自检口径（补充 10.2 表）

- `:spoiler[` 出现数 = 渲染后 `class="spoiler"` 数；无裸 `:spoiler`。
- 每主题组三模式齐全；头部有使用说明 + 复习节奏表。
- `audit_mdx.py` 0 缺陷（裸 `<` / 中文尖括号 / 表格断行等通用检查同 §10）。
