# 笔记类型识别与规范化处理（note-normalizer）

## 0. 定位与边界

**职责一句话**：识别类型 → 匹配规范 → 整理输出。

**与 my-blog-structured-notes 的分工**：输入是例题 / 题解 / 课程讲义，且目标含「美化 / 复习 / 博客发布」→ 调用 `my-blog-structured-notes`（锁定模板 + 转换模式 + 渲染自检）；本 skill 不重复其模板与语法，只做识别与路由。

**四条铁律**：
1. **不编造**：事实、数据、决议、引文一律来自原文，一个字都不许添。
2. **缺失标注**：信息缺口用 `[待补]` 标出，不臆测填充。
3. **日记克制**：日记 / 随笔类只做轻整理，不改语气与人称。
4. **必附说明**：输出末尾必须有「整理说明」（第 5 节），交代识别依据与改动清单，可回退。

---

## 1. 处理流水线（六步）

1. **通读全文**，收集类型信号（第 3 节信号表）。
2. **判定类型**：强信号 ≥ 2 → 确认；强信号 1 + 弱信号 ≥ 2 → 倾向（向用户确认，推荐项排第一）；信号冲突或全部不足 → 问用户（AskUserQuestion，附一句判断依据）。混合内容 → 定**主类型** + 子区段，不硬拆成两篇。
3. **套用类型规范**（第 4 节）：标准骨架 + 默认强度（用户可指定覆盖）。
4. **执行整理**（第 2 节通用规则）。
5. **按该类型 checklist 自检**，不过就回改。
6. **输出**：规范化笔记 + 「整理说明」（第 5 节）。

---

## 2. 通用规则（跨类型）

### 2.1 整理强度分级

| 强度 | 做什么 | 不做什么 | 默认适用 |
| --- | --- | --- | --- |
| 轻度 | 排版规范化、错别字、分段、统一标点 | 不动内容结构 | 日记、通用兜底 |
| 中度 | 重组段落、补标题层级、统一术语 | 不增删事实 | 会议记录、技术文档 |
| 重度 | 结构化重写、生成模板字段（行动项 / 自测问题等） | 事实仍须全部来自原文 | 学习笔记、读书笔记 |

### 2.2 三条公共动作

- **术语统一**：同义异名归一；出现 ≥ 2 组时在文末附「术语对照」小表。
- **信息保全**：任何删减先在「整理说明」列改动清单；拿不准的一律进「待补项」。
- **公式与代码**：公式补 `$…$` 定界、命令进代码块；若目标是 My-Blog 发布，格式细节遵守 `my-blog-structured-notes` 第 3 节语法参考与第 5 节排错。
- **答案 / 剧透遮罩**：原文里「先给出谜面 / 问题、答案单独给出」的内容（题解答案、影评剧透、谜底等），若目标是 My-Blog 发布，可用行内黑幕 `:spoiler[答案]` 遮罩（默认完整显示，文章页「黑幕」开关开启后才隐藏；写法与边界见 `my-blog-structured-notes` 3.6）。非 My-Blog 目标不使用该语法。

## 3. 类型识别信号表

| 类型 | 强信号（命中 ≥ 2 基本确认） | 弱信号 | 否定信号 |
| --- | --- | --- | --- |
| 会议记录 | 出席 / 参会人、议程、决议、"行动项"、"负责人"、deadline | 时间地点头、"讨论"、"同步" | 第一人称情绪叙事 |
| 学习笔记 | 定义 / 公式 / 推导、例题编号（【3.1】式）、考点、易错点 | 课程名、章节号、"老师讲" | 行动项 / 决议 |
| 读书笔记 | 书名 / 作者、章节摘录、引文 + 页码、"作者认为"、读后感 | 金句、ISBN / 豆瓣 | 决议、命令行 |
| 技术文档 | 命令行 / 代码块、安装 / 配置 / 报错、版本号、API、"步骤 1/2/3" | README、依赖、环境变量 | 情绪叙事 |
| 日记 / 随笔 | 日期 + 第一人称、"今天"、情绪 / 心情 | 天气、流水账 | 术语公式密集 |
| 例题 / 题解 | 题干 + 选项 A/B/C/D、"解 / 证明"、批注、考点 | 讲义、"第 X 章" | — |
| 词汇笔记（背单词） | **词条结构高度统一**（词[音标] + 词性释义，一行为一词）、**"考点 / 派生 / 例句"栏**（考点常带真题年份与题型）、按主题或字母序成表 | 词书名、List / Unit 编号、"联想 / 词根"栏 | 成段知识阐述、公式推导 |
| 通用（兜底） | 以上强信号命中均 < 1 | — | — |

**判定输出**：每一步都要能说清「为什么判成这个类型」（引用命中的信号词）。例题 / 题解命中 → 直接路由（4.0），不进入第 4 节其余规范。

## 4. 类型规范库

### 4.0 路由：例题 / 题解 / 讲义

条件命中 → 调用 `my-blog-structured-notes` skill：单题逐篇例题走其锁定模板；**「知识点 + 例题 + 题型总结」混合型强化讲义走其第 9 节「强化讲义模式」**；纯知识点走其第 8 节；普通讲义 / MD 文档走其第 7 节「转换八步」；**词汇笔记（背单词）走其第 14 节「背单词模式」**。输出遵循其骨架与渲染自检，本 skill 流程终止。

### 4.1 会议记录

- **默认强度**：中度。
- **标准骨架**：

```markdown
# <会议主题>（<日期>）
- 时间 / 地点 / 参会人 / 记录人
## 议题与讨论
- <议题>：<要点>（口语转写为陈述句）
## 决议
- <决议>（依据：谁提出 / 是否一致同意）
## 行动项
| 事项 | 负责人 | 截止 |
| --- | --- | --- |
## 遗留问题
```

- **整理规则**：无明确结论的讨论标「结论待定」；行动项缺 owner / 期限 → `[待补]`；同一议题散落多处 → 合并；发言人观点保留归属（"X 提出…"）。
- **自检**：每个议题有归属段落；决议可追溯；行动项全部有 owner + deadline（或待补标记）；无口语转写残留（"然后""就是说"）。

### 4.2 学习笔记

- **默认强度**：重度。
- **标准骨架**：核心问题 → 概念定义 → 方法 / 步骤 → 例题（保留原编号）→ 易错点 → 自测问题（3~5 个，检索式）。
- **整理规则**：概念首次出现补一句定义；相邻易混概念放进**同一个对照结构**；自测问题必须"合上笔记能作答"，不出复述题。
- **自检**：概念有定义；例题编号未丢失；易错点独立成区；自测问题全部为检索式。
- 目标为博客发布 → 转交 `my-blog-structured-notes`：含例题走其锁定模板；**纯知识点走其第 8 节知识手册模式**。

### 4.3 读书笔记

- **默认强度**：中度~重度。
- **标准骨架**：书目头（书名 / 作者 / 版本 / 阅读区间）→ 核心论点（≤ 3 条）→ 章节框架 → 摘录（引号 + 页码 / 章节）→ 我的评注 → 行动启发。
- **整理规则**：**摘录与评注严格分离**——摘录是"作者说的"，评注是"我想的"，不得混排；引文一字不改；评注缺失 → 留空区并标 `[待补]`，不代写。
- **自检**：每条摘录有出处；摘录与评注无混排；核心论点 ≤ 3 条；行动启发可执行。

### 4.4 技术文档

- **默认强度**：中度。
- **标准骨架**：概述（解决什么问题）→ 适用版本与环境前置 → 安装 / 配置 → 使用步骤（编号 + 代码块）→ 常见问题（报错 → 原因 → 解法）→ 参考。
- **整理规则**：命令一律进代码块保证可复制；版本敏感处标注版本号；路径 / 占位符用 `<占位>` 形式；同义术语归一。
- **自检**：每条命令都在代码块内；步骤可从头到尾照跑；报错条目含现象 + 原因 + 解法；版本信息明确（或标 `[待补]`）。

### 4.5 日记 / 随笔

- **默认强度**：**轻度**（除非用户明确要求更深整理）。
- **标准骨架**：日期标题 + 原文正文（仅修错别字、分段）；可选末尾加一行标签（如 `#工作 #旅行`）。
- **整理规则**：**不重写、不改语气与人称、不加结构标题打断叙事**；不做情绪分析、不写总结评语；私密内容保持私密。
- **自检**：原文语句基本原样保留；未新增任何评价性文字；分段未改变叙述顺序。

### 4.6 通用（兜底）

- **默认强度**：轻度。
- **动作**：补标题层级、按主题分段、修错别字与标点、术语对照；正文超过 800 字补目录。
- **自检**：未重排事实顺序；未增删事实；标题层级 ≤ 3 级。


### 4.7 词汇笔记（背单词）

- **默认强度**：重度（重排结构 + 生成自测层，但词条事实逐条保全）。
- **本质**：知识单元是"**词**"而非"概念"，学习动作是"**回忆**"而非"理解"——所以结构围绕"先猜后看"组织，而不是围绕"讲清概念"组织。
- **标准骨架**：见 `my-blog-structured-notes` **第 14 节「背单词模式」**（黑幕自测：英译中 / 中译英 / 语境挖空三轮检测 + 间隔重复节奏表）。目标非 My-Blog 时用 `~~释义~~` 或"词 —— 释义（先遮后看）"的降级形式。
- **整理规则**：
  1. **词条逐条保全**：词、音标、词性释义、考点（含真题年份与题型）、派生、例句一条不许丢——词汇笔记的价值密度在词条本身，不许合并或摘要。
  2. **黑幕承载回忆**：释义与检测答案用 `:spoiler[...]` 遮罩（"看词猜义"是测试效应的落地）；黑幕写在 My-Blog 目标下才用。
  3. **主题分组优先于字母序**（语义网络利于联想）；沿用原书分组。
  4. **三轮检测**：英译中（识别）→ 中译英（主动提取）→ 考点短语挖空（语境调用）。
  5. 头部附「使用说明 + 复习节奏」（间隔重复：当天 → 1/2/4/7/15 天，先密后疏）。
- **自检**：词数守恒（输入 N 词 = 输出 N 词条）；考点年份与题型无丢失；`:spoiler[` 成对且同行闭合；三模式齐全。

---

## 5. 输出格式

正文 = 规范化笔记（按第 4 节骨架）。末尾追加：

```markdown
> **整理说明**（AI 生成）
> - 识别类型：<类型>（置信度 高/中/低；依据：<1 句信号摘要>）
> - 整理强度：轻度 / 中度 / 重度
> - 主要改动：① … ② …（≤ 5 条）
> - 待补项：…（无则写"无"）
```

若目标是 My-Blog 发布：正文格式改走 `my-blog-structured-notes` 的骨架与语法，交付流程走其第 10 节（`.diag` 源文件 + 渲染自检 + 离线预览）。
