# My-Blog 结构化笔记书写规范

**适用**：博客文章（`/blog/*`）、文档系统（`/doc/*`）、写作台预览共用同一套渲染管线。
**配套**：`note-normalizer` 负责判型与路由；本 skill 负责骨架、语法与自检。

> 项目语法手册：`docs/Markdown-语法手册.md`（完整权威，冲突时以源码 `src/lib/mdx.ts`、
> `src/lib/mdx-plugins.ts` 为准）。本 skill 的 `references/syntax.md` 是速查版，
> `references/patterns.md` 是从站内 30 篇文章里提炼的真实体裁样本。

---

## 0. 五种模式：先选骨架，再动笔

| 输入形态 | 模式 | 最小单元 | 自查方式 | 本节 |
| --- | --- | --- | --- | --- |
| 单题逐篇例题 / 题解 | **例题模式**（锁定模板） | 一道题 | 题干常显、解析折叠 | §2.1 |
| 纯定义 / 定理 / 公式，无例题 | **知识手册模式** | 知识块 | 默写自查 | §2.2 |
| 知识点 + 编号例题 + 题型归纳 | **强化讲义模式** | 例题 | 题干可见、解析折叠 | §2.3 |
| 普通 MD / 讲义，要提升复习效率 | **转换模式** | 单元 | 自测卡 + 复习索引 | §2.4 |
| 词汇表 / 单词书 | **背单词模式** | 词 | 黑幕「先猜后看」 | §2.5 |

**通用心态**：骨架是锁定的，**只替换占位内容，不改结构**。同一系列笔记必须长得一样。

## 1. 全模式通用的硬约束

1. **正文从 `##` 起**，不写 `#` 一级标题（文章标题单独由后台填写）。目录只收 h2 / h3 / h4。
2. **`<br />` 必须自闭合**：写 `<br>` 会报 `Expected a closing tag for <br>`，整篇渲染失败。
3. **标题不能在源码里换行**：Callout 标题 = 引用块首段第一行；要分行用 `<br />`
   （选择题选项 `A. …　<br />B. …`，全角空格 `　` 做视觉分隔）。
4. **块级公式 `$$` 必须独占一行**；引用块内写 `> $$`；公式行不要以 `|` 开头（会被当表格转义）。
5. **每个 `\begin{…}` 必须在 `$…$` / `$$…$$` 内**。裸写是本项目最高频故障：
   `{bmatrix}`/`{cases}` → 整篇 500；`\frac{1}{2}` 的 `{1}` `{2}` → 静默错乱，不报错。
6. **正文不写裸花括号**，需要字面量写 `\{` `\}`；不写 HTML 注释与带 `style` 的内联 HTML。
7. **`==` 必须同行闭合**：开闭跨行不报错但高亮静默失效，且同行 `==` 成对时无法靠 grep 发现。
8. **容器闭合围栏独占一行**，不要写成「……正文。 :::」。
9. **`:::` 容器嵌套时外层加长到 4 个冒号**（`::::collapse` 套 `:::tabs`）。
10. **表格表头必须填真实列名**，别写空表头 `|  |  |`。
11. **Callout 里不能放 `:::tabs`**；Callout 里的 `:::collapse` 必须省略参数与 `:+` / `:-`。
12. **知识块默认折叠态**：知识块用 `+`（默认展开、可收起）；题卡 / 自测卡用 `-`（默认收起）。

## 2. 五种模式的强制骨架

### 2.1 例题模式（锁定模板，逐字段复刻）

```markdown
> [!info]【本篇说明】
> 本篇整理<考点清单，用「、」列举>。<题数> 道例题：<一句话串起主线>。每题标题栏含完整题干，解析折叠于卡片内，拓展知识独立于卡片外，默认可折叠查看。

---

## 【3.1】<题型名>

> [!tip]- 【题目】<完整题干><br />A. <选项一>　<br />B. <选项二>　<br />C. <选项三>　<br />D. <选项四>
>
> **【解析】**
>
> ==<关键结论 / 判定依据>=={.tip}
>
> **【思路分解】**
>
> **① <步骤标题>**
>
> <步骤内容，可含 $$ 块级公式>
>
> **② <步骤标题>**
>
> <步骤内容>
>
> **③ <步骤标题>**
>
> <步骤内容>

**【拓展知识】**

:::collapse
- <知识面板标题>

  <面板正文>

- <知识面板标题>

  <面板正文>
:::

---

## 小结

> [!summary]【小结】
>
> <一段总结：各题分别对应什么考点 + 核心工具 / 主线>

:::tabs#summary

@tab:active 知识点映射 #km

- 【3.1】<考点>：<关键结论>
- 【3.2】<考点>：<关键结论>

@tab 通用流程 #gc

1. <流程第 1 步>
2. <流程第 2 步>

@tab 必记结论 #jl

- $<结论公式一>$
- $<结论公式二>$

:::

> [!tip]【最容易失分的地方】
>
> - 【3.2】<易错点>
> - 【3.3】<易错点>
```

**字段规则**：

| 字段 | 规则 |
| --- | --- |
| 题目卡 | 固定 `> [!tip]-`；**完整题干 + 全部选项写进标题行**（折叠时只剩标题可见） |
| 解析 | `**【解析】**` → `==关键点=={.tip}` → `**【思路分解】**` → `**①…**` 3~5 步 |
| 拓展知识 | 卡片**外**段落级 `**【拓展知识】**` + `:::collapse`，1~3 个面板，一个知识点一个 |
| 勘误 | 仅当原笔记确有错误才加，放该题 `:::collapse` 里，没错不加 |
| 小结 | `> [!summary]` + `:::tabs#summary` 固定三页：知识点映射 / 通用流程 / 必记结论 |
| 易错 | `> [!tip]【最容易失分的地方】` + 无序列表，每条以 `【3.X】` 开头 |

### 2.2 知识手册模式（纯知识点）

四层结构：**章 → 知识块 → 导航标题 → 索引**。

```markdown
> [!info]【本篇说明】
> 本篇是<主题>知识手册：<范围>。全篇 <N> 个知识块（<科目缩写>1-01 ~ <科目缩写>2-12），配知识地图、速查表、必背清单与复习索引。内容来自<来源>，<已剔除什么>。

## 【P1】<章名>

### 适用环境与知识地图

**知识地图**

| 编号 | 类型 | 名称 |
| --- | --- | --- |
| P1-01 | 定义 | <名词化标题> |
| P1-02 | 结论 | <名词化标题> |

### <组名：检索词>

> [!note] 定义 P1-01｜<名词化标题>
> <内容；$$ 独占一行>

> [!tip] 结论 P1-05｜<名词化标题>
> <内容；关键判定 ==…=={.tip}>

> [!warning] 注 P1-08｜<错在哪>
> <内容；红线 ==…=={.error}>

> [!example] 方法 P1-09｜<步骤名>
> 1. <步骤>

> [!quote] 口诀｜<主题>
> <口诀>

（全篇末尾，依次为）

### 命令 / 公式速查表

| 主题 | 公式或命令 | 编号 |
| --- | --- | --- |
| <主题> | `<命令>` / $<公式>$ | P1-05 |

### 必背清单

> [!info]【必背清单】
> - ==<高频结论>==。
> - <易错点，配 ==…=={.error}>

### 复习索引

> [!info]【复习索引】
> - <钩子问题>？（P1-02）
> - <钩子问题>？（P2-11）
>
> 复习路径：先只看本索引口头作答 → 展开对应知识块核对 → 答错的顺带扫正文高亮处。间隔：当天 / 3 天 / 7 天 / 考前。
```

**知识块类型徽章**（一块只讲一件事）：

| 知识类型 | 徽章写法 | 默认折叠 |
| --- | --- | --- |
| 定义 | `> [!note] 定义 P1-01｜<名词化标题>` | `+`（展开可收） |
| 定理 / 性质 / 结论 | `> [!tip] 定理 / 结论 P1-05｜…` | `+` |
| 易错注 / 辨析 | `> [!warning] 注 P1-08｜…` | `+` |
| 口诀 | `> [!quote] 口诀｜…` | `+` |
| 方法 / 步骤 | `> [!example] 方法 P1-09｜…` | `+` |
| 自测卡 | `> [!question]- 自测：…？` | `-`（默认收起） |

**导航关键**：知识块是 Callout，**不进目录**。每组知识块上方必须有 `### <组名>`（组名 = 检索词），
让目录提供「章 h2 → 组 h3」两级跳转，任何知识块两次点击可达。

### 2.3 强化讲义模式（知识点 + 例题 + 题型总结）

原子单位是**例题**，组织逻辑是「题型 → 方法 → 例题」。

```markdown
## 【Q1】<考点名>

**考点地图**

| 题型 | 方法一句话 | 例题 |
| --- | --- | --- |
| 题型1｜<名> | <一句话> | Q1-01 ~ Q1-03 |

> [!info]- 工具箱 Q1-T1｜<名称>
> <公式 / 表格>

### 题型1｜<题型名>

> [!tip] 方法 Q1-M1｜<题型名>
> <方法步骤 + 适用条件；关键判定 ==高亮==>

> [!tip]- 【题目】例 Q1-01｜<完整题干；选项用 <br /> 分行>
>
> **【解析】**
>
> **思路**：<一句话切入点>
>
> <步骤；关键步 ==高亮=={.tip}>
>
> **答案**：<结论 ==…=={.tip}>
>
> **易错**：<易错点，一行>

（全篇末尾）题型速查表 → 二级结论清单 → 错题回顾
```

**硬规则**：
- 题干进标题行、整卡折叠（`> [!tip]-`）：先想后翻（testing effect）。
- Callout 内逻辑块之间必须插空引用行 `>`；题干各问 / 选项、解析各步骤一律独立成段，禁止挤同一段。
- 解析内**不嵌套 Callout**；易错要展开时用平级 `:::collapse` 面板。
- 编号：`Q1-01`（例题）/ `Q1-M1`（方法）/ `Q1-T1`（工具）/ `Q1-C1`（二级结论），一经使用不再变更。

### 2.4 转换模式（普通 MD → 复习型笔记）

在第 2.1 骨架基础上追加两个区段，其余不变：

```markdown
（每单元之后，与拓展知识同级；按需 1~2 张）

> [!question]- 自测：<能检索的问题>？
>
> **【答案】** <一句话答案>（指回：【3.X】）

（全篇最后，易错提醒之后）

> [!info]【复习索引】
>
> - <钩子问题一>？（【3.1】）
> - <钩子问题二>？（【3.2】）
>
> 复习路径：先只看本索引口头作答 → 展开对应题卡核对 → 答错的顺带扫正文 ==红== 高亮。间隔：当天 / 3 天 / 7 天 / 考前。
```

**转换八步**：切块 → 主卡化（题卡 / 知识卡）→ 补自测卡 → 提炼拓展 → 写小结 →
复习索引 → 易错清单 → 渲染自检。

**钩子问题合格标准**：合上正文能口头作答（检索），不是「3.1 讲了什么」这类复述题。

### 2.5 背单词模式（黑幕自测）

一个主题 = 一个折叠面板；释义与答案全部 `:spoiler[...]` 遮罩；三轮检测：英译中 → 中译英 → 真题挖空。

```markdown
## 【V1】<词书名>（黑幕自测版）

### 使用说明：这份笔记怎么用

（黑幕开关在哪 + 三轮检测 + 复习节奏表：检测轮 / 看什么 / 回忆什么 / 训练什么）

:::collapse accordion
- <主题组名>｜<N> 词

  **① 英译中｜看词回忆释义**

  - **<word>** /<音标>/　:spoiler[<词性释义，一条不删>]
    - 考点：<真题短语>（<年份 题型>）
    - 派生：…　　- 例句：…

  **② 中译英｜看义回忆拼写**

  - 〔adj.〕<中文释义> → :spoiler[<word>]

  **③ 真题挖空｜语境调用**

  1. <真题短语，原词挖成 ______>　→ :spoiler[<word>]

- <主题组 2>｜<N> 词
  …
:::

### 整理说明
```

**约束**：词 / 音标 / 词性释义 / 考点（年份 + 题型）/ 派生 / 例句一条不丢；音标放在黑幕**外**；
释义里的 `<正式>` 改全角 `＜正式＞`（裸 `<` 会整篇 500）；`:spoiler[...]` 内不得出现 ASCII `[ ]`
（异形音标、变形、同义标注一律转全角 `［ ］`）；中译英表覆盖该组全部词且不给首字母提示。

## 3. 语法速查（核心条目）

> 完整条目、取值与边界见 `references/syntax.md`；本节只列写作时最常用的。

| 语法 | 层级 | 写法 | 关键约束 |
| --- | --- | --- | --- |
| Callout | 引用块 | `> [!type]- 标题` | 折叠符号 `-` / `+` 紧贴类型名；标题支持行内 MD 与 `<br />` |
| Admonition | 段落 | `:::note` … `:::` | 不支持同行标题；5 种：note / info / tip / warning / danger |
| Collapse | 段落 | `:::collapse` + `- 面板` + `:::` | 恰好一个无序列表；面板正文缩进 2 空格；可加 `accordion` / `expand` |
| Tabs | 段落 | `:::tabs#id` + `@tab 标签` + `:::` | 开标记独占一行；≥2 个 `@tab`；不能放 Callout 内 |
| Mark | 行内 | `==重点=={.tip}` | 同行闭合；后缀式最稳；不嵌套 |
| Spoiler | 行内 | `:spoiler[内容]` | 内容内不用 ASCII `[ ]`；文章页默认完整显示 |
| 行内标注 | 行内 | `:note[文字]` | 单冒号 + 方括号 |
| 公式 | 行内 / 块级 | `$…$` / `$$` 独占行 | 块级 `$$` 各占一行；引用块内 `> $$` |

**11 种 Callout 类型**：note / info / tip / success / question / warning / failure / danger / bug /
example / quote（别名：hint→tip，caution→warning，error→danger，summary/tldr→info，faq/help→question）。
高频语义：定义=note，结论=tip，易错=warning，口诀=quote，方法/例题=example 或 tip。

**文件内编号体系**（与文章库一致）：

| 编号 | 含义 | 例 |
| --- | --- | --- |
| `<科目><章>-<序号>` | 知识块 | `P1-01`、`F2-03`、`RM-01`、`C2-05` |
| `Q<章>-<序号>` | 例题 | `Q1-03` |
| `Q<章>-M<n>` / `-T<n>` / `-C<n>` | 方法 / 工具 / 二级结论 | `Q1-M2`、`Q1-T1`、`Q1-C3` |
| `【X.Y】` | 例题或章节 | `【3.1】`、`【C2】` |

## 4. 嵌套与组合：围栏长度铁律

**`:::` 容器互相嵌套时，外层必须比内层更长**：外层 `::::`（4 个冒号），内层 `:::`。

| 外层 ＼ 内层 | tabs | collapse | Callout | 高亮 |
| --- | :---: | :---: | :---: | :---: |
| Callout `> [!x]` | ❌ 整体失效 | ✅（省略参数） | ✅ | ✅ |
| `::::collapse` | ✅ | ✅ | ✅ | ✅ |
| `:::collapse`（3 冒号） | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ | ✅ |
| `::::note` | ✅ | ✅ | ✅ | ✅ |
| `:::note`（3 冒号） | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ | ✅ |
| 段落层级 | ✅ | ✅ | ✅ | ✅ |

记忆法：**要往容器里塞选项卡，外层就写 4 个冒号；Callout 里塞不了选项卡。**

## 5. 排错手册

### 5.1 整篇渲染失败

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| `Could not parse expression with acorn` | 正文有裸花括号 | 公式补 `$…$`；普通花括号改 `\{` `\}`；示例放代码围栏 |
| `ReferenceError: bmatrix / cases is not defined` | 公式漏写 `$` / `$$`，`{bmatrix}` 被当 JS 标识符求值 | 给每处 `\begin{…}` 补定界符；`$$` 独占行 |
| `Expected a closing tag for <br>` | 标题里写了 `<br>` | 改 `<br />` 或 `<br/>` |
| `Unexpected character !` | HTML 注释 `<!-- -->` | 删除注释或改用代码围栏展示 |
| `No such environment: \{` | 公式行以 `|` 开头，被当表格转义 | 公式行不要以 `|` 起行 |

### 5.2 语法泄漏（标记原样显示）

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 页面多出一行 `:::`（容器已渲染） | 闭合围栏与正文同一行 | 闭合围栏独占一行 |
| 页面多出一行 `:::`（容器没渲染） | 外层 3 冒号却内嵌 `:::` | 外层改 4 冒号 |
| `:::tabs#id @tab` 整块泄漏 | 开标记行后面多了内容 | 开标记独占一行 |
| `> :::collapse expand` 泄漏 | Callout 内不能带参数 | 省略参数 |
| Callout 内出现空 `<div></div>` | `> - :+` 的 `:` 被当 textDirective | Callout 内不用 `:+` / `:-` |
| `[! tip]` 原样显示 | `[!` 后多了空格 | 写 `> [!tip]` |
| `==…==` 不生效但正文正常 | 开闭 `==` 跨行 | 闭 `==` 提前到同行；后续内容另起段 |
| `==tip:文本==` 句中泄漏 | 前缀式只在文本节点开头生效 | 改后缀式 `==文本=={.tip}` |
| 表格表头空、列名掉到第一行 | 表头行写成空行 | 表头填真实列名 |
| 折叠面板消失 | 容器内不是「恰好一个无序列表」 | 用 `-` 列表，正文缩进 2 空格 |

### 5.3 公式类

| 现象 | 原因 | 解法 |
| --- | --- | --- |
| 公式红字 / 渲染异常 | `$$` 与内容同行 | `$$` 独占一行 |
| 公式残缺、出现奇怪数字（不报错） | 漏 `$` 且花括号内是合法 JS | 补定界符；跑 `check-math-delims` |
| 公式显示 `\{` 或环境名 | 公式行以 `|` 开头 | 换行首写法 |

## 6. 自检（必做）

### 6.1 公式定界符专查（最高优先级）

```bash
node skills/my-blog-structured-notes/scripts/check-math-delims.mjs .diag/<你的笔记>.md
```

剥掉代码围栏 / 块级公式 / 行内公式 / 行内代码后，列出所有**裸露** LaTeX 与行号，并报未闭合围栏；
退出码 1 = 有问题。**必须单独跑**：`renderMdx` 能跑通 ≠ 公式正确。

### 6.2 渲染自检

用项目 `renderMdx` 直跑（`tsx` 或临时 vitest 用例），检查：

| 指标 | 期望 |
| --- | --- |
| `katex-error` | 0 |
| 裸露 LaTeX（check-math-delims） | 0 处 |

## 7. 文章体裁观察（站内 30 篇实证）

写之前先对照这些真实习惯，能少走很多弯路：

1. **开篇必有一段「本篇说明」**（`> [!info]【本篇说明】`），一句话说清：整理了什么、怎么组织、
   末尾有什么。读者据此决定是通读还是只查索引。
2. **章首放知识地图 / 考点地图**（编号｜类型｜名称 或 编号｜小节），让目录之外也有全局入口。
3. **知识块用「类型徽章 + 编号 + 名词化标题」**：`> [!tip]+ 结论 RM-04｜Remotion 的主场：音画同步`。
   标题是检索词，不是叙事句。
4. **折叠默认态区分用途**：知识块 `+`（可收起、默认展开，不打断阅读）；题卡 / 自测卡 `-`
   （默认藏答案，先想后翻）。
5. **关键判定用高亮，不靠加粗**：`==单靠视频生成模型基本做不到=={.tip}`；
   红线易错用 `==…=={.error}`。高亮只做导航信号，不替代自测结构。
6. **对比优先用表格**：参数对照、版本差异、方案对比、报错速查，全部落成 GFM 表格（表头填真实列名）。
7. **真题 / 出处写进标题或条目**：`命题追踪｜采用二进制编码的原因（2018）`、
   `考点：<真题短语>（2023 英语一 完形）`——保留可追溯性。
8. **末尾三件套按模式选**：知识手册 = 速查表 + 必背清单 + 复习索引；强化讲义 = 题型速查 + 二级结论 + 错题回顾；
   例题 = 小结 tabs + 易错清单。
9. **自测卡只出检索题**：条件辨析、反例判断、结论回溯；不出「本节讲了什么」。
10. **整理说明独立成节**：长文在末尾用 `### 整理说明`，短文用 `> **整理说明**（AI 生成）`。
11. **命令 / 公式都追求「可单行粘贴」**：多行脚本另附「写法示例」代码块，其余写成一行。
12. **删除的东西要交代**：原书习题、答案、水印、推广内容被剔除时，在本篇说明或整理说明里写清。

## 8. 写作流程（七步）

1. **读原始材料**：按「题 / 单元 / 知识块」切块，标出核心考点与题型名。
2. **选模式**（§0），**抄骨架**：整段复制本 skill 对应骨架，再逐块替换占位内容；不要边写边想结构。
3. **填主卡**：题干进标题行；知识块写「徽章 + 编号 + 名词化标题」。
4. **写解析 / 正文**：解析按「解析 → 关键点 → 思路分解 → ①②③」；知识块一块只讲一件事。
5. **写拓展 / 对照**：`:::collapse` 面板或 GFM 表格；跨单元对比用 `:::tabs`（注意外层 4 冒号）。
6. **写小结与索引**：小结 tabs 三页；末尾速查表 / 必背清单 / 复习索引。
7. **自检**（§6），全绿才交付。
