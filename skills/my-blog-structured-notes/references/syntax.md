# My-Blog 扩展语法速查

> 与 `docs/Markdown-语法手册.md` 同源，二者冲突时以源码 `src/lib/mdx.ts`、`src/lib/mdx-plugins.ts` 为准。
> 渲染顺序：GFM → 数学 → 指令容器（`:::`）→ 自定义扩展（callout / 折叠 / 选项卡 / 高亮）→ KaTeX / 代码高亮 / 标题锚点。

## 0. 六条铁律

| # | 规则 | 违反后果 |
| --- | --- | --- |
| 1 | `:::` 开标记必须独占一行，成对闭合 | 整块降级为普通文本，`:::` 原样显示 |
| 2 | 容器嵌套时外层用 4 个冒号 `::::`，内层用 3 个 `:::` | 页面多出一行 `:::`（无声、不报错） |
| 3 | 块级语法之间留空行 | 相邻块被合并解析 |
| 4 | 正文花括号写 `\{` `\}` | 整篇渲染失败（acorn / `xxx is not defined`） |
| 5 | 不写 HTML 注释、不写带 `style` 的内联 HTML | 渲染失败 |
| 6 | 正文不使用 `#` 一级标题 | 与文章标题重复；目录只收 h2 / h3 / h4 |

转义：`\{` `\}`、`\=\=`、`\*` `\_` `\[` `\]` `` \` ``、`\$`、`\\`。

## 1. 标题与目录

- `##` / `###` / `####` 进左侧目录；h1、h5、h6 不进。
- 锚点由标题文本自动生成，中文原样保留；标题内行内代码 / 强调 / 高亮会被剥掉再生成锚点。
- 不支持自定义锚点（`## 标题 {#my-id}` 会渲染失败）。

## 2. Callout（引用块级，主力）

```markdown
> [!note] 自定义标题
> 正文。

> [!example]- 默认收起的标题
> 展开后才可见的正文。

> [!tip]+ 默认展开且可折叠
> 正文。
```

- 折叠符号：无 = 不折叠；`-` = 默认收起；`+` = 默认展开可收起。**紧贴类型名**，中间不能有空格。
- `[! tip]`（`!` 后带空格）完全不识别。
- 标题 = 引用块首段第一行；换行用 `<br />`（必须自闭合）。
- 正文可多段、列表、公式块、表格；**不能放 `:::tabs`**；内嵌 `:::collapse` 必须省略参数与 `:+` / `:-`。
- 折叠时仅标题行可见：题干 / 问题必须写进标题行。

**类型与别名**：

| 规范类型 | 别名 |
| --- | --- |
| note / info / tip / success / question / warning / failure / danger / bug / example / quote | hint→tip；caution→warning；error→danger；summary、tldr→info；faq、help→question；check、done→success |

## 3. Admonition（段落级提示块）

```markdown
:::note
正文（支持完整块级 Markdown）。
:::
```

- 5 种：`note` / `info` / `tip` / `warning` / `danger`，标题固定，**不支持自定义标题**
  （`:::warning 注意安全` 整行降级）。
- 行内形式：`:note[行内备注]`（单冒号 + 方括号）。
- 嵌套选项卡时外层必须写 `::::note`。

## 4. Collapse（折叠面板组）

```markdown
:::collapse
- 面板标题

  面板正文（缩进 2 空格）

- :+ 默认展开的面板标题

  正文。
:::
```

- 参数（写在 `collapse` 后）：`accordion`（互斥）、`expand`（全展开）、`accordion expand`。
- 单项标记：`:+` 初始展开；`:-` 强制折叠。优先级：`:-` > `:+` > `expand` > 默认折叠。
- 容器内必须**恰好一个无序列表**（`-`）；有序列表不识别；标题后空一行再写正文。
- 闭合围栏必须独占一行；写进 Callout 时必须省略参数与 `:+` / `:-`。
- 内嵌 tabs 时外层写 `::::collapse`。

## 5. Tabs（选项卡组）

```markdown
:::tabs#group-id

@tab:active 第一个标签

内容。

@tab 第二个标签

内容。

:::
```

- `:::tabs` / `:::tabs#id` 开标记必须独占一行；同 id 的组选中状态互相同步。
- `@tab:active` 指定初始激活（同组只认第一个）；`@tab 标签#锚点` 的锚点用于跨组对齐，不显示在按钮上。
- ≥2 个 `@tab`；标签支持行内 Markdown；不能写在 Callout 内。

## 6. Mark（荧光高亮）

```markdown
==默认主色==

==重点=={.tip}

==tip:重点==
```

- 变体：`primary`（main / default）、`secondary`（sub）、`tertiary`（third）、
  `error`（danger / warning / warn / caution）、`tip`（success / info / note / hint）。
- **推荐后缀式** `==文本=={.tip}`（位置随意）；前缀式只在文本节点开头可靠。
- 不支持嵌套；同一行必须闭合；字面 `==` 写 `\=\=`。

## 7. Spoiler（黑幕）与行内标注

```markdown
最终的答案是 :spoiler[42]。

:note[随文备注]
```

- `:spoiler[...]` 默认完整显示，文章页「黑幕」开关开启后遮罩（悬停 / 点击揭示）。
- 内容内不要出现 ASCII `[ ]`（嵌套行为未验证）。
- 表格单元格内可用。
- `:note[...]` 用于一句话级别的随文备注。

## 8. 数学

```markdown
行内：$E = mc^2$

块级：
$$
\begin{cases}
x > 0 \\
y < 0
\end{cases}
$$
```

- 块级 `$$` 必须各自独占一行；引用块内写 `> $$`。
- 引用块内块级公式的每一行都要带 `> ` 前缀。
- 公式行不要以 `|` 开头：表格转义会把 `{` `}` 变成 `\{` `\}`。
- 裸 `\begin{…}` 会整篇 500 或静默错乱 —— 用 `scripts/check-math-delims.mjs` 专查。
- 表格单元格内 `$…$` 会被二次渲染，公式里的 `|` 自动转 `\vert`。

## 9. 表格 / 代码 / 图片 / 分隔线 / 脚注

| 语法 | 规则 |
| --- | --- |
| GFM 表格 | 表头行必须填真实列名；对齐由分隔行冒号决定；单元格内可写行内代码、强调、公式 |
| 代码块 | 三反引号或三波浪线 + 语言名；自带行号与复制按钮；围栏内不做任何解析 |
| 图片 | `![说明](url)` → 灯箱；正文不显示说明文字，只在灯箱与无障碍文本中显示 |
| 分隔线 | `---` 独占一行、前后留空行 |
| 脚注 | GFM `[^1]` + `[^1]: 定义`，或旧式 `[1]` + `[1] 定义`（定义段独占段落） |
| 任务列表 | `- [x]` / `- [ ]`，渲染为只读复选框 |
| 链接 | 站外自动新窗口；裸 URL 自动转链接；站内链接用 `/blog` 形式 |

## 10. 可行性矩阵（嵌套）

| 外层 ＼ 内层 | 提示块 | 标注块 | 折叠面板 | 选项卡组 | 高亮 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 提示块 `:::note`（3 冒号） | — | ✅ | ✅ | ⚠️ 残留 `:::` | ✅ |
| 提示块 `::::note`（4 冒号） | — | ✅ | ✅ | ✅ | ✅ |
| 标注块 `> [!x]` | ✅ | ✅ | ✅（省略参数） | ❌ 不可用 | ✅ |
| 折叠面板 `:::collapse`（3 冒号） | ✅ | ✅ | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ |
| 折叠面板 `::::collapse`（4 冒号） | ✅ | ✅ | ✅ | ✅ | ✅ |
| 选项卡组 | — | ✅ | — | — | ✅ |
| 引用块 `>` | ✅ | ✅ | ✅ | ❌ | ✅ |

## 11. 交互 HTML（可选）

````markdown
```html-interactive id="counter-demo" title="计数器演示" height="360"
<button onclick="this.textContent = Number(this.textContent) + 1">0</button>
```
````

单块 ≤ 256 KiB，只允许内嵌资源（无 CDN / 远程 API / 原生桥接）；`id` 同文章唯一；
`title` 默认「交互演示」；`height` 200~960。普通 `html` 围栏只展示代码。
