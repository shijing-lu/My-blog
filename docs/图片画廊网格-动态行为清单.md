# 图片画廊网格 `:::grid` — 动态行为清单

> 配套文档：《图片画廊网格-功能文档.md》
> 本文逐条定义「触发条件 → 状态变化 → 视觉反馈 → 异常兜底 → 验证方式」，用于开发对齐与验收。

---

## 一、交互动态（用户操作触发的行为）

| # | 触发条件 | 状态变化 | 视觉反馈 | 异常兜底 |
|---|---|---|---|---|
| I1 | 鼠标悬停在网格内某张图片上 | 仅该图片进入 hover 态 | 图片**微幅放大**（缩放比例固定、过渡时长与站点其他动效一致） | 触屏设备不触发；`prefers-reduced-motion` 时禁用动效 |
| I2 | 点击网格内某张图片 | 打开灯箱浮层；记录「当前分组 + 当前序号」 | 浮层淡入，显示**未裁切原图** + 图注 + 计数（如 `2 / 3`）；页面滚动锁定 | 原图加载失败时在浮层内提示，仍可继续切换 |
| I3 | 灯箱内点「下一张」/ 按 `→` / 左滑 | 序号 +1，**在当前分组内**循环 | 图片与图注、计数同步更新 | 分组只有 1 张时，切换按钮置灰/隐藏 |
| I4 | 灯箱内点「上一张」/ 按 `←` / 右滑 | 序号 -1，在当前分组内循环 | 同上 | 同上 |
| I5 | 在灯箱内按 `Esc` / 点击遮罩 / 点关闭按钮 | 关闭浮层，恢复打开前的滚动位置 | 浮层淡出，焦点回到被点击的那张图片 | 浮层不存在时按键不产生副作用 |
| I6 | 浏览器窗口宽度跨过断点（拖拽/旋转屏幕） | 列数按响应式规则重算 | 网格重排，图片不拉伸、末行仍左对齐 | 重排不改变灯箱分组与序号 |

## 二、加载与呈现动态（非用户操作触发）

| # | 场景 | 期望行为 | 异常兜底 |
|---|---|---|---|
| I7 | 网格进入视口 | 图片**懒加载**，先占位后填充 | 懒加载失败则按 I8 处理 |
| I8 | 单张图片加载失败 | 该卡片保留占位与图注，布局不被撑破 | 其余图片正常显示；网格不塌陷 |
| I9 | 图片为透明背景（PNG/WebP） | 透明区域透出卡片主题背景色 | — |
| I10 | 原图比例与卡片比例差异极大（超长截图、极端宽幅） | `cover` 居中裁切；`contain` 完整显示并留白 | 不留白、不裁切的折中：作者显式设置接近原图比例的 `aspect` |
| I11 | 图注超长（多行） | 该行**所有**卡片高度一致，图注底部对齐 | 图注不与下方内容重叠 |
| I12 | 首屏与滚动中的布局偏移 | 卡片比例固定，**不产生明显布局跳动** | — |

## 三、分组隔离动态（本功能的核心约束）

| # | 场景 | 期望行为 |
|---|---|---|
| I13 | 文章内有多个 `:::grid` 容器 | 每个容器是**独立灯箱分组**；在某组内切换时**只能**看到该组图片 |
| I14 | 网格内图片 + 容器外普通图片混排 | 容器外图片**不进入**任何画廊分组；点击行为保持现状 |
| I15 | 同一篇文章的文档版与文章版 | 分组规则一致（同一渲染管线） |

## 四、边界与极端场景

| # | 场景 | 期望行为 |
|---|---|---|
| E1 | 容器内只有 1 张图 | 按 `columns` 布局渲染（单张占一列），灯箱可开、无切换 |
| E2 | 图片总数超过 20 张 | 正常成网格；灯箱切换不卡顿 |
| E3 | `columns="7"` / `columns="0"` / `columns="abc"` | 回退为 `3`，页面不报错 |
| E4 | `aspect="16:9"`（冒号写法）或 `aspect="abc"` | 回退为 `16/10`（是否兼容冒号写法见待确认项） |
| E5 | `fit="fill"` 等不支持的取值 | 回退为 `cover` |
| E6 | 容器未写闭合 `:::` | 降级为普通 Markdown，不残留标记、不 500 |
| E7 | 容器内混入段落文字或列表 | 图片仍成网格；非图片内容按普通 Markdown 渲染 |
| E8 | `title` 中含引号或中文标点 | 图注正确显示，不截断、不报错 |
| E9 | 文档页窄栏（< 768px） | 最多 2 列；< 480px 单列 |
| E10 | 写作台实时预览中编辑容器 | 预览随输入更新，不因半成品语法（如只写了开标记）导致预览崩溃 |

## 五、验收清单（必须实测的用例）

| # | 验收点 | 验收方式 |
|---|---|---|
| A1 | 无参数时默认三列、`16/10`、`cover` | 建一个最简容器，核对列数与卡片比例 |
| A2 | 同一网格内卡片尺寸统一、图注底部对齐 | 放「有图注 / 无图注 / 超长图注」三张，核对卡片等高 |
| A3 | `title` 优先于 `alt` 作为图注 | 同一张图分别只写 `alt`、同时写 `title`，对比显示 |
| A4 | 灯箱只在本容器内导航 | 文章内放两个网格，点第一组图片后按 `→`，确认不会跳到第二组 |
| A5 | 容器外普通图片不入组 | 容器外放一张普通图片，点容器内图片后 `→` 遍历，确认不出现该图 |
| A6 | 灯箱打开的是**未裁切**原图 | 用 `cover` 会裁掉边缘的图，比对网格内与灯箱内画面差异 |
| A7 | 断点折叠：≥768 按 columns，<768 ≤2 列，<480 单列 | 拖动窗口宽度逐段核对 |
| A8 | `contain` 不裁图、露出背景色 | 竖屏图放入 `16/9` + `contain`，核对完整性与留白 |
| A9 | 末行不拉伸 | `columns="2"` 放 3 张图，核对第三张宽度 = 前两张 |
| A10 | 参数非法回退 | 依次用 `columns="7"`、`aspect="abc"`、`fit="fill"` 构造，确认回退且无报错 |
| A11 | 极端比例不塌陷 | 超长截图放入 `16/9`，核对网格与灯箱表现 |
| A12 | 透明图片 | 透明 PNG 放入 `contain`，核对透出主题背景 |
| A13 | 无 JS 错误 | 全流程（打开/切换/关闭灯箱、拖窗口）控制台零错误 |
| A14 | 首页文章与文档文章都生效 | 同一段语法分别放进两类文章，核对渲染一致 |
| A15 | 不影响既有图片规范 | 容器外正文图片仍左对齐、无边框、无图注 |

## 六、实现落点（供开发参考，确认后细化）

| 环节 | 现有基础 | 需要改动 |
|---|---|---|
| 容器解析 | `src/lib/mdx.ts` 的 `:::` 容器机制 | 新增 `grid` 容器 → 网格结构 |
| 图片包裹 | `src/components/mdx/LightboxImage.tsx`（`figure[data-lightbox]`） | 网格内保留该结构（分组属性在其中注入） |
| 灯箱 | `src/scripts/lightbox.ts`（无依赖，全文档单组） | 增加「分组 + 计数 + 手势」；保持 `Esc`/`←→`/遮罩关闭 |
| 样式 | `src/styles/global.css`：`.prose img`、`.prose .lightbox-figure figcaption` | 新增网格样式；为网格内 figure 打开图注例外；覆盖 `height: auto` 以启用 `aspect-ratio` 裁切 |
