# Markdown 快捷键与即时预览：需求文档

## 1. 背景与目标

“设置 → 编辑器快捷键”已有录制、冲突提示、恢复默认与保存功能，但目前仅列出 16 个命令；部分显示的组合键在实际编辑器中没有执行预期操作。可视化编辑器对部分行内语法只隐藏标记，光标进入内容后仍不显示原始 Markdown。需要逐项校正快捷键和编辑行为，让已支持的语法可以可靠输入、直接编辑、完整保存。

语法范围以 [Markdown 语法手册](../Markdown-语法手册.md)、当前 MDX 渲染管线和编辑器已有扩展为准。这里的“覆盖所有语法”指每一种已支持语法均有明确的插入或编辑入口、预览行为和验收记录；不要求给每一种语法预设一个可能冲突的组合键，也不在本需求中新增阅读器不支持的 Obsidian 专属语法。

## 2. 用户需求

1. 在现有设置页面继续配置 Markdown 快捷键，沿用“格式、标题、块结构”等分组卡片、录制按钮、恢复默认、冲突提示与网站主题。可增加与现有样式一致的“插入与扩展”分组。每个列出的命令都必须真的执行，设置保存后重新打开编辑器生效。
2. 已有快捷键逐个核对 Windows 桌面端和网页端。若组合键被浏览器、操作系统或编辑器基础功能占用，设置页应说明限制，并给出可用的改绑路径；不能把不可用组合键呈现为已验证可用。
3. 对行内格式和静态预览块，光标在语法范围外时显示渲染效果；点击内容或以键盘把光标移入范围时显示该范围的 Markdown 源码；光标离开后恢复预览。选区、多光标、中文输入法输入时必须能正常编辑。
4. **表格保持预览态原地编辑**：点击单元格后仍显示表格，在单元格内输入，保留行列、对齐、Tab 导航、撤销重做等行为。点击表格不还原整块 Markdown 源码。
5. 任务复选框点击后直接切换状态。选项卡、折叠面板、画廊、多栏等已有可视化控件继续通过可见控件直接修改；点击其编辑区不触发整块源码切换。遇到无法安全解析或保真写回的内容时，显示可编辑源码。
6. 快捷键和预览行为应用于复用 `MarkdownEditor` 的写作台、文档文章原位编辑、日历日记、随心录等入口；入口自身的保存和权限规则保持一致。

## 3. 语法交互矩阵

| 已支持语法 | 离开后的显示 | 进入或点击后的行为 | 快捷操作要求 |
| --- | --- | --- | --- |
| 粗体、斜体、删除线、下划线、高亮、剧透、行内代码 | 隐藏标记并显示格式 | 在当前语法范围显示标记，编辑后恢复预览 | 包裹或取消格式；无选区能插入可输入的成对标记 |
| 标题、普通引用、普通列表 | 显示标题层级、引用与列表样式 | 光标在相应行或结构范围时可编辑前缀 | 标题 1–6、引用、无序、有序列表能切换 |
| 链接、图片、脚注 | 显示链接文字、图片或脚注外观 | 在相应静态范围提供源码编辑或明确的目标编辑入口 | 可插入链接、图片、脚注引用和定义 |
| 围栏代码、公式、静态提示块、分隔线 | 显示块级预览 | 进入内容或指定编辑入口后可以修改语法与内容 | 可插入对应模板，已有内容不能被空模板覆盖 |
| 表格 | 可编辑的表格 | 点击单元格直接编辑，保持表格外观 | 可插入表格；行列操作沿用可视菜单/控件 |
| 任务列表 | 列表与复选框 | 点击复选框直接勾选；正文仍可编辑 | 可插入或切换任务列表 |
| 选项卡、折叠面板、画廊、多栏 | 现有可视化组件 | 在组件中直接编辑文本、选项或结构 | 提供可配置的插入命令；细粒度操作可留在组件菜单 |
| 未闭合、嵌套异常或不支持无损转换的语法 | 源码 | 继续编辑源码，修复后再预览 | 快捷命令不得删改未知内容 |

矩阵为开发时逐项验收的基线。阅读器与编辑器对同一合法示例的最终显示应一致；复杂嵌套的具体编辑粒度在技术文档中约定。

## 4. 快捷键约束

- 默认键位优先沿用已有用户习惯。新增扩展命令若没有安全、无冲突的默认键位，设置页显示“未设置”，允许用户录制绑定；右键菜单或可视化控件仍提供操作入口。
- 录制时识别 Windows `Ctrl`、macOS `Cmd` 及修饰键组合，阻止纯修饰键、无效键和重复绑定；与编辑器保存、撤销、搜索等保留操作冲突时明确提示。
- 已保存的自定义绑定继续沿用原命令 ID。新增命令不能改变旧配置含义；删除或非法配置按现有回退规则处理。
- 命令对“有选区、无选区、多行选区”分别定义稳定结果。快捷键不应在表格单元格、弹窗输入框等子编辑控件中误触发父编辑器命令。

## 5. 验收情形

- 设置页每一项均能录制、保存、重新加载、恢复默认；冲突被阻止或明确提示。已有 16 个命令逐项可用，网页与桌面端差异说明准确。
- 光标进入粗体、斜体、下划线、删除线、代码、链接、高亮等预览型范围时，能看见和修改对应源码；离开后显示预览。
- 点击表格单元格后保持表格形态，编辑、移动焦点、调整行列、保存、撤销和重做均不丢内容；点击复选框能直接改变勾选状态。
- 选项卡、折叠面板、画廊、多栏在已有可视化区域内继续编辑；异常语法以源码保底。大文档滚动、跨块选区、多光标和输入法编辑不出现明显跳位或吞字。

## 6. 非目标

不重做整个阅读器，不增设项目尚未支持的 Markdown 方言，不将静态代码块、表格等强行统一为同一种点击行为。
