# 分栏右键入口与表格边缘加号：需求及开发计划

日期：2026-09-28

## 需求定义

### 右键创建分栏

文档文章编辑模式中，未选中文本时，右键菜单的“段落设置”二级列表增加“分栏”；悬浮后三级列表为“两栏”“三栏”。点击后在当前光标处插入与工具条相同的 `:::columns` 源码，并立即进入现有可视分栏编辑器。选中文本时继续只显示行内格式项，不混入块级分栏。

### 表格边缘加号

用户确认语义：**行的右侧加号新增列，列的下方加号新增行**。

- 鼠标移动到某行最右侧附近，显示小 `＋`；点击后在该行对应的位置新增一列。由于 Markdown 表格的列数必须统一，实际为整张表增加一列，其他行同列填入空单元格。焦点落在触发行与新列交叉的格子。
- 鼠标移动到某列底部附近，显示小 `＋`；点击后在表格底部增加一行，各列填入空单元格。焦点落在新行与触发列交叉的格子。
- 为“中间插入”留接口：现有表格右键菜单已有上下插行、左右插列。边缘加号先作为快速追加入口，避免在每个单元格旁堆叠多个控件。
- 小加号仅在表格悬浮或键盘焦点进入时出现；触控设备保持可点击，显示位置不遮挡文字。按钮提供 `aria-label`、键盘焦点与至少适当的点击热区。
- 点击前先冲刷单元格 300ms 防抖输入，复用 `applyTableOperation` 和 `requestTableFocus`，单次 CodeMirror 事务支持撤销；保留现有右键、Tab/Enter、排序和对齐行为。

## 技术现状

`cm-table.ts` 已有 `insertRow`、`insertColumn` 操作与源码序列化，边缘按钮只需调用现有 `runOperation`。表格 Widget 根据 Markdown 重建 DOM，保存了待恢复焦点坐标。`cm-context-menu.ts` 有三级悬浮菜单和统一 `addBlock()`；`markdown-columns.ts` 已有 `buildMarkdownColumns()`，可直接生成规范源码。

## 开发顺序

1. 先完成首次编辑可视化修复（见 08 文档），保证新插入分栏可立即呈现。
2. 右键菜单接入两栏/三栏，使用现有生成器，选区/代码块/表格内保持当前安全限制。
3. 表格 Widget 增加边缘操作层与鼠标定位，调用 `runOperation` 追加行列；处理尚未回写的单元格输入与重建后的焦点。
4. 加响应式、深色主题和键盘可访问样式；文档文章及已有写作台表格共用控件。
5. 进行类型检查和桌面构建；按用户既有要求，只覆盖 `release/portable` 固定便携目录。

## 验收标准

首次进入编辑即为可视组件；未选中正文处右键可创建两栏/三栏；表格右侧加号追加列、底部加号追加行，原单元格文字不丢失，新增格获得焦点；键盘与窄屏仍可操作。
