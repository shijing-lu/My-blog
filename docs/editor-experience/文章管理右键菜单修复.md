# 文档文章管理右键菜单修复

日期：2026-09-30。

## 症状与根因

- 文档详情脚本仅在模块首次执行时绑定目录右键菜单，而菜单会在 `astro:before-swap` 清理。Astro 客户端跳转复用脚本模块，返回文档详情不会再执行首次绑定，因此菜单偶发失效。
- 权限判断缓存首次页面 DOM 的值，与客户端切换后的页面不一致。
- “编辑文章、删除文章”原来只绑定左侧文章树，文章阅读区与编辑器外侧空白没有管理菜单入口。

## 修复

- 每次 `astro:page-load` 初始化当前文档菜单；WeakSet 避免重复绑定，离开页面时清理并移除绑定标记，兼容返回和复用 DOM。
- 权限、激活文章 ID、标题按当前 DOM 读取，不使用首次页面缓存。访客不安装管理菜单，执行命令时再次检查权限；API 继续执行原有服务端鉴权。
- 复用目录菜单样式与命令，在正文区提供当前文章的编辑、删除操作；编辑入口复用等待 React 水合的已有按钮逻辑。
- 编辑器文字、表格和扩展语法内部保持原 Markdown 菜单；外侧空白显示文章管理菜单。正在编辑时避免切换或删除文章造成未保存内容丢失。
