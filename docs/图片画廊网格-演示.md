# 图片画廊网格 `:::grid` — 演示与验收文档

> 配套文档：《图片画廊网格-功能文档.md》《图片画廊网格-动态行为清单.md》
> 用法：把下面的代码块直接粘进文章正文即可。**示例里的图片地址请替换为你自己的图片**
> （图片需先上传到图床或网盘并拿到直链）。

---

## 1. 最简语法（默认 3 列 / 16:10 / cover）

```markdown
:::grid

![图片一](/img/demo/01.webp)

![图片二](/img/demo/02.webp)

![图片三](/img/demo/03.webp)

:::
```

**书写要点**：每张图片**单独占一个段落**（图片之间必须空行）；容器内只放图片。

---

## 2. 全部参数

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `columns` | `1` ~ `6` | `3` | 桌面端列数；非法值回退为 3 |
| `aspect` | `16/9`、`3/4`、`1/1`… | `16/10` | 卡片宽高比（不是原图比例） |
| `fit` | `cover` \| `contain` | `cover` | `cover` 居中裁切填满；`contain` 完整显示并留白 |

```markdown
:::grid{columns="4" aspect="1/1" fit="cover"}

![图片一](/img/demo/01.webp)

![图片二](/img/demo/02.webp)

![图片三](/img/demo/03.webp)

![图片四](/img/demo/04.webp)

:::
```

> 也支持空格写法：`:::grid columns=4 aspect=1/1 fit=cover`

---

## 3. 按场景选参数

### 3.1 横屏截图 / 视频封面 → `16:9` 三列

```markdown
:::grid{columns="3" aspect="16/9"}
```

### 3.2 竖屏人像 / 手机截图 / 海报 → `3:4` 三列

```markdown
:::grid{columns="3" aspect="3/4"}
```

### 3.3 细节大图 → 单列

```markdown
:::grid{columns="1" aspect="16/9"}
```

### 3.4 缩略图索引 → 六列

```markdown
:::grid{columns="6" aspect="1/1"}
```

### 3.5 不可裁切的图表 / 长截图 → `contain`

```markdown
:::grid{columns="3" aspect="16/9" fit="contain"}
```

> `contain` 不裁切任何画面，代价是原图比例与卡片不一致时会露出主题背景色（设计预期）。

---

## 4. 图注规则

| 写法 | 图注 |
|---|---|
| `![无障碍文本](/img/a.webp)` | 显示「无障碍文本」 |
| `![无障碍文本](/img/a.webp "我的图注")` | 显示「我的图注」（**title 优先**） |

```markdown
:::grid{columns="2" aspect="3/4"}

![这是替代文本](/img/demo/portrait-1.webp)

![替代文本被覆盖](/img/demo/portrait-2.webp "这行才是图注")

:::
```

同行多条图注**底部对齐**：某条图注换行也不会让同行卡片高低不齐。

---

## 5. 灯箱（点击大图）

- 点击网格内任意图片 → 打开灯箱，显示**未裁切的完整原图**（`cover` 裁掉的边缘在这里能看到）
- `←` / `→` 或左右滑动切换，`Esc` 关闭，点击遮罩关闭
- 多图时底部显示计数（如 `2 / 3`）
- **导航范围限制在当前网格内**：另一个网格、以及容器外的普通图片，都不会被串进来

## 6. 验收清单（视觉 + 交互逐条核对）

| # | 核对项 | 通过标准 |
|---|---|---|
| A1 | 默认三列 | 不写参数时一行 3 张，卡片比例 16:10 |
| A2 | 卡片等高等宽 | 同行卡片尺寸一致，无参差 |
| A3 | 图注底部对齐 | 长图注换行时，同行卡片仍等高、图注底边齐平 |
| A4 | `title` 优先于 `alt` | 同时写 alt 与 title 时显示 title |
| A5 | `contain` 不裁切 | 竖图放进 `16/9` 卡片后完整可见、两侧留白 |
| A6 | 末行不拉伸 | `columns="2"` 放 3 张时，第 3 张宽度与前两张相同 |
| A7 | 响应式折叠 | ≥768px 按 `columns`；<768px 最多 2 列；<480px 单列 |
| A8 | 悬停微缩放 | 鼠标移入图片轻微放大，移出复原 |
| A9 | 灯箱看原图 | 网格内被裁切的图片，灯箱里能看到完整画面 |
| A10 | 分组隔离 | 两个网格互不串图；容器外普通图片不进任何分组 |
| A11 | 非法参数回退 | 写 `columns="9"` / `aspect="abc"` / `fit="fill"` 均回退默认且不报错 |
| A12 | 极端比例不塌 | 超长截图放入 `16/9` 后网格与灯箱都正常 |
| A13 | 透明图 | 透明 PNG 在 `contain` 下透出主题背景色 |
| A14 | 两类文章都生效 | 首页文章与文档文章正文渲染一致 |
| A15 | 既有规范不破 | 容器外的正文图片仍左对齐、无边框、不显示图注 |
