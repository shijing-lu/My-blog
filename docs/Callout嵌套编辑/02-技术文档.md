# Callout 嵌套编辑技术方案

## 原因

原右键菜单通过行首 `>` 禁用了引用中的块插入，并且选中文本后只显示行内格式。编辑预览对 Callout 使用逐行装饰，内部代码与分栏没有经过独立的 Markdown 解析。阅读态分栏的合法位置校验只扫描顶层源码，遗漏了引用内部的分栏。

## 结构

1. 使用保守的 Callout 扫描器，跳过代码示例，提取标题与连续显式引用正文；每次只去掉一层引用前缀。
2. Callout 由块级组件承载，正文创建子 CodeMirror 编辑器。子编辑器递归复用父编辑器的预览、分栏、扩展容器、快捷键及右键菜单配置。
3. 子编辑器内容变化后同步回父文档，将每一行重新加上 `> `。更新已有组件，避免每次输入重新挂载并丢失焦点。
4. 编辑目标沿父子链定位；撤销重做由根文档管理，保存继续触发原有保存入口。内部表格沿用现有单元格编辑。
5. 根预览跳过由 Callout 组件管理的范围，避免重复渲染。分栏和其他可视化容器内部也使用同一递归编辑配置。
6. 阅读分栏保留严格的结构校验，并增加引用剥离后的原位置映射，使引用内合法分栏能被 MDX 插件识别。

## 数据与安全

持久化格式仍为 Markdown，不增加数据库或接口。所有插入操作校验菜单打开时的文档快照；过期菜单不能写入变化后的文档。代码块包裹使用比选中文本已有反引号更长的围栏。
