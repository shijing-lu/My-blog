## 操作确认清单

- 空 Callout 右键创建代码块、双栏、表格、选项卡与折叠面板。
- 多行代码选中后包裹；原文包含反引号时保存后不会提前结束代码块。
- Callout → 分栏 → Callout 多层编辑及撤销、重做；保存并重新打开内容一致。
- 表格单元格与分栏正文直接编辑；阅读态嵌套结构正确显示。
- 引用或代码示例不会被错误截断；标题及正文输入不会丢焦点。
