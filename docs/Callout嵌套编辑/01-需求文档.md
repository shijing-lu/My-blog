# Callout 嵌套编辑需求

## 目标

Callout 内外使用同一套 Markdown 编辑能力。Callout 正文可以包含代码块、表格、双栏/三栏、选项卡、折叠面板、图片画廊、公式和进一步嵌套的 Callout。阅读继续使用项目的 MDX 渲染管线。

## 交互

- 在 Callout 正文内未选中文字时右键，可以通过段落设置插入现有块级语法，包括代码块和分栏。
- 选中文字后右键显示“添加代码块”，将选中的单行或多行原文包进代码围栏。没有选中内容时创建空代码块。
- 表格、分栏及其他已有可视化容器继续在预览形态内直接编辑；点击它们不会被统一还原为源码。
- Callout 保持现有主题配色；标题可编辑，正文使用与外部一致的预览和源码切换规则。
- 保存时为嵌套正文的每一行保留引用前缀，包括空行；再次打开时结构保持一致。撤销、重做、快捷键和图片粘贴应作用于当前编辑的正文。

## 边界

代码块内的 Markdown 示例不能被识别成真实嵌套容器。列表、表格单元格及代码块内部继续保留各自编辑行为，禁止直接插入破坏当前结构的块级容器。选中文字含代码围栏时，外层围栏应自动加长，避免提前闭合。

## 完成标准

Callout 内外的右键入口一致；选中文本可包裹为代码块；Callout 内的代码、表格、分栏和嵌套扩展能够编辑、保存和阅读。既有文章内容及非 Callout 编辑行为保持兼容。
