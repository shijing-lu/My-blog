# 网盘对接部署指南（AList 中转层 + 蓝奏云）

> 本文档为「网盘对接」功能的部署手册，所有步骤与参数均在 AList v3.64.0 + 本地环境实测通过。
> 网站侧代码已就绪，**只需完成本文档的部署与配置，功能即生效**。

---

## 一、架构与数据流

```
                     ┌────────── 你的 Windows 本机 ──────────┐
                     │  AList (127.0.0.1:5244)                │
                     │   ├─ 存储A 蓝奏云（lanzou 驱动）        │
                     │   └─ 存储B Local（暂存区 /local）       │
                     │  cloudflared ──出站──► Cloudflare Edge │
                     └────────────────────────────────────────┘
                                  ▲ 公网 HTTPS  alist.<域名>
   ┌──────────────────────────────┼──────────────────────────────┐
   │                              │                              │
[浏览器]──①小文件(≤4MB)经过本站函数──►[Vercel]──► AList ──► 蓝奏云   │
   │    ──②大文件 PUT 直传────────────────────────► AList ──► 蓝奏云   │
   │    ──③下载：AList 直链（302）────────────────► AList/蓝奏 CDN    │
```

- **①小文件**：唯一经过 Vercel 函数的路径（受 4.5MB 请求体上限约束，故阈值默认 4MB）
- **②大文件**：浏览器带**受限子账号 token** 直传 AList 暂存区 → 服务端用管理员 token 跨存储复制到蓝奏云（绕开 AList 蓝奏驱动的 120s 上传超时）
- **③下载**：本站只返回直链 URL，不转发字节

## 二、部署 AList（Windows）

### 方式 A：直接运行二进制（推荐，无需 Docker）

1. 下载最新版（**必须 ≥ 3.57.0**，旧版有路径穿越漏洞 CVE-2026-25161）：
   https://github.com/AlistGo/alist/releases → `alist-windows-amd64.zip`
2. 解压到一个**固定目录**（建议 `C:\alist`，不要放在临时目录），得到 `alist.exe`
3. 设置管理员密码（在 `C:\alist` 下执行）：
   ```bat
   alist.exe admin set 你的强密码
   ```
4. 启动服务：
   ```bat
   alist.exe server
   ```
   默认监听 `0.0.0.0:5244`，本机访问 http://127.0.0.1:5244

### 方式 B：Docker

```bat
docker run -d --name alist --restart=always -p 5244:5244 -v alist-data:/opt/alist/data xhofe/alist:latest
docker exec -it alist ./alist admin set 你的强密码
```

### 设为开机自启（必做）

本机常驻是本功能的前提，否则线上网盘功能不可用：

- **方式 A**：用「任务计划程序」创建「计算机启动时」触发的任务，程序填 `C:\alist\alist.exe`，参数 `server`，起始位置 `C:\alist`
- **方式 B**：`--restart=always` 已覆盖（需 Docker Desktop 开机自启）

## 三、在 AList 后台配置存储

访问 http://127.0.0.1:5244 → 用 admin 登录 → 「存储」→「添加」。

### 存储 1：蓝奏云（目标网盘）

| 字段 | 值 |
| --- | --- |
| 驱动 | `蓝奏云`（lanzou） |
| 挂载路径 | `/蓝奏云`（可自定义） |
| 类型 | `账号密码`（account） |
| 账号 / 密码 | 你的蓝奏云账号（建议用小号） |
| 根文件夹 ID | `-1`（默认根目录） |

⚠️ 若使用蓝奏云**优享版**，需把驱动里的 BaseUrl 改为优享版域名（否则列表为空）。

### 存储 2：本地暂存区（大文件中转必需）

| 字段 | 值 |
| --- | --- |
| 驱动 | `本地存储`（Local） |
| 挂载路径 | `/local` |
| 根文件夹路径 | 任意本地目录，如 `D:\alist-storage` |

创建后，在 AList 里进入 `/local` 新建子目录 `_netdisk_staging`（即网站的暂存目录）。

## 四、创建受限子账号（大文件直传的安全核心）

大文件由浏览器直传 AList，因此需要一份下发给浏览器的凭证。**绝不能下发管理员 token**，
必须建一个只能写暂存目录的受限账号：

1. AList 后台 →「用户」→「角色」→ 新建角色
   - 名称：`blog-uploader`
   - **权限作用域**：路径 `/local/_netdisk_staging`，权限只勾 **「上传/新建文件夹」** 与 **「路径限制」**
     （源码权限位：mkdir+upload = `8`，路径限制 = `16384`，合计 **`16392`**）
     > 「路径限制」**必须勾选**，否则路径作用域不生效。
2. 「用户」→ 新建用户
   - 用户名：`blog-uploader`，密码：自己设一个强密码
   - 角色：`blog-uploader`
   - **基础路径（base_path）必须留空或填 `/`**
     > ⚠️ 实测坑：若 base_path 填 `/local/_netdisk_staging`，AList 会把所有请求路径当作**相对路径**解析，
     浏览器直传会报 `object not found`。路径限制靠「权限作用域」实现，不靠 base_path。

**验证方法**：用该子账号登录 AList（新开无痕窗口），应能进入 `/local/_netdisk_staging` 但**看不到也进不去其他目录**。

## 五、内网穿透（让线上网站与本机 AList 互通）

网站部署在 Vercel（公网），AList 在本机（内网），必须有一条公网入口。

### Cloudflare Tunnel（推荐）

1. 前提：域名 NS 托管在 Cloudflare（如 `byqx-blog.online` 不在 CF，需先迁移 NS，或用子域挂到 CF）
2. 安装 cloudflared：https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/downloads/
3. 登录并创建隧道：
   ```bat
   cloudflared tunnel login
   cloudflared tunnel create alist
   cloudflared tunnel route dns alist alist.你的域名
   ```
4. 配置 `config.yml`（放在 `%USERPROFILE%\.cloudflared\`）：
   ```yaml
   tunnel: alist
   credentials-file: C:\Users\<你>\.cloudflared\<tunnel-id>.json
   ingress:
     - hostname: alist.你的域名
       service: http://127.0.0.1:5244
     - service: http_status:404
   ```
5. 注册为 Windows 服务（开机自启、后台常驻）：
   ```bat
   cloudflared service install
   ```
6. 验证：浏览器打开 `https://alist.你的域名` 能进 AList 登录页

**限制**：Cloudflare 免费版单请求体上限 **100MB**（与蓝奏云标准版单文件上限一致，不构成额外瓶颈）；
免费版 ToS 不鼓励大文件/视频分发，超大文件建议走其他方案。

## 六、收紧 CORS（安全必做）

AList 默认 `allow_origins: ["*"]`（便于开发，但生产应收紧）。

编辑 `data/config.json` 的 `cors` 段：

```json
"cors": {
  "allow_origins": ["https://www.byqx-blog.online", "http://localhost:4321"],
  "allow_methods": ["GET", "POST", "PUT", "HEAD", "OPTIONS"],
  "allow_headers": ["Authorization", "Content-Type", "File-Path", "As-Task", "Overwrite"]
}
```

改完重启 AList。⚠️ 不要保留 `*`（浏览器直传会带凭证，通配来源等于放开任意站点）。

## 七、网站侧配置

后台 →「设置」→「网盘对接」（或直接访问 `/admin/settings/netdisk`）：

| 字段 | 填写 |
| --- | --- |
| 启用网盘对接 | ✅ 勾选 |
| 中转服务地址 | 生产填 `https://alist.你的域名`；本地开发填 `http://127.0.0.1:5244` |
| 管理员账号 / 密码 | AList 的 admin 账号（服务端调用用） |
| 直传子账号 / 密码 | 第四步建的 `blog-uploader` |
| 管理页根目录 | `/`（或你想在管理页看到的起始目录，如 `/蓝奏云`） |
| 上传落点目录 | 蓝奏云里的目标目录，如 `/蓝奏云/blog/uploads` |
| 大文件暂存目录 | `/local/_netdisk_staging` |
| 分流阈值 | `4`（MB，超过走浏览器直传） |
| 单文件上限 | `100`（MB，蓝奏云标准版；优享版可填 500） |

填完点 **「测试连接」**，应看到 5 步全绿：
```
✓ 登录：管理员登录成功
✓ 身份：当前账号：admin
✓ 管理目录：目录「…」可访问（N 项）
✓ 暂存目录：暂存目录「…」可用
✓ 直传子账号：子账号 blog-uploader 登录成功
```

## 八、使用

- **管理页**：后台顶部导航「网盘」，或直接访问 `/admin/netdisk`
  - 浏览目录（面包屑/分页）、上传（拖选多文件，自动按大小分流）、下载（直链）、删除、新建文件夹
- **接入更多网盘**：在 AList 后台「存储」里再加一个驱动（百度网盘/123云盘/坚果云/OneDrive…），
  网站侧**零改动**——管理页会自动看到新挂载点。这就是本方案选 AList 的核心价值。

## 九、限制与注意事项

| 项 | 说明 |
| --- | --- |
| 本机必须常驻 | AList + cloudflared 都要开机自启；关机/休眠/断网 = 线上网盘功能不可用（博客其他功能不受影响） |
| 蓝奏云单文件 | 标准版 100MB，优享版 500MB |
| 蓝奏云驱动超时 | 120s 硬编码 → 大文件必须走「暂存 + 复制」（系统已自动如此处理） |
| 蓝奏云凭证 | account 模式自动续期；若登录失效，「测试连接」会在「管理目录」一步报错，到 AList 后台重新登录即可 |
| CF 隧道 | 单请求 100MB；免费版 ToS 限制大文件分发 |
| 家庭带宽 | 直链下载走厂商 CDN 不吃本机带宽；若驱动回落为 AList 代理流式，则占用家庭上行 |
| AList 版本 | 必须 ≥ 3.57.0（旧版子账号路径限制可被 `../` 绕过） |
| AList 后台安全 | 建议用 Cloudflare Access 保护后台路径；强密码 + 关访客 + 指定 `jwt_secret` |
| 许可证 | AList 为 AGPL-3.0：仅调用其 API、不修改源码，自用不触发分发义务 |

## 十、故障排查

| 现象 | 原因与处理 |
| --- | --- |
| 「无法连接中转服务」 | AList 未运行 / 隧道断开 / 地址填错 → 本机访问 `http://127.0.0.1:5244` 确认 |
| 「中转服务拒绝了请求：账号或密码错误」 | AList 账号密码不对 |
| 「目录不可访问」 | 该挂载路径不存在，或厂商网盘登录态失效（去 AList 后台重登） |
| 大文件报「直传不可用」 | 未配置受限子账号（设置页 uploader 字段） |
| 直传报 `object not found` | 子账号 base_path 不是 `/`（见第四节警告） |
| 直传报 CORS 错误 | `config.json` 的 `cors.allow_origins` 未包含网站域名 |
| 转存成功但暂存文件残留 | 复制任务耗时超过 25s（大文件），可稍后在 AList 里手动删除或重试 |
