# 正文标题折叠验证记录

日期：2026-10-04。

## 实现结果

文档和文章的阅读及就地编辑均支持正文 H1–H6 折叠。原标题和 id 保留，章节边界按同容器同级或更高级标题计算；页面名称和目录折叠继续使用原有逻辑。

阅读折叠采用显示层章节包装；编辑折叠采用 CodeMirror 状态范围。提示块、分栏的子编辑器也支持标题折叠，并在虚拟滚动或上级折叠重建时恢复状态。目录跳转展开对应章节及子编辑器。折叠状态不写 Markdown、API 或数据库。

## 浏览器验收

使用 Edge 的实际浏览器引擎验证：

1. `/blog/[slug]` 公开阅读、`/edit/[id]` 文章阅读和 `/doc/[id]` 文档阅读：H1–H6、Setext、嵌套状态、引用容器边界、目录展开、键盘按钮、320/390px 无页面横向溢出、打印显示被折叠正文。
2. 文档页内文章切换、回到原文后的状态恢复、大文档延迟渲染：正确重新接入折叠，控件无重复。
3. 两类页面的编辑：各级标题折叠、键盘展开、父子状态和目录展开通过；折叠后等待超过自动保存周期，没有产生 PATCH 请求。
4. 折叠子章节后编辑可见前言：自动保存的全文与原文加前缀逐字符一致，隐藏正文仍完整；退出编辑后正文刷新和折叠控件恢复。
5. 提示块及双栏正文：子编辑器折叠及目录展开通过；收起并重开上级章节后，提示块子标题维持折叠；原始正文不变。
6. 真实长文副本：186,293 个源文字符、128 个可折叠标题，阅读增强和可视化编辑折叠通过，标题装饰仍存在，没有浏览器运行错误。
