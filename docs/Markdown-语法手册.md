# My-Blog Markdown 语法手册

> 适用范围：博客文章（`/blog/*`）、文档系统（`/doc/*`）、写作台实时预览。
> 三者共用同一套渲染管线，源码在预览与阅读页的表现一致。

---

## 0. 通用规则

### 0.1 渲染管线

源码依次经过：GFM 基础语法 → 数学公式 → 指令容器（`:::`）→ 自定义扩展（callout / 折叠 / 选项卡 / 高亮）→ KaTeX、代码高亮、标题锚点。

写作时只需记住一条：**行首独占一行**是容器类语法的唯一识别方式。

### 0.2 六条铁律

| # | 规则 | 违反后果 |
| --- | --- | --- |
| 1 | `:::` 开标记**必须独占一行**（行首 ≤3 空格），且成对闭合 | 整块降级为普通文本，`:::` `@tab` 等原样显示 |
| 2 | 容器**嵌套**时外层用 4 个冒号 `::::`，内层用 3 个 `:::` | 页面多出一行 `:::`（无声、不报错） |
| 3 | 块级语法之间留**空行** | 相邻块被合并解析 |
| 4 | 正文里的花括号写 `\{` `\}` | 整篇渲染失败（报 acorn 或 `xxx is not defined`） |
| 5 | 不写 HTML 注释 `<!-- -->`，不写带 `style` 的内联 HTML | 渲染失败 |
| 6 | 正文不使用 `#` 一级标题 | 与文章标题重复；目录只收 h2 / h3 / h4 |

### 0.3 转义对照

| 想显示 | 写法 |
| --- | --- |
| `{` `}` | `\{` `\}` |
| `==` | `\=\=` |
| `*` `_` `[` `]` `` ` `` | `\*` `\_` `\[` `\]` `` \` `` |
| `$` | `\$` |
| `\` | `\\` |

## 1. 基础语法（GFM）

### 1.1 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

- **用途**：划分结构。左侧目录（TOC）自动采集 **h2 / h3 / h4**，h1 与 h5、h6 不进目录。
- **锚点**：由标题文本自动生成，中文原样保留（如 `## 谁是我们的朋友？` → `#谁是我们的朋友`）。
  标题内的行内代码、强调、高亮会被剥掉后再生成锚点。
- **不支持**自定义锚点（`## 标题 {#my-id}` 会导致渲染失败）。
- 末尾的 `#` 可省略；也可用下划线式（`标题` 换行后 `===`），但不推荐。

### 1.2 强调与删除线

```markdown
**加粗**　*斜体*　***加粗斜体***　~~删除线~~
```

支持任意嵌套组合。强调标记内的内容同样支持公式、代码、高亮。

### 1.3 列表

```markdown
- 无序项
- 无序项
  - 嵌套项（缩进 2 空格）

1. 有序项
2. 有序项

- [x] 已完成任务
- [ ] 未完成任务
```

- 嵌套请统一用 **2 空格**缩进；混用 Tab 与空格会导致层级错乱。
- 任务列表渲染为真实复选框（只读，不可点击）。

### 1.4 引用

```markdown
> 普通引用。
> 可以跨多行。
```

普通引用保持原始样式。**若首行以 `[!类型]` 开头，会被识别为标注块**——详见 [2.2 标注块](#22-标注块-callout)。

### 1.5 代码

````markdown
行内代码：`pnpm install`

```ts
const a: number = 1;
```
````

- **用途**：行内代码用于术语、命令、文件名；围栏代码块用于代码。
- 围栏用三个反引号或三个波浪线，可跟语言名以获得语法高亮（`ts` `js` `bash` `json` `astro` `css` `md` 等）。
- 渲染后自带**行号**与**复制按钮**。
- 围栏代码块内的所有内容**不做任何语法解析**——`:::`、`@tab`、`==`、`{}` 都会原样显示，是展示语法示例的正确方式。

### 1.6 表格

```markdown
| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| A | B | C |
```

- **用途**：并列比较、参数说明。
- 对齐由分隔行的冒号决定；省略即默认左对齐。
- 单元格内可写行内代码、强调、链接、高亮，以及**行内公式** `$...$`。
- 单元格内公式里的 `|`（绝对值）会被自动处理为 `\vert`，无需手动规避。

### 1.7 链接与图片

```markdown
[链接文字](https://example.com)
[站内链接](/blog)
![图片说明](/api/images/xxxx)
```

- **链接**：站外链接自动新窗口打开并加 `rel` 安全属性；裸 URL（`https://example.com`）自动转为链接，紧跟全角标点也不会被吞。
- **图片**：渲染为**灯箱**（点击放大）。正文中图片**左对齐、按原始尺寸显示**（超出列宽才等比缩小），无边框、无图注、无任何装饰包裹。
- `![...]` 方括号里的文字是**说明文字**：在正文中**不显示**，但**点击放大后会在灯箱中显示**，同时作为无障碍替代文本。请填写有意义的描述。
- 图片地址请使用站内图片地址或已配置的图床地址，不要粘贴 base64。

### 1.8 分隔线

```markdown
---
```

独占一行，用于章节间的视觉分隔。前后建议留空行，避免被误判为标题下划线。

### 1.9 脚注

两种写法并存，任选其一。

```markdown
GFM 标准写法：正文引用[^1]。
[^1]: 注脚内容。

旧式数字写法：正文引用[1]，另一处[2]。

[1] 第一条注脚。
[2] 第二条注脚。
```

- 渲染后在文末生成脚注区，支持「点击编号跳到底部、点 ↩ 跳回原处」的双向跳转。
- ⚠️ **写了引用就必须写对应定义**，否则编号无法正确关联。
- 脚注定义段必须以 `[N]` + **一个空格** + 内容开头，且独占一个段落。

### 1.10 数学公式

```markdown
行内公式：质能方程 $E = mc^2$。

块级公式（$$ 必须独占一行）：
$$
\begin{cases}
a & x > 0 \\
b & x < 0
\end{cases}
$$
```

- **用途**：行内公式随文字排版；块级公式独占居中显示。
- 语法为 LaTeX，KaTeX 渲染。
- ⚠️ **块级公式的 `$$` 必须各自独占一行**。写成 `$$x^2$$` 一行，或把内容与 `$$` 写在同一行，都会导致公式渲染异常。
- 未识别为公式的写法会显示为红字错误——**调整 `$$` 的换行位置**即可。
- ⚠️⚠️ **每个 `\begin{…}` 都必须落在 `$…$` 或 `$$…$$` 内**。漏掉定界符时有两种表现：
  - 花括号内是**标识符**（如 `{bmatrix}`、`{cases}`）→ **整篇渲染失败**，报 `ReferenceError: bmatrix is not defined`
  - 花括号内是**合法 JS**（如 `\frac{1}{2}` 的 `{1}`/`{2}`）→ **静默错乱**，不报错但公式显示残缺

  **这是本项目最高频的公式类故障**：`\begin{…}` 裸写既不一定会报错，又很难用肉眼发现。交付前请全局搜 `\begin{` 逐个确认。
  行内代码（`` `\begin{bmatrix}…` ``）里的 LaTeX 会被原样输出成字面文本——不报错，但也**不是公式**；要渲染就必须写 `$…$`。
- 公式可出现在段落、列表、引用块、表格单元格、标注块与折叠面板内。
- 若要显示字面美元符号，写 `\$`。

## 2. 扩展语法

### 2.1 提示块（Admonition）

**用途**：页面级的醒目提示条，用于强调注意事项、补充说明。

**语法**

```markdown
:::note
这是一段备注内容。

支持**完整的块级 Markdown**：列表、代码、公式、表格。
:::
```

**五种类型**

| 写法 | 默认标题 | 图标 | 定位 |
| --- | --- | --- | --- |
| `:::note` | 备注 | i | 中性补充 |
| `:::info` | 信息 | ℹ | 背景信息 |
| `:::tip` | 提示 | ✦ | 技巧、建议 |
| `:::warning` | 注意 | ! | 需要留意 |
| `:::danger` | 危险 | ⚠ | 严重风险、破坏性操作 |

**正确用法**

- 开标记行写 `:::类型`，**后面不跟任何内容**；结尾用单独一行 `:::` 闭合。
- 标题只能用默认文案，**不支持自定义标题**：
  `:::warning 注意安全` 会让整块失效（变成普通文本）。

**行内形式**

```markdown
正文中间的 :note[行内备注] 效果。
```

用**单个冒号**，尖括号换成方括号，适合正文中一句话级别的提示。

**嵌套**：提示块内可嵌套引用块、标注块、折叠面板。
需要**内嵌选项卡组**时，外层必须写成 **4 个冒号** `::::note`（否则页面会多出一行 `:::`，见 [3. 嵌套与组合](#3-嵌套与组合)）。

### 2.2 标注块（Callout）

**用途**：Obsidian 风格的引用式标注，**支持折叠**，是「题目 / 答案」「结论 / 推导」「拓展知识」类内容的首选。

**语法**

```markdown
> [!note] 自定义标题
> 正文内容。

> [!example]- 默认收起的标题
> 展开后才可见的正文。

> [!tip]+ 默认展开且可折叠
> 正文。
```

**折叠符号**

| 符号 | 含义 |
| --- | --- |
| 无 | 普通标注块，不折叠 |
| `-` | **默认收起**，仅标题行可见 |
| `+` | 默认展开，但可点击收起 |

**可用类型与别名**

| 规范类型 | 默认标题 | 别名（同样可用） |
| --- | --- | --- |
| `note` | 笔记 | — |
| `info` | 信息 | `todo` `abstract` `summary` `tldr` |
| `tip` | 提示 | `hint` `important` |
| `success` | 成功 | `check` `done` |
| `question` | 问题 | `help` `faq` |
| `warning` | 警告 | `caution` `attention` |
| `failure` | 失败 | `fail` `missing` |
| `danger` | 危险 | `error` |
| `bug` | 缺陷 | — |
| `example` | 示例 | — |
| `quote` | 引用 | `cite` |

**正确用法**

- 必须写成**引用块**：每行以 `> ` 开头，`[!类型]` 写在引用块首行。
- 类型名与 `-` `+` 之间**不能有空格**：`[!note]-` ✓ ／ `[!note] -` ✗。
  ⚠️ `[! note]`（`[!` 后有空格）**不会被识别**，会原样显示。
- 标题写在 `[!类型]` 之后的同一行，支持行内 Markdown（加粗、行内代码、公式、高亮）。
  紧贴写法 `> [!example]【例 5.1】题干` 与空格写法 `> [!example] 【例 5.1】题干` 均可。
- **标题不能在源文件里换行**：标题取的是引用块**首段的第一行**，源码里换行会让后面的内容掉进折叠正文。
  想在标题内换行（例如把 A/B/C/D 选项分行排版），用 **`<br />`**：

  ```markdown
  > [!tip]- 【题目】齐次方程组 $Ax=0$ 的系数矩阵化为阶梯形是 $…$<br />则自由变量**不能**取成（　）<br />A. $x_2, x_3$　B. $x_2, x_5$
  ```

  - **必须自闭合**：`<br />` / `<br/>` ✅；写成 `<br>` 会报 `Expected a closing tag for <br>`，**整篇渲染失败**。
  - `<br />` 在**折叠状态**下同样生效，标题照样显示多行。
  - 不想用 HTML 的替代方案：题目用**不可折叠**的 callout（`> [!tip]` 不带 `-`）分段写题干与选项，解析另起一个 `> [!note]-` 可折叠 callout。
- 正文可以是多段、列表、公式块、表格。
- **折叠语义**：折叠时**仅标题行可见**，其余内容整体隐藏。因此「题干 + 解析」场景要把**题干写进标题行**。
- 不支持自定义锚点；不写标题时使用该类型的默认文案。

### 2.3 折叠面板（Collapse）

**用途**：一组可展开 / 收起的面板，适合「问答清单」「拓展知识」「分层解析」。与标注块的区别：折叠面板是**一组多个**面板，支持手风琴互斥。

**语法**

```markdown
:::collapse
- 面板标题一

  面板正文（完整块级 Markdown）。

- :+ 默认展开的面板标题

  正文。

- :- 强制折叠的面板标题

  正文。
:::
```

**参数**（写在开标记行的 `collapse` 之后，空格分隔）

| 参数 | 作用 |
| --- | --- |
| （无） | 全部默认折叠，仅 `:+` 标记项展开 |
| `expand` | 整组默认展开 |
| `accordion` | 整组**互斥**（手风琴）：展开一项自动收起其他项 |
| `accordion expand` | 互斥且默认展开 |

**单项标记**（写在标题最前）

| 标记 | 作用 |
| --- | --- |
| `:+` | 该项初始展开 |
| `:-` | 该项强制折叠（整组 `expand` 时用来压回折叠） |

优先级：单项 `:-` > 单项 `:+` > 整组 `expand` > 默认折叠。

⚠️ **参数与单项标记只在段落层级有效**（或外层写成 `::::collapse`）。
写进标注块（`> :::collapse`）时**必须全部省略**：

- `> :::collapse expand` → 开标记行的改写只认行首 `:::`，`> ` 前缀会让它失配 → **整行降级，`:::collapse expand` 裸泄漏到页面上**
- `> - :+ 标题` → `:` 被 remark-directive 当作 textDirective → **标记失效**，并在页面上残留一个空 `<div></div>`
- `> :::collapse`（无参数、无标记）→ ✅ 正常

**正确用法**

- 容器内必须**有且仅有一个无序列表**（`-` 开头）；每个列表项 = 一个面板。
- **有序列表（`1.`）不被识别**，必须用 `-`。
- 每个面板内：**标题 = 列表项的首行**；标题后**空一行**再写正文，正文支持完整块级 Markdown。
- 正文需要缩进 **2 空格**（列表项续行规则）。
- 面板内可嵌套标注块、引用块、公式。
- ⚠️ **闭合围栏 `:::` 必须独占一行**。写成「最后一句正文。 `:::`」这种同行形态时，`:::` 不会被识别为闭合——面板虽然照样渲染出来，但页面上会**多出一行字面的 `:::`**。
- 需要**在面板内嵌选项卡组**时，外层必须写成 **4 个冒号** `::::collapse`（否则页面会多出一行 `:::`，见 [3. 嵌套与组合](#3-嵌套与组合)）。
- 可嵌套在普通引用块内（`> :::collapse`，每行带 `> ` 前缀，且省略参数与标记）。

### 2.4 选项卡组（Tabs）

**用途**：把并列的多种方案 / 多个步骤折叠到同一区域，通过按钮切换。适合「方案 A / B / C」「第 1 / 2 / 3 步」。

**语法**

```markdown
:::tabs#group-id

@tab 第一个标签

第一个标签的内容。

@tab:active 第二个标签

第二个标签的内容（初始激活）。

:::
```

**组成部分**

| 写法 | 含义 |
| --- | --- |
| `:::tabs` | 不带稳定标识的选项卡组 |
| `:::tabs#group-id` | 带**稳定标识**：同页多个组标识相同则选中状态互相同步 |
| `@tab 标签` | 开启一个选项卡 |
| `@tab:active 标签` | 开启并指定为初始激活项（同组只认第一个） |
| `@tab 标签#anchor` | 标签尾部的 `#锚点` 是该选项卡的稳定 ID，用于跨组对齐；**不会**显示在按钮文字上 |

**正确用法**

- 开标记行必须**独占一行**：
  `:::tabs#summary` ✓ ／ `:::tabs#summary @tab` ✗（后面多写任何内容都会让整块失效）。
- 开标记行尾多余空格**无影响**。
- 组内必须有 **≥2 个 `@tab`**；只有 1 个或不闭合都会降级为普通文本。
- 必须用**空行**分隔 `@tab` 标签行与其正文；正文缩进可选。
- 标签支持行内 Markdown（`**加粗**`、`` `代码` ``、`$公式$`）。
- 末端用单独一行 `:::` 闭合。
- 可嵌套在**折叠面板**内（正文缩进 2 空格），但**外层必须写成 4 个冒号** `::::collapse`。
- ⚠️ **不能写在标注块（`> [!type]`）内部**——引用块的 `> ` 前缀会让选项卡语法整体失效、原样泄漏。需要「标注块 + 选项卡」时，把选项卡**移到标注块之外**，或改用 `::::collapse` 当外层。
- ⚠️ 嵌在 3 个冒号的 `:::note` / `:::collapse` 内时，选项卡自身能渲染，但外层容器的闭合行会残留成页面上一行 `:::`。**外层加长到 4 个冒号即可消除。**

### 2.5 荧光高亮（Mark）

**用途**：给正文片段加一层语义色块，突出关键结论、易错点、必背条目。

**语法**

```markdown
默认（主色）：==这是一段重点==

后缀指定颜色：==这是一段重点=={.tip}

前缀指定颜色：==tip:这是一段重点==
```

**颜色变体与别名**

| 变体 | 别名 | 典型用途 |
| --- | --- | --- |
| `primary` | `main` `default` | 默认，主色强调 |
| `secondary` | `sub` | 次级强调 |
| `tertiary` | `third` | 第三级强调 |
| `error` | `danger` `warning` `warn` `caution` | 易错、危险、否定 |
| `tip` | `success` `info` `note` `hint` | 技巧、结论、肯定 |

**正确用法**

- **推荐统一使用后缀写法** `==文本=={.tip}`：位置随意，段首段中段尾都可靠。
- ⚠️ 前缀写法 `==tip:文本==` **只在段落或文本节点开头生效**（段首、或紧跟其他行内元素之后）。写在句子中间会失效并原样泄漏，因此不建议在正文中间使用。
- 文本内可含 `=` 与行内公式，例如 `==$|A| = 0$=={.tip}`。
- 可在**标题、表格单元格、标注块、折叠面板、列表项**内使用。
- **不支持嵌套**（`==外 ==内== 尾==` 会被切成多个独立高亮）。
- 想显示字面 `==`，写 `\=\=`。
- 变体名写错（不在上表内）时，花括号部分会**原样保留显示**，不会静默丢失——遇到这种情况请检查变体名拼写。

## 3. 嵌套与组合

### 3.1 围栏长度铁律

**`:::` 容器互相嵌套时，外层必须比内层更长：外层 `::::`（4 个冒号），内层 `:::`（3 个冒号）。**

`remark-directive` 用**围栏长度**判定闭合归属。两层都用 3 个冒号时，第一个 `:::` 被外层吃掉，内层虽然渲染出来了，**外层的闭合行却残留成页面上一行 `:::`**——无声、不报错，最难发现。

```markdown
::::collapse
- 面板标题

  正文

  :::tabs#steps-31

  @tab:active ① 第一步 #s1

  步骤内容

  @tab ② 第二步 #s2

  步骤内容

  :::
::::
```

参数在 4 冒号下照常生效（`::::collapse accordion` ✅）；但写进标注块内（`> :::collapse`）**必须省略参数**。

### 3.2 可行性矩阵

| 外层 ＼ 内层 | 提示块 | 标注块 | 折叠面板 | 选项卡组 | 高亮 |
| --- | :---: | :---: | :---: | :---: | :---: |
| 提示块 `:::note`（3 冒号） | — | ✅ | ✅ | ⚠️ 残留 `:::` | ✅ |
| **提示块 `::::note`（4 冒号）** | — | ✅ | ✅ | ✅ | ✅ |
| 标注块 `> [!x]` | ✅ | ✅ | ✅（**省略参数**） | ❌ **不可用** | ✅ |
| 折叠面板 `:::collapse`（3 冒号） | ✅ | ✅ | ⚠️ 残留 `:::` | ⚠️ 残留 `:::` | ✅ |
| **折叠面板 `::::collapse`（4 冒号）** | ✅ | ✅ | ✅ | ✅ | ✅ |
| 选项卡组 | — | ✅ | — | — | ✅ |
| 引用块 `>` | ✅ | ✅ | ✅ | ❌ | ✅ |
| 段落层级 | ✅ | ✅ | ✅ | ✅ | ✅ |

要点：

1. **要往容器里塞选项卡，就把外层写成 4 个冒号**；标注块里塞不了选项卡。
2. 引用块内嵌任何 `:::` 容器时，**闭合行也必须带 `>` 前缀**；且容器**不能带参数**。
3. 每层容器都要有自己独立的闭合行，数量一一对应；嵌套时外层加长冒号数。
4. 记忆法：**验证时只看页面正文有没有多出一行 `:::`**，有就是围栏长度不够。

## 4. 常见报错与排查

### 4.1 整篇渲染失败：`Could not parse expression with acorn`

**含义**：正文里有裸露的**花括号**，被当作 JavaScript 表达式解析。

两个来源，**先查公式定界符，再查普通花括号**：

1. **公式漏写 `$` / `$$` 定界符**（最高频）——见 [4.2](#42-整篇渲染失败referenceerror-bmatrix--cases-is-not-defined)。
2. **正文里的裸花括号**：`{花括号}`、`{#id}`、`{2a}` 等任何未转义的 `{` `}`。

**修正**：公式补上 `$…$` / `$$…$$`；普通花括号改为 `\{` `\}`。需要展示花括号语法时，把示例放进**代码围栏**里。

### 4.2 整篇渲染失败：`ReferenceError: bmatrix / cases / matrix is not defined`

**含义**：花括号被当作 JS 表达式求值，而内容恰好是合法标识符（`bmatrix`、`cases`……），语法通过但求值失败。

**首要原因（先查这个）**：**公式漏写 `$` 定界符**。

```markdown
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}      ← ❌ 裸写 → bmatrix is not defined
```

```markdown
$$
A = \begin{bmatrix} 1 & 2 \\ 3 & 4 \end{bmatrix}
$$
```

**修正**：给每一处 `\begin{…}` 补上 `$…$` / `$$…$$`；块级公式的 `$$` 各自独占一行。

**次要原因**：正文里的裸花括号（`{cases}`、`{花括号}`）→ 转义 `\{` `\}`。

⚠️ 看到这类报错**不要去找同名变量**，它不是代码问题，是内容里的定界符/花括号问题。
⚠️ 漏 `$` 但花括号内是**合法 JS** 时（如 `\frac{1}{2}` 的 `{1}`、`{2}`）**不会报错，只会静默错乱**——所以「能跑通」不等于公式正确。交付前用 `.diag/check-math-delims.mjs` 扫一遍（用法见 skill `my-blog-note-writing` 第 5 节）。

### 4.3 `:::` / `@tab` / `[!` 原样显示在页面上

说明对应语法**没被识别**，逐项检查：

| 现象 | 原因 | 修正 |
| --- | --- | --- |
| `:::tabs#id @tab` 连在一起显示 | 开标记行后面多了内容 | 让开标记行独占一行 |
| `:::tabs` 与 `@tab` 都泄漏 | 只写了 1 个 `@tab`，或缺少闭合 `:::` | 补齐 ≥2 个 `@tab` 与结尾 `:::` |
| 标注块内出现 `@tab` | 选项卡写在标注块内 | 移到标注块外，或外层改用 `::::collapse` |
| **页面多出一行 `:::`，但容器渲染出来了** | **`:::` 闭合行与正文写成了同一行**（如 `…说明文字。 :::`） | 闭合围栏必须**独占一行** |
| **页面多出一行 `:::`，且容器没渲染** | **外层容器只有 3 个冒号却内嵌了 `:::` 容器** | **外层改 4 个冒号 `::::`** |
| 表格表头是空的、真实列名掉到第一行数据 | 表头行写成了空行 `|   |   |` | 表头行填真实列名 |
| **整篇渲染失败 `Expected a closing tag for <br>`** | 标题内换行写了 `<br>`（未自闭合） | 改 `<br />` 或 `<br/>` |
| 标题里本来分行的内容被折叠起来 | 在源文件里换行 → 后续行被判为正文 | 标题内换行用 `<br />`；或把解析分到另一个 `> [!note]-` |
| 标注块内 `:::collapse expand` 整行原样显示 | 标注块内的容器不能带参数 | 省略参数；要 `expand` 就挪到段落层级 |
| 标注块内出现一个空 `<div></div>` | `> - :+ 标题` 的 `:` 被当 textDirective | 标注块内不要用 `:+` / `:-` |
| `[! tip]` 原样显示 | 少了 `>` 前缀，或 `[!` 后多了空格 | 写成 `> [!tip]`，`!` 后不留空格 |
| `:::tabs` / `:::` 泄漏 | 容器没闭合 | 补上对应的 `:::` |
| 折叠面板整块消失 | 容器内不是「恰好一个无序列表」 | 改用 `-` 列表；检查缩进是否被破坏 |

### 4.4 公式显示为红字

`$$` 没有独占一行。把块级公式写成三行：

```markdown
$$
公式内容
$$
```

### 4.5 公式显示残缺 / 位置出现奇怪的数字

公式漏写了 `$` 定界符，且花括号内恰好是合法 JS（如 `\frac{1}{2}` 的 `{1}`、`{2}` 被求值成数字）——**不报错，只是静默错乱**。
修正：给每处 LaTeX 补上 `$…$` / `$$…$$`。这也再次说明：`renderMdx` 能跑通**不等于**公式正确。

### 4.6 图片下方看不到说明文字

这是设计行为，不是故障。正文图片的说明文字在图注层被隐藏，只在**点击放大后的灯箱**里显示。

### 4.7 自检方法

改完一篇内容后，确认以下各项均为「否」：页面上出现 `:::`、出现 `@tab`、出现 `[!`、出现 `==`、表格表头为空。
任一项为「是」，说明有语法没被识别，按 4.3 对照排查。

另外**始终单独跑一次公式定界符检查**（`.diag/check-math-delims.mjs`，用法见 skill `my-blog-note-writing` 第 5 节）——它专门抓「不报错但错乱」的那一类。
