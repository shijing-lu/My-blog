正文里放多张图，麻烦的从来不是"放不进去"，而是排不整齐：横图竖图混在一起，一行里高高低低；想看细节还得一张张点进新标签页。`:::grid` 用一个容器解决这两件事——把一组 Markdown 图片排成统一比例的响应式网格，并自动给它们加上灯箱浏览。==读完这一篇，你就能给任何一篇文章排出整齐的配图=={.tip}。

它同时适用于**文章正文**与**文档正文**，同一套语法、同一套渲染。

## 写第一组网格

最小可用的写法，是直接把图片放进容器里：

```markdown
:::grid

![图片一](/img/a.webp)

![图片二](/img/b.webp)

:::
```

两条书写约定：

- 每张图片**单独占一个段落**，图片之间必须有空行；
- 容器内**只放图片**，段落文字与列表写在容器外面。

不写参数时，默认按**三列 / 16/10 / cover 裁切**渲染——预期结果是下面这样一个两图的网格：

## 调参数：列数、比例、填充

三个参数写在起始指令后面的花括号里：

```markdown
:::grid{columns="3" aspect="16/9" fit="cover"}
```

| 参数 | 取值 | 默认 | 说明 |
| --- | --- | --- | --- |
| `columns` | `1` ~ `6` | `3` | 桌面端每行的列数 |
| `aspect` | 任意比例，如 `16/9`、`3/4`、`1/1` | `16/10` | 卡片的宽高比 |
| `fit` | `cover` / `contain` | `cover` | 裁切填满，或完整显示 |

> [!tip]
> `aspect` 约束的是**卡片**的比例，不是原图比例。原图比例与它不一致时，由 `fit` 决定是裁切还是留白。

## 让图注显示出来

图注有两个来源，`title` 优先于 `alt`：

| 写法 | 图注显示的内容 |
| --- | --- |
| `![无障碍文本](/img/a.webp)` | 无障碍文本 |
| `![无障碍文本](/img/a.webp "真正的图注")` | 真正的图注 |

怎么选，记三条就够：

- 想让版面整齐 → 用默认的 `cover`；被裁掉的边缘，点开灯箱就是完整原图。
- 图上边缘有文字或关键信息（图表、截图） → 用 `contain`，绝不裁图。
- 两者都想要整齐与完整 → 把 `aspect` 调成接近原图的比例。

## 在小屏上会怎么变

列数不是固定的，窄屏会自动折叠：

| 视口宽度 | 实际列数 |
| --- | --- |
| ≥ 768px | 按 `columns` 指定 |
| < 768px | 最多 2 列 |
| < 480px | 单列 |

末行图片不够时保持轨道宽度、左对齐，不会被拉伸变形。需要一张大图时用单列，超宽长图也能完整显示：

:::grid{columns="1" aspect="16/9" fit="contain"}

![4/1 超宽长图]({{IMG_WIDE}} "单列 + contain：超宽长图完整显示")

:::

## 检查是否生效

发布前按这四步确认一遍：

- [ ] 图片排成了网格，而不是各占一行 → 说明容器闭合、图片之间有空行
- [ ] 一行里的卡片等宽等高 → 说明 `columns` 与 `aspect` 生效
- [ ] 点开图片能看到未裁切的完整原图 → 说明灯箱与分组正常
- [ ] 缩窄窗口到手机宽度 → 应折叠为两列，再窄则单列

## 故障排查速查表

| 现象 | 根因 | 解决 | 预防 |
| --- | --- | --- | --- |
| 图片各占一行，没成网格 | 图片之间没有空行，或容器没写闭合的 `:::` | 在图片之间补空行、补上 `:::` | 记住两条书写约定 |
| 一行里卡片宽度不一致 | `columns` 写了非法值，回退成默认 3 列 | 检查是否为 1~6 的整数 | 参数照抄示例 |
| 图片边缘被裁掉了 | `cover` 的正常行为 | 需要完整图就换 `contain`，或点开灯箱看原图 | 边缘有信息的图别用 `cover` |
| 图注没显示 | `alt` 与 `title` 都没写 | 给图片补上 `title` | 每张图都写说明文字 |
| 卡片里露出背景色 | `contain` 下原图比例与 `aspect` 不符 | 调整 `aspect`，或接受留白 | 混排时统一原图比例 |

## 已知限制

- 列数最多 6 列，再多会挤成缩略图墙，正文阅读通常 2~4 列更合适。
- `contain` 会留白，这是不裁图的代价，无法同时做到"零留白 + 零裁切"。
- 灯箱分组不能跨网格：想让几张图一起浏览，就把它们放进同一个容器。

## 上线检查清单

- [ ] 每个网格的参数都符合预期（列数 / 比例 / 填充）
- [ ] 每张图片都写了说明文字（`alt` 或 `title`）
- [ ] 在手机宽度下看过一遍折叠效果
- [ ] 点开每个网格，确认灯箱只在组内切换

> [!note]- 边界与容错：写错了会怎样
> 这套语法对写错的容忍度很高，最坏情况也不会让整篇渲染失败：
>
> - 参数非法（`columns="9"`、`aspect="abc"`、`fit="fill"`）→ 逐项回退默认值；
> - 忘了写闭合的 `:::` → 降级成普通内容，不残留标记；
> - 容器里混进文字或列表 → 图片照常成网格，文字按普通段落渲染；
> - 图片失效 → 保留卡片占位与图注，布局不塌；
> - 只有一张图 → 按指定列数渲染，灯箱可开但没有切换按钮；
> - 极端比例（超长截图）→ `cover` 裁切或 `contain` 完整显示，都不会撑破版式。
