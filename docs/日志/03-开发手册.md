# 日历日记与 AI 整理：开发手册

状态：已实施（2026-09-28）。

## 实施顺序

1. 先更新需求、技术与本开发手册，确认原独立日志功能迁入日历。
2. 扩充来源的 ID 和安全引用转换，完善动态、随心录的单条深链。
3. 在日历接入生成按钮、进度、双击日期、阅读浮层和可视化就地编辑；替换旧编辑跳转。
4. 移除独立导航入口，令 `/diary` 和旧编辑页跳转到日历对应日期。
5. 检查类型、构建与关键用户流程，记录真实 AI 服务需要站主账号验证的部分。

## 开发约束

- 日记按 `Asia/Shanghai` 日期计算；历史补缺只扫描今天以前，跳过所有已有日记。
- 首次打开空白日记使用冲突不覆盖插入；生成失败、空输出和取消请求均不覆盖原文。
- Markdown 阅读使用现有 MDX 渲染；编辑使用现有 `MarkdownEditor` 可视化模式。
- 来源链接使用服务端白名单路由和真实来源 ID；原文权限在目标页继续生效。
- 站主权限由日记路由和页面共同保护；页面及 API 禁止公共缓存。

## 验收流程

检查单击和双击日期、跨月日期、触屏按钮、空白日记创建、编辑保存与再次阅读；检查全量补缺、当日覆盖、无来源和 AI 失败；检查公开/私密动态与随心录逐条来源链接；检查上海午夜跨日及非站主权限。开发用 GPT-6-Sol（medium 推理）；运行时 AI 模型沿用站点设置。

## 本次验证

`astro check` 为 0 错误；日记日期、来源引用和路由权限定向测试共 61 个用例通过；`astro build` 完成。真实 AI 服务的生成效果与站主登录后的浏览器交互需使用站点已配置的服务商验证。
