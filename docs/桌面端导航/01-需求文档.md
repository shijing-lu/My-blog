# 桌面端前进与后退导航需求文档

## 目标

让桌面端像浏览器一样，能在当前窗口访问过的站内页面之间后退、前进。

## 界面与交互

- 在桌面端网站顶部导航的站名两侧放置按钮，顺序为「后退｜白衣卿相｜前进」。站名仍可点击并返回首页。按钮沿用网站的颜色、边框、悬停和焦点样式。
- 浏览器网页版不显示这两个按钮。保留 Windows 原生窗口标题栏。
- 当前窗口没有上一条或下一条历史记录时，相应按钮禁用，并有清晰的禁用外观及辅助技术标签。
- 点击按钮后，当前窗口沿历史记录移动一项。普通站内跳转和 Astro 客户端路由跳转都参与历史记录；后退之后打开新页面，原先的前进记录按浏览器规则失效。
- 每个桌面窗口独立维护历史。新窗口从首页开始，不继承其他窗口的历史。
- 外部网站由系统浏览器打开，不进入桌面窗口的站内历史。

## 验收情形

1. 桌面端初次打开首页时，两个按钮均禁用；网页版不显示按钮。
2. 依次打开多个站内页面，可以逐项后退、前进；按钮状态随导航及时变化。
3. Astro 客户端路由跳转、浏览器历史跳转和普通整页加载后，按钮状态正确。
4. 后退后进入新页面，前进按钮禁用；新开的桌面窗口历史独立。
5. 站名链接、现有顶部导航、主题切换和窗口原生控制保持可用。
