# 123 云盘对接教程（AList 挂载全姿势）

> 面向读者：已经按《网盘对接实战教程》搭好 AList 中转层的用户。
> 本文只讲 **123 云盘这一家**怎么接进来，以及它和其他网盘不一样的脾气。

## 一、四个驱动，先选对再动手

123 云盘在 AList 里有**四个**驱动，对应四种完全不同的用途。选错驱动是挂载失败的第一大原因。

| 驱动 | 认证方式 | 能做什么 | 适合谁 |
|---|---|---|---|
| `123Pan`（个人） | 手机号 + 密码 | 全功能读写：浏览/上传/下载/删除 | **大多数人的选择**，零门槛 |
| `123 Open`（开放平台） | clientID + clientSecret | 官方 API 读写，更稳，支持直链签名 | 想要稳定长期使用、愿意申请开发者 |
| `123PanShare`（分享） | 分享 key（+提取码） | **只读**浏览/下载别人的分享 | 挂别人的分享资源 |
| `123PanLink`（直链） | 直链 URL 列表 | 只读加速分发（需 VIP 购买直链额度） | 有付费直链需求的高级玩法 |

:::tip 怎么选
- 只是想把 123 云盘当存储用 → **`123Pan` 个人驱动**，填账号密码就行
- 长期稳定挂载、介意“非官方接口” → **`123 Open`**，花十几分钟申请开发者
- 想白嫖别人分享的资源 → **`123PanShare`**
- `123PanLink` 依赖付费直链额度，除非你清楚自己在做什么，否则跳过
:::

## 二、方案 A：个人驱动（账号密码，5 分钟搞定）

### 2.1 填写步骤

1. AList 后台 →「存储」→「添加」→ 驱动选 **123云盘**（`123Pan`）
2. 按下表填写：

| 字段 | 填什么 | 说明 |
|---|---|---|
| 挂载路径 | `/123` | 出现在网盘页的目录名 |
| 用户名 | 注册 123 云盘的**手机号** | 也支持邮箱登录 |
| 密码 | 账号密码 | |
| 保险箱密码 | 留空 | 只在你要访问「保险箱」内的文件时才填 |
| 根文件夹 ID | `0` | 挂整盘；只挂某文件夹就填 URL 里 `homeFilePath=` 后面的数字 |

3. 保存 → 状态 `work` 即成功。

### 2.2 硬限制（官方文档明说的）

> [!warning] 免费用户的流量墙
> - **下载流量：免费用户每天 1G**，超了就下不动（上传不受限）
> - **禁止多 IP 共享使用**——也就是说「复制地址」把直链发给别人下载，是有风险的用法
> - 单个文件夹内文件太多（几百个）时列目录容易报错，API 每次加载数量有限

==挂别人的分享、当公共下载站，都不是 123 免费账号该干的事=={.error}。它适合当**你自己的第二块存储盘**——尤其上传不限量，可以当文件备份仓。

### 2.3 高频报错：「当前账号存在安全风险」

这是 123 云盘**排障第一名**的报错：

```text
failed get objs: failed to list objs: 当前账号存在安全风险，
请使用短信验证码或者微信进行登录。
```

原因：123 官方禁止“陌生设备”调接口登录，AList 所在的机器对它来说是陌生设备。

::::tabs 解决办法
@tab 方法一（最常用）

在本机浏览器打开 123 云盘网页版，登录同一个账号，完成一次**短信或微信验证**，回到 AList 重新保存存储即可。

@tab 方法二

在网页端**修改一次密码**——修改动作会重置设备信任状态。

@tab 方法三（服务器场景）

如果是 Windows Server 上挂载报这个错，先在本地电脑登录一次网页版完成验证，再把同样的账号密码填进服务器上的 AList。
::::

## 三、方案 B：123 Open 开放平台（长期稳定之选）

个人驱动走的是 123 的**网页接口**（官方不承诺稳定，且每天 1G 下载流量）；`123 Open` 走的是**官方开放平台 API**，token 自动维护、支持分片上传和秒传，是长期使用的正路。

:::note 代价
- 要**申请开发者**并通过审核（填一次表，等邮件）
- **下载/预览等直链功能需要开通 123 的 VIP**（列目录、上传、管理是免费的）
:::

### 3.1 申请开发者（一次性）

1. 登录 123 云盘网页版 → 右上角头像 →「设置」→ 记下**账号 ID**（申请表里要填的“云盘 UID”）
2. 打开开放平台官网 `https://www.123pan.com/developer`：
   - 阅读并签署开发者协议
   - 填写申请材料（必填项含 UID）
   - 等待审核通知
3. 审核通过后，`client_id` 和 `client_secret` 会**发送到你的邮箱**——==记得翻垃圾箱=={.tip}，并妥善保管（这对密钥等于你网盘的管理权限）

### 3.2 挂载配置

| 字段 | 填什么 |
|---|---|
| 挂载路径 | `/123open` |
| 认证方式（auth_mode） | `client_credentials`（默认） |
| 客户端 ID（client_id） | 邮件里的 client_id |
| 客户端密钥（client_secret） | 邮件里的 client_secret |
| 根文件夹 ID | `0`（或某文件夹的 ID） |
| 上传线程（upload_thread） | `3`（默认，分片上传并发数） |

Token 的获取与刷新 AList 全自动处理，无需人工干预。

### 3.3 能力清单（官方口径）

- ✅ 浏览、**上传（分片 + 秒传）**、创建文件夹、重命名、移动、删除、自动刷新 token
- ❌ **不支持复制**（跨目录复制不可用）、在线压缩/解压、打包批量下载
- ⚠️ 直链/预览功能要 VIP + 手动「启用直链空间」；**根目录（ID=0）不支持直链功能**——要直链就挂一个启用了直链空间的子文件夹

> [!danger] 使用红线（后果自负）
> 官方明确警告：**禁止多人共享、图床、软件床、视频外链**等分发类用法，违规**封号不救**。这和阿里云盘 Open 的红线几乎一样——你的网站「复制地址」功能如果对外发放 123 直链给别人下载，就属于踩线行为，请自斟酌。

## 四、方案 C：挂别人的分享（只读）

想把**别人分享的 123 链接**变成自己网盘页里的一个目录：

| 字段 | 填什么 |
|---|---|
| 分享 key（sharekey） | 分享链接里的 key 部分 |
| 分享密码 | 有就填，没有留空 |
| 根文件夹 ID | `0` = 展示分享的全部文件 |

**获取 sharekey**：打开分享链接（形如 `https://www.123pan.com/s/xxxxx`），链接尾部那串就是 key；如果页面跳转后看不到，用 F12 在请求里找。只读，**不能上传**。

## 五、接到网站上：零改动

和蓝奏云、阿里、夸克一样——AList 挂好后，**网站的网盘管理页自动多出对应目录**，上传（跟随当前目录）、下载、复制地址全部照常。

:::tip 结合本站功能的建议姿势
- 123 个人驱动**上传不限量** → 适合当「大文件备份仓」：在本机用 AList 网页（`http://127.0.0.1:5244`）传大文件，绕开隧道超时
- 免费账号**每天只有 1G 下载流量** → 别用「复制地址」对外分发；给自己用没问题
- 「复制地址」拿到的链接同理有时效与流量限制，引用到文章前先想清楚读者量
:::

## 六、排障速查

| 症状 | 原因 | 解决 |
|---|---|---|
| `当前账号存在安全风险，请使用短信验证码或者微信进行登录` | 123 禁止陌生设备登录 | 网页版登录同账号完成一次短信/微信验证，或改一次密码 |
| 免费账号下载报错/没速度 | **每天 1G 下载流量用完** | 等次日重置；或升级 VIP；或改用 Open 驱动 |
| 列目录中途报错、大文件夹打不开 | API 单次加载数量有限 | 减少单文件夹文件数；分目录存放 |
| Open 挂载后看不到文件 | 密钥填错 / 审核未通过 | 核对邮件里的 client_id/secret；确认审核已通过 |
| Open 想要直链但 404/不可用 | 未开 VIP 直链空间 / 挂的是根目录 | 文件夹右键「启用直链空间」；不要挂根目录（ID=0） |
| 保险箱内文件列不出来 | 未填保险箱密码 | 存储配置里补 `safe_password` |

## 七、上线检查清单

- [ ] 已确认用的是四个驱动里**对应需求**的那一个
- [ ] 个人驱动：已在网页版完成一次设备验证（安全风险报错预防）
- [ ] 知道免费账号 **1G/天下载流量** 的墙，并想清楚 123 盘的定位（备份仓 or 下载站）
- [ ] Open 驱动：client_id/secret 已妥善保管，**没有提交到任何公开仓库**
- [ ] 没有把 123 直链对外分发（图床/外链 = 封号红线）
- [ ] AList 状态 `work`，网站网盘页能看到新目录并能上传一个测试文件
