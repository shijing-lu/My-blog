# Markdown 多栏使用与实现说明

## 直接编辑

1. 打开文章或文档的 Markdown 编辑器，点击上方「两栏」或「三栏」。选中的正文会进入第一栏。
2. 在每栏内直接写 Markdown。可写标题、段落、列表、引用、链接、图片、代码、公式与表格；视觉反馈沿用所在编辑器的预览模式。
3. 点击「添加一栏」将两栏变为三栏。「左移／右移」调整顺序；三栏中的「合并移除」把文字按阅读顺序合入相邻栏，留下两栏。
4. 「展开为普通正文」按从左到右的顺序保留所有内容，移除分栏结构。
5. 「查看源码」切换编辑器中的分栏为源码；上方「恢复分栏视图」恢复完整语法块的可视编辑。

插入后自动聚焦第一栏。栏内 Tab／Shift+Tab 切换相邻栏，到边界会回到普通正文；Esc 退出当前多栏块。Ctrl/Cmd+S 沿用原有保存入口，撤销／重做沿用主文档历史。格式工具作用于当前栏，图片上传完成后也会回到发起上传的栏。

阅读和编辑均按容器宽度折叠：三栏在 640px 及以下、两栏在 480px 及以下按原顺序显示为单列。长代码在本栏滚动。

## 保存格式

内容继续保存在原有 Markdown 字段，无数据库迁移。

````markdown
:::columns

::column

## 左栏标题

- 列表项
- **加粗文字**

::column

## 右栏标题

```ts
console.log('每栏可含完整 Markdown 块');
```

:::
````

三栏增加一个独占一行的 `::column`。恰好支持两个或三个标记。容器中的第一个标记之前不要放正文。

栏内使用其他容器指令时，外层冒号数量要大于内部指令；可视编辑器自动调整外层围栏。例如内层 `:::note` 对应外层 `::::columns` 和 `::::`。代码块中的字面 `::column` 不会被误分栏。

没有闭合或列数错误的语法不生成可视分栏，保留源码供修正。可视编辑过程中暂时未闭合的代码／指令会保留编辑边界；在此时保存并重新打开，可能回退源码，补齐闭合符号即可恢复。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `src/lib/markdown-columns.ts` | 扫描源码范围、生成规范语法、移除栏时保留正文 |
| `src/lib/mdx/columns.ts` | 将各栏完整 Markdown AST 子树转换为 MDX 组件 |
| `src/components/mdx/Columns.tsx` | 阅读页面的静态结构 |
| `src/components/admin/cm-columns-state.ts` | 缓存、编辑边界、活动子编辑器、焦点状态 |
| `src/components/admin/cm-columns.ts` | 栏内编辑器、源文档事务、结构操作 |
| `src/components/admin/MarkdownEditor.tsx` | 快捷插入、格式与粘贴／上传目标路由 |
| `src/styles/global.css` | 阅读与编辑分栏样式及容器查询 |

每栏复用当前预览扩展，不加载另一套富文本编辑框架；修改通过主文档事务进入现有保存链路。只在内容改变时重算分栏结构，光标移动不重算，Widget 更新复用子编辑器。表格在移动、合并、展开及分栏保存前提交未失焦内容。

## 首版边界

- 等宽两栏或三栏，支持多组分栏；不支持列宽拖拽、嵌套分栏和跨行合并。
- `::column` 是独占行的保留标记；需要展示这段语法时放进代码块。
- 项目的 MDX 阅读管线支持此扩展；其他 Markdown 阅读器不一定支持。
- 编辑时的可视效果取决于既有预览扩展，不保证所有自定义指令都与最终阅读页完全一致。
- 模拟 IME 检查不能代替全部真实中文输入法和设备的体验验收。

## 交付路径

桌面构建使用 `pnpm run build:desktop`，组装使用 `node scripts/make-desktop-bundle.mjs`。构建完成后覆盖固定 `release/portable`；用户继续打开其中的 `白衣卿相.exe`。内部暂存目录仅用于避免发布半成品，不作为另一个使用入口。
