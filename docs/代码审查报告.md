## 1. P0 —— 应立即修复

### P0-1 开放重定向（Open Redirect）可被反斜杠绕过 · 安全

- **位置**：
  - `src/pages/api/auth/user/github.ts:14`
  - `src/pages/api/auth/user/github/callback.ts:32`
- **问题**：两处校验均为 `next.startsWith('/') && !next.startsWith('//')`。该写法只挡住了 `//evil.com`（协议相对 URL），但**浏览器会把反斜杠 `\` 规范化为正斜杠**——`/\evil.com` 或 `\evil.com` 会被解析为跳转到外部域名，从而绕过检查。攻击者可构造登录链接，让已登录用户被重定向到钓鱼站点。这是可被实际利用的漏洞。
- **方案**：统一收敛到一个安全校验函数，同时拒绝反斜杠、绝对 URL、其它 scheme（`javascript:`、`data:`）以及控制字符（防 `Location` 响应头注入），并用「不可能冲突的 base 域名 + 二次 origin 断言」兜底。
- **状态**：✅ **已修复**（见第 5 节）

### P0-2 AUTH_SECRET 缺失时回退派生密钥 · 安全

- **位置**：`src/lib/auth.ts:25-29`
- **问题**：原实现为 `serverEnv('AUTH_SECRET') || sha256(ADMIN_PASSWORD)`。未配置 `AUTH_SECRET` 时，HMAC 会话签名密钥由管理员口令派生，这意味着「能否伪造任意管理员会话」只取决于一个可能被暴力枚举的口令，攻击面明显大于独立随机密钥。
- **方案**：改为 fail-fast——缺失即抛错拒绝启动，不做回退。
- **状态**：✅ **已修复**（已确认 Vercel 生产/预览环境均**已配置** `AUTH_SECRET`，不会造成线上中断）

### P0-3 动态页 `/moments` 首屏请求爆炸 · 性能

- **位置**：`src/pages/moments/index.astro:209`（原 `<Comments client:load …>`）；`src/components/interact/Comments.tsx:243,261`；`src/components/interact/LikeButton.tsx:44-47`
- **问题**：动态列表给**每条**动态挂一个 `client:load` 评论岛。每个岛 mount 时立即发起 `/api/comments` + `/api/likes/summary`，并在 `Comments.tsx:261` 各发一次 `/api/auth/user/me`——而登录态是全站唯一的，**20 条动态就是 20 次完全相同的请求**。线上实测该页 **87 个请求，其中 52 个是 API**，为全站最严重的首屏瓶颈。
- **方案**：① 评论岛改 `client:visible`，滚动进视口才水合；② `/api/auth/user/me` 用模块级 in-flight Promise 去重；③ 列表内重复头像补 `loading="lazy"`。
- **状态**：✅ **已修复**（见第 5 节，实测 API 52 → 1）

### P0-4 移动端导航溢出 / 管理按钮触屏与键盘不可达 · UI/UX

- **位置**：顶部与侧边导航组件；文档/相册等页面的管理按钮（`opacity-0 hover:opacity-100` 模式）
- **问题**：窄屏下导航项溢出或被裁切；仅靠 hover 显现的操作按钮在触屏设备上无法触发，键盘 Tab 也聚焦不到，属于功能不可达。
- **方案**：移动端改抽屉/汉堡菜单；管理按钮改为常驻或提供 `:focus-visible` 与触屏触发路径。
- **状态**：⏳ **未处理**（涉及多页面交互重构，建议单独一轮迭代）
