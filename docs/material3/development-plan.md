# Material 3 开发与发布计划

## 顺序与完成条件

1. 需求、技术分析、覆盖矩阵及代表性设计预览：覆盖全部路由和反馈状态。
2. 站点默认/设备覆盖、API、持久化、首帧/转场、公共令牌/字体/图标：状态回归通过。
3. 自适应导航及文章、文档、编辑器：阅读、编辑、切换保留状态的浏览器验证通过。
4. 相册、动态、日历、日程、思维导图、AI/笔记、管理/设置、第三方 DOM：覆盖矩阵逐项核验，不以首页结果代替全站验收。
5. 两种风格回归、长文性能、双库/同步验证；提交推送和 Vercel 发布；构建客户端与 Android 包，实际安装/设备结果独立记录。

## 产物

requirements.md、technical-analysis.md、coverage.md、设计预览及组件展示页、verification.md、浏览器截图/机器报告、桌面和 Android 更新包。
