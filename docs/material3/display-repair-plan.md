# Material 3 显示问题修复（1.1.1）

用户已确认实施，2026-10-05。排查包括 147 次设置视图采样、24 次代表页面检查。原始证据保留在 `outputs/material3-review/settings-audit-20261005/`。

## 根因与方案

1. 导航的 nowrap 被弹窗继承；弹窗需要独立的排版边界。
2. 设置 grid 使用自动最小尺寸，中间栏被长内容撑开；采用可收缩网格和实际内容宽度的字段排列。
3. 文字按钮的 padding 根据通用颜色/边框类推断，挤压图标与头像；改用明确的 button/icon-button/avatar-button/fab/navigation-item 角色。
4. 独立页和弹窗维护不同导航清单；统一分区、名称、地址、搜索词和环境限制。

## 实施顺序

设置布局（840px 边界）及个人外观面板（480px 边界）→ 公共控件角色 → 全站浮层与异步控件收口 → 验证、打包、提交推送与生产发布。

字段低于 560px 单列，达到 560px 双列，三字段组达到 840px 三列；Material 中旧外观配置可展开编辑且明确其生效范围。保留业务 DOM 标识、事件与编辑器生命周期，不新增 API、表或迁移。

## 验收

完整重跑 1500 个入口组合；追加全部设置分区及弹窗内部裁切、按钮/焦点可达性、搜索、保存各状态、原页换肤和窗口缩放。检查两种风格、三种明暗、五种宽度、839/840 边界和 200% 缩放。回归编辑/折叠/上传/加密/权限/同步，修改仅作用于隔离数据或 mock 响应。

发布版本 1.1.1、Android versionCode 6。Windows 真实客户端独立验收；Android 按用户选择先交付签名包，真机后续补验。最终结果另记验证与发布文档，不将浏览器模拟写为真机通过。
