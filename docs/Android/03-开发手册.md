# Android 构建与数据迁移手册

## 构建入口

Windows 环境需 Node >=22.12、JDK 21（设置 JAVA_HOME 或由脚本在用户 .jdks 中发现）。首次准备工具链需联网，下载校验后的官方 SDK 和固定版本移动运行时；首次使用 SDK 需确认许可。工具全部放在项目 `.android-tools` 中。

```powershell
pnpm run setup:android
pnpm run build:android
pnpm run export:android-data
```

构建不执行 Web 生产数据迁移，standalone 单独输出 `.android-tools/dist`。运行依赖保留真实版本和必要代码/许可；不包含 Windows 原生二进制。当前 APK 为 `release/android/白衣卿相-Android-1.0.3.apk`，构建脚本按 APK 构建元数据命名产物。

## 签名与升级

首次构建生成本项目自用 release 密钥，位于 `android/signing/byqx.jks`，口令位于同目录 `password.txt`，均已排除 Git。请保留签名材料，后续升级需使用同一密钥；新的正式版本需更新 `android/app/build.gradle` 的 versionCode/versionName。安装新 APK 保留应用私有数据；卸载应用会删除手机本地数据。

从 1.0.1 升级到 1.0.2：直接覆盖安装新 APK，随后重新打开。不要卸载旧版；已导入数据无需再次导入。新版修复服务就绪信号，并提供“复制诊断信息”；若仍无法启动，将复制的诊断信息发回排查。具体原因与交付范围见 [启动故障修复](04-启动故障修复.md)。

## 迁移当前桌面数据

1. 在桌面保存正在编辑的内容；日程有未同步变更时先完成日程同步。
2. `export:android-data` 从桌面用户目录读取实际配置及数据库，在线备份 SQLite。已提交 WAL 内容包含在快照中，源数据库不修改。
3. 将 `release/android/桌面数据.byqx` 传到手机。口令见 `迁移口令.txt`，应通过另一渠道取得，不要公开分享。
4. 手机安装 APK，首次打开选择“导入桌面加密迁移包”，选取该文件并输入口令。
5. 等待解密和完整性检查结束，进入本地站点；使用原桌面站主密码登录。
6. 联网后从网站的站点设置进入“云端同步”（`/admin/settings/sync`）。原桌面云端配置已随加密包导入。

迁移包带个人内容、AI 配置及云端凭据，必须私密保存。APK 本身只有代码与空库模板。首次导入不覆盖已存在的手机数据库；错误口令、损坏归档和越界路径不提交数据。成功解密后一次移动完整数据目录，避免数据库/配置部分导入。

导出是当时已提交数据的快照；导出后新增内容通过云端同步交换。未保存编辑、尚未同步至 SQLite 的日程 IndexedDB 不在快照内。

## 运行行为

- Android 自身启动 Node 24、本地 SSR 和 SQLite；无需电脑保持运行。
- 本地文章/文档/日记/随心录等读写继续使用原接口；远端 AI、图床上传、云端同步和未缓存媒体需联网。
- 已有 R2 本地缓存导入手机，R2 媒体请求经本地缓存接口读取/按需下载。
- 只有本地页面在 WebView 中导航，站外链接由系统浏览器处理。系统文件选择提供上传入口。
- 1.0.4 起移除 Android 原生顶部按钮栏，保留网站导航；系统返回键仍可返回上一页。
- 文档详情与文章编辑页右上角提供当前文章目录按钮。窄屏点击展开右侧目录，选择章节后收起；点击遮罩或收起按钮也可关闭。
- Android 后台可能被系统终止；下次打开重新启动本地服务。并非常驻后台同步服务。
- 首次打开解压约 100 MB 运行资源可能需要等待；系统 WebView 需保持更新。
- 手机快捷键、长按菜单、软键盘和可视化编辑的体验应在手机进一步验收，不能由桌面构建结果代替。

## 关键文件

- `android/app/src/main/java/com/byqx/blog/MainActivity.java`：导入、启动、导航及文件选择。
- `android/app/src/main/cpp/node.cpp`：JNI 启动 Node，与日志接入。
- `android/runtime/main.cjs`：注入私有配置及本地数据库路径，启动 SSR。
- `scripts/package-android-runtime.mjs`：依赖闭包、原生绑定与 manifest 路径修正。
- `scripts/export-android-data.mjs`：一致快照和加密迁移。
- `scripts/setup-android.mjs`、`scripts/build-android.mjs`：工具准备、签名构建与产物交付。
