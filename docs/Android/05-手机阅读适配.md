# 手机阅读适配计划

截图中长公式、题目提示块及正文超出手机右边界。手机应能完整阅读文章，普通文字换行，标题和提示块保持在屏幕内；无法换行的公式、代码和宽表格在自身区域横向滑动，不裁掉内容，不让整个页面变宽。保持现有主题和 Markdown 语法。

## 实施顺序

1. 收紧文章单列 grid 与正文的最小宽度，限制提示块、媒体和标题宽度。
2. 手机行内公式与长代码提供局部滚动，保持公式内部排版。
3. Android WebView 启用 viewport 与双指缩放，生成同签名新版 APK，保留已有数据。
4. 使用实际页面在手机宽度确认内容可完整访问，记录构建和设备验证范围。

## 验收

320、390、430 CSS 像素宽度；截图对应文档；分段公式提示块、标题、长链接、代码、宽表格；横竖屏及桌面。构建成功不能代替页面或 Android 真机验证。
