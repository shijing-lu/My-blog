# Android 本地服务技术文档

## 运行结构

`MainActivity → 后台 Node 线程 → Astro standalone → 本地 SQLite`。WebView 仅加载 `127.0.0.1` 的本地服务，外链交给系统浏览器；服务不暴露到局域网。

Node 在每个应用进程只启动一次，Activity 重建复用服务；系统终止后下次重新启动。代码和用户数据分目录，升级仅替换代码。配置必须在加载 SSR 模块前注入。

启动就绪信号从 Astro adapter 返回的 `service.server.server`（Node HTTP 服务器）监听，而不是外层生命周期包装对象。处理已经监听的情况，失败后删除就绪标记；Android 同时检查就绪标记和首页 HTTP 响应。首次解压等待最多 180 秒，完成解压后服务启动另计 90 秒，均按单调时钟计算。

失败界面支持复制应用版本、Android API、架构、启动阶段、错误类型/代码及 HTTP 状态。不会复制异常正文、配置、口令和个人内容；完整运行错误仍通过系统日志定位。

## 平台依赖

Gradle 8.13、AGP 8.11.1、JDK 21、SDK 36；最低 Android 8（API 26）。arm64-v8a 面向手机，x86_64 用于模拟器。运行时固定 Node.js Mobile 24.20.0-0 完整版（含 ICU），SQLite 固定 better-sqlite3 13.0.3，图片处理使用 sharp 0.35.4 的 WebAssembly。

原生库从 APK 的 nativeLibraryDir 加载，避免执行应用可写目录中的二进制。来源与下载摘要记录在构建工具配置。

## 配置与权限

`DESKTOP_MODE=1` 复用本地逻辑；新增 `ANDROID_MODE=1`。DATABASE_URL 指向应用私有 SQLite，HOST 固定回环地址，固定端口维持 Cookie/IndexedDB origin；被占用时明确失败。手机独立生成 AUTH_SECRET。

不暴露通用 JS 原生桥，不忽略 TLS 错误；只有回环地址允许 HTTP。上传用系统文件选择，无整盘读写权限。关闭 Android 自动备份。站主鉴权和私密 API 缓存策略沿用项目。

## 数据迁移

桌面导出工具只读打开数据库并执行 SQLite backup，不修改源库。迁移包包含数据库、必要配置与已有媒体缓存，采用 PBKDF2-HMAC-SHA256（210000 次）及 AES-256-GCM；解密口令单独存放。

手机通过系统文件选择，在首次启动本地服务前导入，校验格式及 SQLite 完整性。导入后的手机和桌面各持独立数据库，后续沿用现有云端同步及冲突副本。

未保存编辑和浏览器内尚未同步的日程 IndexedDB 不属于 SQLite 备份；需要先保存/同步。远端图片未缓存时需联网，联网功能不会因本地模式而变成离线能力。

## 构建隔离与验收

Android standalone 使用独立输出，不读根目录 .env，不执行生产迁移、不覆盖 portable。SDK、载荷、签名材料和数据迁移包不提交 Git。

构建和签名检查不能代替真机验收。安装、Node 启动、登录、断网编辑、文件上传、媒体与跨设备同步需在设备确认，并在交付文档注明实际覆盖范围。
