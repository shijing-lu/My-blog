## 1. 测试方法

| 维度 | 方法 |
| --- | --- |
| 浏览器加载 | playwright-core 驱动 Edge，视口 1280×900，`waitUntil:'load'`，统计 `load` 时间、请求数、按路径归类、资源传输体积 |
| 服务端响应 | `curl -w "%{time_starttransfer} %{time_total}"` 多次采样取 TTFB 与总耗时 |
| 构建产物 | 分析 `.vercel/output/static/_astro/` 的 JS/CSS 数量与体积 |
| 本地 A/B | 在本地 dev 环境造 22 条动态，对同一份数据分别以 `client:load` 与 `client:visible` 各测一次，得到**同数据、同环境**的对照 |

### 数据可比性说明（重要）

- **请求数**：前后两次统计方法一致，**可直接比较**。
- **资源体积**：优化前那次采样用的是 `content-length`/解码后体积，优化后用的是 `performance` API 的 `transferSize`（压缩后）。**两者口径不同，不可直接相减**。本报告因此不以体积作为前后对比结论。
- **完整 load 时间**：Serverless 冷启动导致波动极大（同一页面多次采样在 1424ms–5162ms 间跳动），**不适合做前后对比**。本报告以 TTFB 与请求数作为稳定判据。

## 3. 本地受控 A/B 对照

为排除生产环境波动干扰，在本地 dev 造 **22 条动态**，对同一份数据切换 `client:load` / `client:visible` 各测一次：

| 配置 | load | 总请求 | API | API 构成 |
| --- | --- | --- | --- | --- |
| 修复前 `client:load` | 1829 ms | 223 | **68** | 20×`/api/comments` + 20×`/api/likes/summary` + 1×`/api/auth/user/me` + 27×`/api/images/*` |
| 修复后 `client:visible` | 994 ms | 189 | **32** | 2×`/api/comments` + 2×`/api/likes/summary` + 1×`/api/auth/user/me` + 27×`/api/images/*` |

说明：

- 表中「修复前」的 `/api/auth/user/me` 已因去重修复降为 1 次。**真实原始基线应为 20 次**，因此岛驱动型请求实际是从 **60 次降到 5 次（−92%）**。
- 评论与点赞请求从「动态条数 × 2」降为「可见条数 × 2」。

## 4. 构建产物分析

| 项 | 数值 |
| --- | --- |
| JS 文件数 / 总体积 | 49 个 / ≈1454 KB |
| CSS 总体积 | ≈443 KB |
| 最大 chunk | `MarkdownEditor.js` 534 KB |
| 次之 | `ThemeHead.css` 419 KB、`simple-mind-map.js` 331 KB、`client.*.js` 179 KB |
| 运行时 / dev 依赖 | 64 / 13 |

**核实修正**：`simple-mind-map` 虽是 331 KB 大 chunk，但运行时走**动态 `import()`**（`MindMapViewer.tsx:241`、`MindMapEditor.tsx:43`），已做代码分割，不会无条件进入所有页面。真正的隐患是 `client:load` 导致岛在首屏挂载并立即触发该动态导入——本次已改为 `client:idle`。

## 5. 遗留问题与后续建议

| 问题 | 现状 | 建议 |
| --- | --- | --- |
| 列表头像重复请求 | 已加 `loading="lazy"`，但本页卡片较紧凑，Chromium 懒加载阈值较宽松，本地实测仍有 27 次图片请求 | 更彻底的做法是避免每张卡片重复渲染同一头像（如用 CSS `background-image` 或合并为单元素），或让 `/api/images` 返回可缓存的 301/302 而非 307 |
| 完整 load 时间偏慢 | 受 Serverless 冷启动主导，波动 1.4s–5.2s | 关注 `/api/study/stats` 等冷启动热点；可考虑对公开页面开启 ISR/边缘缓存 |
| `/api/search` 全量过滤 | 未处理 | 改 SQL `LIKE` + `LIMIT` |
| ActivityHeatmap 全量取正文 | 未处理 | SQL 列裁剪或写入时预聚合 |
| 移动端导航 | 未处理 | 单独迭代 |

## 6. 复现方式

```bash
# 生产页面测量（脚本需临时创建，测完即删）
node data/prod-measure.mjs /moments

# 服务端 TTFB
curl -s -o /dev/null -w "TTFB %{time_starttransfer}s\n" https://www.byqx-blog.online/moments

# 类型检查 + 测试
npx astro check
npx vitest run
```

> 注：本地 dev 启动需绕过沙箱的 safe-delete shim（`dangerouslyDisableSandbox`）；本地 `data/blog.db` 为旧库，缺列时**不要用 `db:push:dev`**（会因索引冲突把库弄成半迁移态），应按需 `ALTER TABLE` 补列，操作前先备份。
