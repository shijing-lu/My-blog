# 首页文章与文档文章统一页面：需求规格

> 状态：待开发；2026-09-28。本文覆盖首页文章编辑页返工，以及文档/首页文章左侧目录右键操作。实现细节见 [技术设计](article-page-parity-design.md)，执行顺序见 [开发计划](article-page-parity-implementation.md)。

## 1. 背景与目标

现有文档文章页 `/doc/[id]?article=<nodeId>` 是一张完整的阅读/原位编辑页面：全站导航、面包屑、可折叠的左侧目录树、中间正文与工具、可折叠的右侧文章内目录。现有首页文章编辑页 `/edit/[id]` 使用 `AdminLayout` + `LiveEditor` 独立写作台，虽已支持可视化 Markdown 和预览，但页面结构、左栏行为、正文排版、右栏行为均与文档文章页不同。此前“复用编辑器”没有达到“一模一样”的要求，必须返工页面本身。

最终用户在首页文章编辑页看到的页面骨架、视觉尺寸、折叠状态、正文阅读与原位编辑、目录定位应与文档文章页一致。两个页面只在数据源和文章专属业务上不同：文档读取 `doc_nodes`；首页文章读取 `articles` 及其目录归属。首页文章仍拥有标签、内置类型、摘要、封面、访问密码、草稿/发布及已有思维导图能力。这些设置以不挤占正文宽度的设置入口呈现。

## 2. 术语与边界

- **左侧目录**：文章文件/目录树。目录可以包含文章和子目录；文章为叶子，不能包含任何节点。
- **右侧目录**：当前文章 Markdown 标题生成的文章内 TOC；与左侧数据树无关。
- **文档域**：文档册及 `doc_nodes`；现有嵌套树和公开读取规则延续。
- **首页文章域**：`articles` 和升级后的 `article_categories`、`article_post_categories`；分类升级为可嵌套的目录，文章仍至多归属一个目录，无归属显示于“未分类”。
- **编辑页**：首页文章 `/edit/[id]`，需管理员权限；不以这次改造扩大草稿或受密码保护正文的公开范围。首页前台公开文章详情仍按现有访问控制运行。
- **文档正文右键 Markdown 菜单**：已有编辑器功能；本需求的右键菜单只作用于左侧目录树，事件作用域不能重叠。

## 3. 页面一致性要求

| 区域/行为 | 文档文章页基线 | 首页文章编辑页要求 |
| --- | --- | --- |
| 全局框架 | `BaseLayout` 的导航、主题、右侧全局工具栏 | 使用同一框架，不能保留写作台的独立全高外壳 |
| 顶部位置 | 面包屑及当前文档/文章信息 | 同位置呈现“首页文章 / 目录路径 / 当前文章”；目录路径随移动更新 |
| 左侧目录 | 约 220px、可折叠到窄轨、树节点缩进、滚动区、折叠记忆 | 共用组件和交互；数据换成首页文章目录及文章，不仅仅模仿样式 |
| 中间正文 | 同标题字级、按钮区、分隔线、`prose` 排版、空态、长文加载反馈 | 同一正文容器与排版；可视化编辑在该位置原位打开，预览同阅读形态 |
| 右侧 TOC | 340px 贴右悬浮面板；窄窗收起为浮钮；标题折叠、定位与高亮 | 同一组件和状态机；编辑时标题变化能更新/定位目录 |
| 编辑切换 | 阅读态点“编辑”进入可视化 Markdown，退出回到预览并尽量维持视口 | 新草稿创建后直接进入可视化编辑；已有文章进入编辑页按文档页面呈现，点“编辑”原位切换；允许显式预览 |
| 存储 | 文档节点内容自动保存 | 首页文章保留现有自动保存、草稿/发布状态；切换文章及离页必须处理未完成保存 |

“一模一样”指同一布局组件、主要交互和视觉规范，不指两种文章完全相同的权限、接口、数据字段。首页文章的额外设置以“文章设置”按钮打开抽屉/弹层；常驻标题区只露出必要状态（如草稿与发布按钮），避免新增一整列压缩正文。

## 4. 左侧目录右键菜单

管理员在**文档文章页和首页文章编辑页**均可使用相同的左栏右键交互。访客的文档树保持阅读/跳转能力，不出现管理菜单。桌面鼠标右键在目标树节点旁弹出轻量悬浮菜单，屏幕边缘自动翻转或收缩，菜单不遮挡整个页面。触屏长按与键盘 `Shift+F10`/菜单键、行尾“更多操作”按钮提供同等入口，不能把操作限制为只能用鼠标右键。

| 右键位置 | 显示菜单 | 目标层级 |
| --- | --- | --- |
| 左栏树空白处或“本册目录/全部文章”标题 | 新建文章、新建目录 | 当前册/首页文章树根级 |
| 目录节点 | 新建文章、新建子目录、编辑/重命名目录、删除目录 | 新建项放在该目录下 |
| 文章节点 | 编辑文章、删除文章 | 不出现“新建文章/目录”；文章绝不能成为父节点 |

文章“编辑”对文档域进入当前文章的原位编辑，对首页文章域进入该文章的原位编辑；重命名可由正文标题操作或菜单编辑流程触发。目录“编辑”修改名称等目录属性。移动/排序保留已有拖拽能力；若提供菜单内“移动”，须作为后续单独需求，不混入首版菜单。右键菜单替换每一行常驻的“＋文/＋目/编辑/删除”按钮；顶部根级新建按钮可保留作可发现入口，但与根级右键执行同一命令，不得维护两套创建逻辑。

菜单在点击外部、`Escape`、选中命令、切换文章、页面滚动使锚点离开视口时关闭；聚焦位置在关闭后回到原节点。目录左键仍展开/收起，文章左键仍切换文章；右键不触发左键导航。危险操作必须先提示影响范围，再明确确认；失败后菜单关闭/保持的规则一致，并给出可见错误，不乐观删除真实数据。

## 5. 创建、删除与数据规则

### 5.1 文档域

- 根级/目录下新建文章：沿用已实现的立即创建空白文章、选中、打开可视化编辑；新建失败保留原页面。
- 新建目录：在右键所在目录下创建，根空白处创建根目录。现有目录允许无限层级；后端验证父节点属于同一册且为目录。
- 删除文章：删除当前文档节点；若是当前文章，转到同册其他文章或空态。
- 删除目录：**沿用现有文档域级联语义**，删除该目录及全部子目录/文章，确认文案显示影响数量；这是文档域的既有行为，不复制到首页文章域。

### 5.2 首页文章域

- 新建文章：先持久化仅管理员可见的草稿，按右键目录设置归属，导航到新文章并直接打开可视化编辑；根级新建归入“未分类”。自动保存不发布；用户主动发布后才公开。
- 新建目录：目录下或根级创建真实目录；支持任意深度嵌套，不能形成环，也不能跨数据域挂接。
- 删除文章：按现有文章删除能力删除；明确确认，清理目录归属及关联数据；公开列表不留失效链接。
- 删除目录：**保留全部文章**。被删目录本身删除；它直接包含的文章归入“未分类”。直接子目录提升到被删目录原父级，子目录自身及内部结构、文章归属保持不变；若被删目录是根目录，直接子目录提升为根目录。此规则使整个子树脱离被删目录而不丢文章。删除前显示将移出几篇直接文章、提升几个直接子目录；操作须在一个数据库事务内完成。
- “未分类”是虚拟根分组，不是可删除的真实目录；可在其中右键新建文章，不能把其作为子目录的数据库父节点。

### 5.3 目录路径与排序

同级按 `sort`，再以创建时间/稳定 ID 排序；迁移前的平面分类保持顺序并成为根目录，原文章归属不变。目录下创建/移动后只刷新受影响树和路径，不整页重载；目录展开状态、左右栏滚动、正在编辑的正文必须保留。

## 6. 文章专有 UI 与权限

首页文章“文章设置”容纳标签、固定类型、所属目录、摘要、封面、访问密码开关/提示、发布状态与思维导图相关入口。密码字段输入时不回显旧明文；关闭/更改加密必须经过现有保存语义，预览/编辑仅管理员可见的明文。草稿状态在左树和标题区可辨认。发布前校验有效标题与非空正文；已发布文章保存即生效。

菜单 API 和页面 API 都在服务端复核权限、数据域、父节点类型、环检测及删除范围。客户端禁用项只是体验，不是权限边界。公开页面/接口/搜索/RSS/站点地图仍不得列出草稿；受密码保护文章仍需现有访问密码流程。文档域公开规则不因共享 UI 改变。

## 7. 非功能要求与验收

- 对照用户给出的文档页面截图，在 1424×881、宽屏和窄屏下对比左右目录、正文宽度、标题与工具区、滚动/折叠行为；避免出现独立写作台的全高三栏布局。
- 长文继续使用现有延迟渲染/按需载入策略；右键菜单只在打开时挂载，避免每节点长期监听器。普通光标移动不触发整篇 MDX 重渲。
- 编辑器初次进入即为可视化；表格、多栏、引用、画廊、选项卡、折叠面板的已有编辑能力不退化。
- 左栏菜单支持鼠标、键盘、触屏；焦点可见；窄屏不溢出；尊重减少动态效果；切换目录与正文菜单互不串场。
- 创建/保存/删除失败保持数据一致；未保存编辑时阻止丢失内容；网络慢和快速连续操作不覆盖较新正文。
- 本轮仅先完成文档；不在文档阶段修改业务代码、迁移数据库或覆盖便携版。后续每个功能或修复独立使用 Conventional Commits 提交，最终便携包覆盖 `release/portable` 原目录。

## 8. 待开发时验证的边界

1. 当前文档页已有约 1700 行页面脚本和 `#doc-*` DOM 协议；共享前先记录这些协议，不能通过直接复制脚本做“两份一致”。
2. 首页目录当前是平面分类，升级到树会影响分类接口、旧后台分类管理、桌面同步和双数据库迁移。
3. 此文档确认的首页目录删除语义只影响首页文章域；两个数据源共享菜单展示，但删除命令必须由域适配器分别实现。
