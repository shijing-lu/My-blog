# 项目排查与性能优化记录（2026-09-26）

## 项目结构

- `src/pages`：Astro SSR 页面及 API；公共博客、文档、影集、导航、管理台。
- `src/components`：React 岛与 Astro 组件；CodeMirror 编辑器、AI 对话、思维导图。
- `src/lib`：内容查询、Markdown 渲染、身份认证、权限、设置和 AI 业务。
- `db`：SQLite / PostgreSQL 双方言 schema、数据库代理和主备逻辑。
- `desktop`：Electron 启动与打包；`src/sync`：同步引擎。
- `tests`：Vitest 回归测试；`scripts`：构建、迁移与诊断工具。

本轮保留开始工作时已有的未提交改动。没有升级依赖、调用付费 AI 服务、部署、提交 Git，或执行真实数据库迁移。浏览器验证使用 `.diag/performance-review/test.db` 中的合成数据。

## 已修复问题

### 认证与数据边界

1. 管理员、普通用户、OAuth state 和顶级管理员令牌增加独立 purpose 校验，拒绝跨用途复用、额外分段和无效有效期。
2. 删除顶级管理员密码的硬编码兜底；没有配置 `TOP_ADMIN_PASSWORD` 时该密码入口禁用。
3. 将路由权限规则集中到 `src/lib/route-permissions.ts`，补齐字体、AI 配置、样式、思维导图等写入口权限，并统一处理尾斜杠。公共读和公开聊天继续保留原有语义。
4. 公开搜索不再读取设密码文章的正文：不能通过搜索命中推断私密关键词，也不会从私文提取首图。

**升级提示：旧管理员/用户会话需要重新登录；进行中的 OAuth 流程需要重新开始。** `AUTH_SECRET` 仍须显式配置。README 已同步说明，真实环境变量未修改。

### 编辑器与交互

1. 自动保存串行合并，旧请求完成后继续保存最新内容，避免保存期间输入被误标为已保存。
2. CodeMirror 字数改为统计变动片段，普通光标移动和滚动不再全文串化计数。
3. 标题索引按不可变文档与语法树复用；光标未改变渲染块状态时复用装饰集合。
4. 文档编辑输入减少父 React 岛重渲染；保留主题切换时的自适应高度，处理文末围栏装饰边界及过期正文响应。

### 查询与服务端渲染

1. 文档搜索按数据库方言选择 `LIKE` / `ILIKE`，修复 SQLite 搜索失败；`%`、`_` 按字面匹配；支持分类名搜索，排除目录节点，合并新旧文章后仍遵守条数上限。
2. 文档目录只读取文章元信息，不再传输整库正文；按分类预分组，避免对每个分类重复过滤所有文档。
3. 同一 Markdown 源码的并发请求共享编译。缓存同时限制 100 条与估算字符串体积 32 MiB；失效后的旧任务不能重新填回缓存，失败任务与目录寄存会清理。
4. 搜索摘要复用纯文本缓存；标题/分类命中的公开结果恢复字数与首图，仅补读实际展示的至多 50 篇正文。
5. 公共/管理布局的字体状态由两次查询合为一次；CSS 查询不再传回 base64 字体字节，保留 Blob URL 和字体 API 地址。

SQLite 的大小写匹配遵循数据库默认规则：ASCII 大小写不敏感，非 ASCII 字符不做完整 Unicode 大小写折叠。参见 [SQLite 表达式文档](https://www.sqlite.org/lang_expr.html)。

### AI 资源消耗

1. 前后端共享最近消息预算：最多 20 条、单条最多 4000 字符、总历史最多 12000 字符；长会话不再因为前端发送全部历史而超过接口条数限制。
2. 已完成的历史回答使用 memo；流式分片每 50ms 合并更新，减少 Markdown/KaTeX 重渲染。
3. 关闭、取消与新对话隔离旧响应；服务端在取消时停止上游，收到 `[DONE]` 即结束读取。
4. 摘要读取最近 60 条，原文总预算 12000 字符，修复长会话一直读取最早 200 条的问题。
5. 使用持久化摘要标记跳过未变化会话，同实例并发摘要去重；新消息清除标记，结束时按消息计数条件更新，避免摘要期间新增内容被误标为已处理。
6. AI 未配置或未启用时不挂载助手岛，避免下载和初始化其前端脚本。

字符预算不是 token 计费承诺；实际账单仍取决于模型、系统提示和回答长度。同实例并发去重不是跨多个 Serverless 实例的分布式任务锁。
