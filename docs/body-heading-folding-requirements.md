# 正文标题折叠需求

日期：2026-10-04。用户已确认：阅读和编辑状态均支持。

## 范围与交互

- 文档正文、首页文章的阅读正文、文章就地编辑正文中的 H1–H6 均可折叠。页面顶部的文章名称不是正文标题。
- 在有内容的标题左侧显示小箭头，点击折叠或展开。保持现有主题、排版和移动端阅读方式。
- 标题自身保持可见，折叠范围从标题结束开始，到当前容器内下一个同级或更高级标题前结束；没有后续标题时到容器末尾结束。
- 下级章节属于上级章节。收起上级隐藏其下级；再展开上级时保留下级原来的折叠状态。允许跳级标题。
- 支持 Markdown 的 ATX 标题和 Setext 一级、二级标题。代码块里的 `#` 不作为标题。
- 引用、列表项等容器内的标题不吞掉容器外的正文。空章节无需折叠控件。
- 正文折叠与右侧目录折叠互相独立，不更改目录现有层级和操作。

## 状态与内容

- 首次阅读或进入编辑时默认展开。阅读折叠状态在当前页面会话中按文章和标题区分，正文刷新和页面切换后可恢复；编辑折叠状态由当前编辑器实例维护。
- 折叠只是显示操作：不修改源文、不产生保存请求、不新增表字段，也不影响两个数据库的同步逻辑。
- 自动保存继续保存完整正文，包括被折叠的内容。正常编辑继续采用已有自动保存机制。
- 阅读和编辑状态不强制共享折叠状态，避免阅读折叠影响编辑光标。

## 验收标准

1. 两类页面及两种模式均可折叠 H1–H6；标题、前言、后续同级章节正确显示。
2. 嵌套章节、跳级、重复标题、最后一节、Setext 标题和代码中的假标题处理正确。
3. 折叠不改变源文，自动保存和重新读取后的完整内容一致；无未保存弹窗或发布步骤。
4. 点击目录或访问标题锚点时，展开隐藏目标的祖先章节；定位保留现有 ClientRouter 历史行为。
5. 文档异步加载、文章切换和保存退出后的正文重渲染能重新接入折叠，且不重复添加箭头。
6. 控件有名称和展开状态，可通过键盘操作；移动端不产生页面级横向溢出。
7. 打印输出包含全部正文，折叠箭头不进入打印结果。
8. 代码、公式、图片、表格、标签页和现有 callout 保留原来的内容和交互。

## 不在本次范围

不新增目录折叠功能、数据库持久化折叠字段、Markdown 折叠语法或全站批量收起操作。
