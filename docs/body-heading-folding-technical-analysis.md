# 正文标题折叠技术分析

日期：2026-10-04。依据当前工作区代码和已确认需求。

## 接入位置

文档 `/doc/[id]` 和首页文章编辑 `/edit/[id]` 使用 `ArticleDetailShell.astro`、`DocInlineEditor.tsx`。公开文章 `/blog/[slug]` 使用独立正文模板。三处正文均由 `renderMdx` 渲染，必须保留原始渲染管线及标题 id。

文章编辑由 `MarkdownEditor.tsx` 的 CodeMirror 6 承载，现有 `heading-index.ts` 基于 Markdown 语法树识别标题。仅文档和文章就地编辑启用新折叠扩展，其他编辑器保持原有配置。

## 阅读状态

在明确标记的文章正文上进行 DOM 增强：把标题及后续同容器内容组织成嵌套章节，标题插入独立按钮，章节内容通过 `hidden` 切换。移动现有节点而不是重新生成其 HTML，以保留图片、公式、callout、标签页等结构和监听器。

章节包装采用 `display: contents`，减少对 prose 排版的干扰；可见内容块继续使用已有长文渲染优化。折叠控件采用站点颜色、焦点样式和小尺寸箭头，打印时显示所有章节并隐藏按钮。

阅读状态保存在有容量限制的页面内存中，以文章身份和标题序列区分，不写服务器或浏览器持久化存储。异步正文加载及保存重渲染显式重新初始化；SPA 页面加载统一初始化。增强过程幂等。

目录和正文锚点点击在定位前展开目标祖先；文档稳定滚动和阅读位置恢复也显式调用展开函数，避免隐藏元素的零尺寸造成错误定位。不改现有 `pushState` 数据结构。

## 编辑状态

使用 CodeMirror 官方 `codeFolding`、`foldEffect` 和 `unfoldEffect` 保存折叠范围。通过 Markdown 语法树建立 H1–H6 章节范围，按照同一语法容器内同级或更高级标题划定边界，识别 Setext 且排除代码块。

自定义标题 gutter 只为正文标题展示按钮，避免默认 Markdown 折叠把代码、列表等一起纳入本次功能。按钮及快捷键仅发送状态 effect；已有 `update.docChanged` 条件保证折叠不触发正文变更回调和自动保存。

索引按文档和语法树缓存，gutter 使用当前已解析树；用户实际折叠时补全语法树，不在每次按键时对长文强制完整解析。目录和模式切换定位先解除覆盖目标的折叠范围。现有 WYSIWYG 装饰与折叠装饰共同验证，尤其检查复杂长文是否退回源码。

提示块、分栏及标签页等可视化组件使用独立子编辑器。根编辑器的章节索引跳过这些组件内部标题，由子编辑器维护自己的折叠范围；目录定位通过源文位置转交给相应子编辑器。子编辑器被虚拟滚动或上级章节折叠重建时，使用有容量限制的内存快照恢复折叠范围，且仅在正文完全一致时恢复，避免套用过期位置。

CodeMirror 实现参考：[官方折叠模块源码](https://raw.githubusercontent.com/codemirror/language/main/src/fold.ts)。具体 API 以项目已安装版本的声明和实现为准。

## 数据库与部署影响

折叠不改变文章 schema、API、Markdown 或同步表。SQLite 与 PostgreSQL 均继续保存完整正文，无迁移、无新增云表，也不需要修改生产环境参数。验证重点是编辑器状态 effect 不产生 `docChanged`，真实编辑后的保存仍包含隐藏正文。

## 风险与控制

| 风险 | 处理 |
| --- | --- |
| 嵌套容器越界折叠 | DOM 按兄弟节点、编辑器按语法父容器划范围 |
| 异步正文替换丢失功能 | 显式接入刷新路径，初始化幂等 |
| 隐藏标题定位不准 | 测量和滚动前展开目标祖先 |
| 标题按钮污染目录文本 | 按钮只含 SVG，名称通过 aria-label 提供 |
| 长文解析或装饰冲突 | 缓存索引、限时补解析、真实长文浏览器验证 |
| 移动端溢出或打印漏内容 | 窄屏验证及 print 专用规则 |
