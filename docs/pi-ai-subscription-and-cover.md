# Pi 接入、订阅技能编辑与文章封面

本批实现 API / 订阅两种接入，保持小卿人设和现有文章 Agent 提示词。API 地址、密钥和 API 文字模型独立保存，切换订阅后继续保留。明暗模式及现有新粗野主义外观继续有效。

## 订阅修改文章

1. 在 `/admin/settings/ai` 启用 AI，选择「订阅接入」。
2. 点击 ChatGPT 的「订阅登录」，在官方授权页面完成登录。授权回调使用本机可用端口，避免 Windows 禁用 1455 的问题；无法自动返回时，可粘贴最终回调地址。
3. 连接后选择账号实际可用的文字模型，保存配置，测试普通连接和工具调用。
4. 打开 `/edit/:id` 或文档详情，进入编辑模式，点击工具条的 AI 按钮。选择「通用笔记整理」或「结构化学习笔记」，说明修改要求。
5. AI 读取当前最新文章、按需读取完整技能及其参考资料，生成修改预览。确认并应用后才保存正文。

原有长文分段、选区编辑、Markdown 校验、自动保存、版本检查、冲突保留及修改历史继续有效。已配置本机技能挂载时，新任务重新读取原文件；不能访问时显示失败，不静默替换技能。现有 Agent 对密码保护文章的限制保持原样。

订阅只供站主在本地桌面、Android 运行环境及隔离预览使用。OAuth 访问/刷新令牌保存在本机独立文件，接口不返回令牌，不参与站点设置同步。ChatGPT 使用 PKCE、state、nonce、签名 ID 令牌及账号一致性检查；刷新由 Pi 调度，在串行文件锁内经应用订阅传输执行。断开清除令牌，保留已注册客户端的非令牌登记信息，重新授权复用登记；「连接其他 ChatGPT 账号」可发起新的登记。

Windows 本地 ChatGPT 连接自动读取已启用的系统 HTTP/HTTPS 代理；显式 HTTP_PROXY / HTTPS_PROXY 优先，NO_PROXY 与本地回调绕过代理。令牌交换、身份公钥、令牌刷新、模型目录和文字请求使用同一订阅传输，不改变 API 网关或其他模块的请求。代理变化最多 15 秒后生效。设置页按失败阶段显示不包含令牌的诊断；浏览器收到授权回调仅代表授权信息已返回，仍需令牌交换和身份校验完成。

ChatGPT 模型列表通过官方 `/v1/models` 读取当前账号可用目录。Claude、GitHub Copilot 使用 Pi 内置 OAuth 及模型目录；这些提供商的真实订阅账号尚未人工验收。平台额度与模型权限以账号实际返回为准。

## API 文章封面

文章编辑页在「导出 PDF」右侧新增「AI 生成封面」。操作先保存当前正文，按完整 Markdown 段落提炼文章主题，再使用保存的 API URL/密钥调用生图模型。图床配置在任何付费请求前检查。

生图模型独立设置，默认 `gpt-image-2`，可改为 API 服务实际支持的 GPT Image 型号。API 服务须支持 `/images/generations` 及 `data[0].b64_json` 响应；程序不会回源下载服务随意返回的 URL。生成图片转 WebP，保存到现有 GitHub 图床或 R2，然后设置为文章封面。

正文、标题、封面变化，或编辑会话/文章切换时，不自动覆盖。新封面保留为候选，在原文章中确认后应用；服务器同时检查签名候选及 SQL 条件更新。封面应用只写封面及更新时间，文章设置同步新封面状态。

ChatGPT 订阅用于文字，不用于生图。封面使用 API 单独计费。生成文本摘要会使用当前所选的文字接入方式。
