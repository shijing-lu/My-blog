## 二、架构基线（为什么长这样）

- **跨行替换装饰必须由 StateField 提供**：CM6 规定 ViewPlugin 装饰不能替换换行符，
  违反会抛错并进入 measure 死循环 → 编辑页白屏（本项目早期实测踩过）。勿回退。
- **装饰区间互斥**：行内 pass 用 occupied 区间表防正则互相重叠（如列表 marker 与斜体），
  任何漏网重叠令 RangeSetBuilder 抛错 → `safeBuild` 兜底为空集（降级纯源码显示，绝不白屏）。
- **表格是例外**：不做"光标进入回显源码"——单元格自身就是编辑面（contenteditable），
  输入 300ms 防抖回写源码，重建后经 `pendingTableFocus` 恢复焦点。
