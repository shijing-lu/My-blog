# 文档交互、分钟日程与编辑稳定性

## 需求与技术分析

1. 黑幕总开关保持全站偏好，每个点击展开状态按稳定文章 ID + 内容指纹 + 重复序号存入本设备；正文改写后恢复，悬停不存储，存储不可用降级内存。
2. 文档界面 Ctrl+Shift+F 搜索全站普通文章和文档，Ctrl+F 查找当前正文或编辑器未保存内容。现有普通文章 API 仅扫描最近 300 个正文；新范围需完整检索并分页。加密文章只返回公开元信息，不读取其正文。
3. 原生 time 输入精确到分钟，结束可选择当天 24:00。新建、编辑、拖拽、自然语言解析及持久化使用 1 分钟精度，最短 1 分钟；拒绝无效输入，不改变原有单日和重叠规则。
4. 左栏使用固定头部与独立滚动树，高度约束以可用视口为准；左栏所有滚轮动作只作用于目录，边界不传播，Ctrl+滚轮保留缩放。
5. 两种编辑入口追踪竞态、加载态、焦点及门户清理。文档 HTML 缓存分支早于请求取消，是确定的竞态风险；其余偶发根因须用运行证据确认，不以重建编辑器掩盖故障。

## 实施计划

先黑幕/目录/竞态，再搜索与快捷键，再分钟日程。全部保留自动保存、历史、撤销和用户正文语义。搜索 API 新增 scope=site 和分页，旧请求兼容；时间继续整数分钟，不新增表或迁移。
