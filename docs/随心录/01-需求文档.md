# 随心录需求文档

状态：需求草案（2026-09-27）  
范围：仅需求定义；技术实现建议见同目录《技术探讨》，执行顺序见《开发计划》。

## 1. 背景与目标

“随心录”是面向站主的轻量私密记录工具，核心是从任意页面快速打开、迅速写下当下想法，并能在之后按标签或时间找回。它与公开分享的“动态”不同，也与每天一篇、按日期覆盖的“日记”不同：每次保存都是一条独立记录。

## 2. 用户与权限

- 使用者：站主（沿用当前站点管理员/站主鉴权体系）。
- 内容默认私密，不出现在公开首页、动态、搜索引擎、RSS 或公开 API 中。
- 只有通过站点既有受保护会话且具备约定权限的用户可读写；未授权 API 请求应返回现有风格的 401/403。
- 页面应设置 `noindex`，并确保私密响应不进入共享 CDN 缓存。

## 3. 入口与导航

### 3.1 快速记录入口

- 在右侧悬浮工具栏中，紧接“AI 聊天”按钮下方增加“随心录”图标。
- 图标有中文可访问名称、悬停提示、键盘焦点状态，与现有工具栏视觉和交互一致。
- 点击后打开轻量悬浮编辑器；在小屏幕上应转为全屏或近全屏面板，避免窄窗内难以编辑。
- 已存在未保存内容、保存中的记录或网络失败时，关闭面板须有明确状态反馈，不能静默丢失输入。

### 3.2 浏览入口

- 在全站顶栏“归档”右侧增加“随心录”入口，进入私密记录列表。
- 未授权者不应看到可误导其认为可访问的私密列表入口；访问受保护路由时走现有登录/权限处理。
- 页面标题、描述和索引策略均应体现私密属性。

## 4. 创建与编辑

- 点击悬浮图标后可立即输入正文；标题可选，未填写时列表卡片使用正文首行/首个标题作为展示标题，空标题记录仍可保存。
- 正文以 Markdown 源码持久化。
- 编辑与预览必须能表达项目已有的 Markdown/MDX 扩展，不另创一套语法；包括项目当前使用的 GFM、数学公式、代码高亮、指令/Callout 及注册的 MDX 组件等。最终支持范围以实际渲染插件清单和编辑器能力盘点为准。
- 提供清晰的编辑/预览切换（桌面可并排，小屏可标签切换）；预览的最终结果必须来自项目正式渲染器。
- 标签可在保存时添加、移除、去重；建议首期上限沿用动态模块的 10 个标签、每个 20 字符，避免不同模块数据规则漂移。
- 保存成功后显示状态及更新时间。建议采用短防抖自动保存并保留明确的“立即保存”操作；关闭/换记录前等待在途保存完成。
- 支持从列表打开已有记录并继续编辑；编辑既有记录不可意外创建重复条目。
- 首期不要求上传媒体、协作、评论、公开/私密切换、全文搜索或离线冲突合并。

## 5. 列表、卡片与筛选

- 记录以卡片显示：标题或摘要、正文预览、标签、创建时间及有编辑时的更新时间。
- 默认按最近创建时间倒序；编辑记录不应改变创建顺序，可选提供按最近更新排序。
- 支持按标签筛选、清除筛选和时间范围筛选（至少年月/某日；时间线按年/月分组）。
- 标签筛选与时间筛选可组合；空结果需有清楚的空状态及清筛选操作。
- 列表使用分页或按需加载，避免一次载入所有历史记录；浏览过程保留当前筛选状态。

## 6. 关键质量要求

- 私密性优先：路由、API、中间件权限、缓存头、服务端 HTML 均不可泄漏内容。
- 保存可靠：有加载/成功/失败反馈；支持重试；未完成保存时保护编辑内容。
- 与站点主题、深浅色、桌面 Electron 与 View Transitions 行为一致。
- 桌面与移动端可用；图标有键盘操作和屏幕阅读器名称。
- 长记录预览和大量历史记录不应阻塞页面交互。

## 7. 首期验收标准

1. 管理员从任意页面的右侧工具栏打开悬浮框，创建记录并添加标签，保存后列表可见。
2. 页面刷新/重新登录后内容仍在；再次编辑保存时原记录被更新。
3. 正文预览正确处理经盘点确认的项目扩展语法，且与正式内容渲染一致；未知/不支持语法有可见退化而非静默破坏源码。
4. 访客、未登录用户和无权限账号无法读取列表、正文或通过 API 写入；页面与 API 的缓存策略不会共享私密内容。
5. “随心录”列表能按标签和时间筛选，支持组合筛选、清除筛选、空状态和历史分页。
6. 顶栏入口在“归档”右侧，工具栏图标在“AI 聊天”下方，且窄屏布局可正常操作。
7. SQLite 开发环境、PostgreSQL 部署环境与桌面数据同步的表结构保持一致。

## 8. 待确认事项

- 标签/时间筛选、卡片呈现及私密站主笔记等均按上述建议作为首期默认方案；如你希望“随心录”对登录访客开放、按账号隔离，或支持公开分享，需要在开发前调整权限与数据模型。
- 首期自动保存建议采用约 700–1000ms 防抖；悬浮窗提供显式保存状态与手动保存按钮。具体时延可在实现中依现有保存队列约定决定。
