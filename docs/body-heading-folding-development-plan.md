# 正文标题折叠开发计划

日期：2026-10-04。顺序：需求整理 → 技术分析和计划 → 开发 → 验证。

## 已完成的准备

用户确认阅读和编辑均支持；需求见 `body-heading-folding-requirements.md`，技术选择见 `body-heading-folding-technical-analysis.md`。已检查共享正文壳、公开阅读页面、异步渲染路径、CodeMirror 初始化和现有自动保存逻辑。

## 实施步骤

1. 编写共享阅读增强模块和样式，接入文档及文章正文，支持 H1–H6 嵌套范围、状态恢复、键盘和打印。
2. 接入异步正文加载、保存后的刷新及目录和锚点展开，保持已有目录折叠及路由历史。
3. 编写基于语法树的编辑章节索引和 CodeMirror 折叠扩展，启用文档与文章编辑，接入编辑定位。
4. 编写针对边界、嵌套、Setext、代码和完整源文的单元验证。
5. 浏览器检查真实页面的阅读、编辑、正文刷新、键盘、移动端、打印和自动保存；检查复杂长文装饰兼容。
6. 运行相关回归、类型检查和构建，补充验证记录并交付。

## 完成条件

需求文档的验收项有自动化或浏览器证据；相关检查通过；源文和数据库结构无折叠相关改写。若客户端安装更新或正式环境发布尚未执行，交付时明确说明，不能将本地测试描述成生产已生效。
