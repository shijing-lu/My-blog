# 第4阶段：文章阅读实施与契约

用户已批准第4阶段。仅实施首页与文章阅读，交付后停止等待真机验收。

1. 核对当前 `renderMdx`、组件注册表、分类、落地页、诗词及密码保护；维护矩阵。
2. 新增站主 Bearer 阅读接口，列表不含正文或密码元数据；受保护正文单独验证密码。返回原文与版本，不下发可执行网页。
3. 原生本地 Kotlin 解析层保留节点ID、源码范围、目录、资源及未适配节点；Compose 渲染基础 Markdown 和扩展组件。数学通过独立 Android Canvas 排版模块，不使用 WebView。
4. Room 阅读缓存按站点隔离、Keystore 加密，列表5分钟、正文/展示1小时；过期先展示本地再刷新、失败保留缓存、空结果也缓存。阅读位置持久保存，普通浏览不触发随心录全量同步。
5. 首页文章入口、分类标签与月份筛选、联网标题/正文搜索、离线已缓存正文搜索、详情、密码解锁、右侧目录、图片预览和本地 Markdown 导出。
6. 验证解析及语义、缓存零请求/失败降级、受保护接口、数据库升级、中文长文与局部滚动、真机返回和离线阅读；记录全部未适配内容，不能按源码回退判定通过。

基础语法采用 [commonmark-java](https://github.com/commonmark/commonmark-java) 0.24.0，项目扩展由 Kotlin 解析器实现。公式采用 [JLatexMath Android](https://github.com/noties/jlatexmath-android) 0.2.0 Canvas 排版；随包保留其 GPL-2.0 许可，最终对外分发前落实对应源码交付。当前仅私人调试包。

第5阶段编辑器、第6阶段文档、第14阶段评论管理按总计划保留。不得将这些未交付能力标记完成。

## 阅读接口

统一入口`/api/mobile/v1/reading/[action]`，站主Bearer校验及`private, no-store`。不新增服务端表；复用现有文章、分类、展示、阅读量和点赞数据。

| 动作 | 方法 | 输入/输出与边界 |
|---|---|---|
| catalog | GET | 文章元数据、分类和统计；不含正文和密码哈希 |
| display | GET | 落地页与诗词；独立于5分钟列表缓存 |
| search | GET | q最多200字符；联网搜索未加密文章标题/摘要/标签/正文，只返回元数据 |
| detail | POST | serverId/id/password；服务身份匹配，正文密码沿用现有PBKDF2验证；密码错误或缺失423；返回原文与SHA256版本 |
| view | POST | serverId/id；明确阅读事件递增现有阅读统计，离线不重放 |
| like | POST | serverId/id/liked；保存期望状态，重复请求不重复点赞，返回统计 |

客户端不因站主身份绕过文章密码。密码仅用于当前请求，不缓存密码、不记录敏感正文。解锁后的正文按绑定站点加密缓存，离线可读。远端搜索排除所有受保护正文；本地仅搜索已取得的缓存资料。

## 原生正文与文件

基础CommonMark/GFM由本地解析器形成节点；原文不被渲染改写。已实现指令形式的提示块/Callout、折叠面板、手风琴、同组Tabs联动、Grid、Columns、剧透、五种Mark高亮、公式、两类脚注引用、代码复制折叠和图片说明。右侧目录跳转自动关闭；宽公式、表格与代码只在自身区域横向滚动。未知HTML/JSX、未知指令或公式错误显式登记未适配及源码范围，保持原文；不能判为迁移完成。

阅读位置、Tabs/折叠/剧透状态持久保存。Markdown通过SAF保存，分享通过限于导出缓存目录的FileProvider授权；保留frontmatter、正文，补全相对资源URL。图片通过受控OkHttp下载、10MiB上限、逐跳校验和Keystore加密文件缓存；Coil仅解码字节，关闭明文磁盘缓存。图片全屏预览支持滑动、双指缩放、平移和保存原始字节。

两端使用同一份`scripts/native-reading-fixture.md`语义样本，分别执行真实`renderMdx`和Kotlin解析/真机Canvas排版。验收范围及未完成项见`11-阶段4验收.md`，不以样本通过替代私人历史资料验收。
