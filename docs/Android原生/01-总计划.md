## 完整性

以当前源码、路由、组件、接口和实际使用数据为准，矩阵逐项关联阶段、字段、离线行为和用例。每阶段开工前重新扫描 Web 变动。数据库中的历史表不能单独证明功能有可用入口。没有明确适配的原生功能保持“未完成”，不能用空页面或源码回退宣称迁移完成。

正文覆盖基础 Markdown、数学公式、脚注、高亮、提示块、Callout、Collapse、联动 Tabs、Grid、Columns、Spoiler、代码复制折叠、图片说明灯箱、标题锚点搜索。编辑器覆盖源码、可视、预览、撤销、自动保存、查找替换、折叠、表格公式图片、扩展组件菜单和外接键盘。

Cadence 以当前实现为准：最小与吸附粒度为 1 分钟，当天 0–1440 分钟，结束晚于开始，相邻不视作重叠，保留既有任务完成联动；不照抄旧 15 分钟计划。

## 迁移边界

新目录 `android-native/`，包名 `com.byqx.blog.nativeapp`，旧包 `com.byqx.blog` 共存。旧数据用明确导出导入迁移，不直接访问另一应用私有目录。App 无 WebView、Node 服务和 Hybrid 运行时。

首次站主口令绑定，系统浏览器只承担外链；无需 GitHub 登录客户端。网站账号审批、授权和评论管理完整保留。任意 CSS 仍可在 App 管理并应用于 Web，App 使用原生 Token，不执行网页脚本。

当前工作区原有未提交文件保留，旧安卓工程和既有Web业务改动不覆盖。第2阶段只新增移动认证与双方言会话表、主库权威访问及移动路径守卫；既有Cookie认证不变。

## 交付与最终完成

阶段 1–3 提供可编译 ViewModel、持久配置、Repository/Room/Retrofit 等对应骨架；本阶段没有伪造未来数据层空实现。最终需功能矩阵全部通过、真实数据与跨端同步通过、关键问题关闭以及用户真机通过。阶段 16 先交签名 APK，商店发布另行确认。
