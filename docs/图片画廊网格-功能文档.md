# 图片画廊网格 `:::grid` — 功能文档

> **状态**：待确认（确认后进入实现）
> **作用范围**：文章正文与文档正文中的 **Markdown 扩展语法**
> **明确排除**：导航栏「影集」功能（两者独立，不复用数据与页面）

---

## 一、功能目标

给正文新增一个容器指令 `:::grid`，把容器内的普通 Markdown 图片按**统一宽高比**排成**响应式网格**，并为其启用**独立分组的灯箱大图浏览**。

适用场景：正文配图组、界面截图索引、作品集缩略图、小型相册。

**一句话边界**：容器**只负责排版一组图片**；容器外的普通 Markdown 图片行为完全不变。

---

## 二、语法定义

### 2.1 最简语法

```markdown
:::grid

![图片描述](/img/example-1.webp)

![图片描述](/img/example-2.webp)

:::
```

**书写约束**：

| 约束 | 说明 |
|---|---|
| 每张图片单独占一个段落 | 图片之间必须有**空行**，否则会被 Markdown 解析成同一段落的行内图片 |
| 容器内只放图片 | 段落文字、列表、代码块写在容器外；出现非图片内容时按「降级策略」处理 |
| 闭合标记为 `:::` | 与项目现有 `:::tabs` / `:::collapse` 同一套约定 |

### 2.2 带参数

参数写在起始指令后的大括号内：

```markdown
:::grid{columns="3" aspect="16/9" fit="cover"}

![第一张](/img/a.webp "可选图注")

![第二张](/img/b.webp "可选图注")

:::
```

### 2.3 参数一览

| 参数 | 允许值 | 默认值 | 用途 | 非法值处理 |
|---|---|---|---|---|
| `columns` | `1` ~ `6` 的整数 | `3` | 桌面端每行列数 | 回退为 `3` |
| `aspect` | 正数比例：`16/9`、`3/4`、`1/1`、`16/10` | `16/10` | 卡片宽高比（**非原图比例**） | 回退为 `16/10` |
| `fit` | `cover` \| `contain` | `cover` | `cover` 居中裁切填满；`contain` 完整保留原图并留白 | 回退为 `cover` |

## 三、图注规则

| 情形 | 图注内容 |
|---|---|
| 图片写了 `title`（`![alt](url "标题")`） | **标题**作为图注 |
| 只有 `alt` | **替代文本**作为图注（同时保留无障碍语义） |
| 两者都没有 | 无图注，卡片高度仍与同行一致 |

**对齐规则**：同一行内所有图注**底部对齐**。图注换行（长文本）不会导致同行其他卡片高度错落。

> ⚠️ **与既有规范的冲突点（需你确认）**：项目现有的正文图片规范是「不显示 figcaption」——`.prose .lightbox-figure figcaption { display: none }`。本功能需要在**网格容器内**打开这个例外（容器外的正文图片仍然不显示图注）。

---

## 四、布局与视觉规范

### 4.1 卡片

- 卡片外框固定 `aspect` 比例，圆角裁切；图片填满卡片，**不带**正文图片的默认外边距
- 卡片间距、圆角取值**沿用站点现有卡片样式**（不新造一套视觉语言）
- 网格内不使用边框/阴影装饰（与项目图片规范一致）

### 4.2 网格轨道

- 桌面端**严格**按 `columns` 排列
- 末行图片数量不足时**保持轨道宽度、左对齐**，不拉伸变形
- 单列（`columns="1"`）在桌面/平板/移动端均保持单列

### 4.3 响应式断点

| 视口宽度 | 列数 |
|---|---|
| ≥ 768px | 按 `columns` |
| < 768px | 最多 2 列 |
| < 480px | 1 列 |

### 4.4 `cover` 与 `contain` 的取舍

| 模式 | 表现 | 代价 |
|---|---|---|
| `cover`（默认） | 网格整齐划一，卡片比例统一 | 裁掉边缘内容 |
| `contain` | 完整呈现原图，绝不裁切 | 与原图比例差异大时露出主题背景色 |

> 供参考：边缘含关键信息（文字、UI 细节）的图片，建议 `contain` 或用清晰图注说明「点击可看完整图」。

## 五、降级与鲁棒性（项目铁律）

| 异常 | 处理 |
|---|---|
| 参数值非法/拼错 | 该参数回退默认值，**不报错**、不中断渲染 |
| 容器未闭合 | 整体降级为普通 Markdown 内容，不产生残留标记 |
| 容器内混入非图片内容 | 非图片部分按普通 Markdown 渲染（或忽略），**不影响同容器内图片成网格** |
| 图片加载失败 | 保留卡片占位与图注，不撑破布局 |
| 容器内只有 1 张图 | 按 1 列渲染，行为与其他网格一致 |
| 解析整体失败 | 绝不导致整篇渲染 500（沿用现有 MDX 容器容错策略） |

## 六、灯箱（动态浏览）

| 项目 | 规格 |
|---|---|
| 触发 | 点击网格内任意图片 |
| 导航范围 | **严格限制在当前 `:::grid` 容器内**（各容器独立分组） |
| 与其他图片的关系 | 容器外的普通 Markdown 图片**不会**进入任何画廊分组 |
| 查看内容 | **未裁切的完整原图**（即 `cover` 裁掉的边缘在灯箱里可见） |
| 键盘 | `←` / `→` 切换，`Esc` 关闭 |
| 触屏 | 左右滑动切换 |
| 遮罩 | 点击遮罩关闭；打开时锁定页面滚动 |

> 灯箱的**能力深度**（是否支持缩放、旋转、全屏、缩略图条）取决于实现方式选择，见第九节「待确认决策」。

## 七、兼容范围

| 场景 | 是否生效 |
|---|---|
| 首页文章正文（`/blog/[slug]`） | ✅ |
| 文档文章正文（`/doc/...`） | ✅（窄栏下按响应式规则自动降列） |
| 写作台实时预览 | ✅（与正文使用同一渲染管线） |
| 影集页（`/gallery`） | ❌ 不受影响，不使用本语法 |
| 列表页摘要/搜索结果 | ❌ 不参与（只渲染正文） |

## 八、实现要点（供你判断工作量）

| 环节 | 做法 | 备注 |
|---|---|---|
| 语法注册 | 沿用 `:::` 容器机制（与 `tabs` / `collapse` 同族） | `{键="值"}` 属性形式，无需额外改写 |
| 网格渲染 | CSS Grid + `aspect-ratio` + `object-fit`，列数与比例通过 CSS 变量注入 | 纯 CSS，无新依赖 |
| 图注 | 复用现有图片包裹结构中的图注数据 | 需要为网格内 figure 打开 `figcaption` 例外 |
| 灯箱分组 | 扩展现有 `src/scripts/lightbox.ts`（无依赖，已有 ESC/箭头/遮罩） | 现状是「全文档一个组」，需增加分组与计数 |
| 悬停微缩放 | CSS `transform` + `transition` | 纯 CSS |

**必须注意的既有约束**：网格内图片需要覆盖正文的 `.prose img { height: auto }` 规则，否则 `aspect-ratio` + `cover` 裁切不生效。
