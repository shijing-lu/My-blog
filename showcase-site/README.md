# 白衣卿相 · 项目宣传网站

一份独立的 My-Blog 宣传网站源码，主题是“把思考，变成自己的世界”。采用暖白、墨黑、陶土橙、文楷大标题与现有像素标记，展示博客的阅读、写作、摄影和站主工作台。

## 页面内容

- 品牌首屏：云海影像、项目主张与宣传片入口。
- 项目理念：以文章、知识和生活记录介绍个人博客。
- 阅读能力导览：阅读、数学公式和归档三个可切换面板。
- 写作：Markdown、公式、代码、多栏排版与写作片段。
- 摄影与生活：错落的影像构图，介绍影集与时间线。
- 站主工作台：可展开的计划、专注、复盘和随心录介绍。
- 宣传片：完整 56 秒视频，以及六个可直接播放的章节。
- 品牌收束与页面导航。

## 运行与修改

```powershell
node scripts/preview.mjs
```

访问 <http://127.0.0.1:4319/>。本地服务器支持视频范围请求，便于跳转章节。若电脑安装了 RTK，可在命令前使用 RTK。

| 修改内容 | 文件 |
| --- | --- |
| 页面内容与章节 | `dist/index.html` |
| 视觉、响应式和入场动效 | `dist/styles.css` |
| 视频、能力切换与折叠交互 | `dist/site.js` |
| 图片、字体、视频 | `dist/assets/` |
| 站点身份 | `.openai/hosting.json` |
| 开发计划 | `DEVELOPMENT_PLAN.md` |

网站是静态 HTML、CSS、JavaScript，无安装步骤或数据库。已有图片与视频均在网站目录内。更新素材可在 My-Blog 中运行 `node showcase-site/scripts/prepare-assets.mjs`；该准备脚本复用博客已有的 Sharp 依赖。网页播放版视频保存在 `dist/assets/promo.mp4`，约 9.8 MB，1080p、56 秒，并已优化播放加载顺序。

## 交互与可访问性

- 视频使用浏览器播放器和原生模态对话框；关闭时停止播放，恢复页面滚动与触发按钮焦点。
- 视频章节按钮从对应片段开始播放，完整播放入口从片头开始。
- 阅读导览支持方向键、Home、End 与键盘焦点。
- 工作台使用原生 `details`，不依赖 JavaScript 也能展开。
- 支持跳过导航、焦点样式和减少动态效果偏好。
- 手机布局在 767px 以下切换；没有把桌面左右布局直接缩成手机大小。

## 内容与素材边界

写作、日程与随心录按站主功能介绍。本网站不接入博客账号、私密记录或管理接口。

三张风景图沿用宣传片的生成素材。写作与日程画面是已完成宣传片的抽帧，并注明演示性质。视频界面为视觉重构，非真实网站录屏。配乐由宣传片工程原创合成。字体许可证在 `licenses/`，部署资源中也附有对应许可证。

网站没有添加未经确认的正式博客网址、开源下载入口、用户量或客户评价。当前发布为本人可访问的网站；正式博客域名确认后，可以加入真实的访问入口。

## 已完成的检查

页面与本地视频资源响应正常，脚本语法检查通过；预览中阅读能力切换成功，视频能从 32 秒处播放，识别到完整时长 56 秒。在 1280px 桌面和 390px 手机布局下进行了查看；390px 时页面没有横向溢出。没有运行博客的数据库迁移、桌面构建或测试套件。
