# 白衣卿相项目宣传网站 · 开发计划

## 目标与范围

用户确认制作独立的项目宣传网站，介绍 My-Blog 功能、展示宣传片与项目特色。源码放在 `showcase-site/`。访客可以了解项目、探索功能章节，并播放 56 秒宣传片。

## 视觉方向

以“自己的世界”为主题，把博客的阅读气质与宣传片的影像尺度结合起来。延续暖白、墨黑、陶土橙与文楷字体；大标题、错落影像、留白与章节编号建立编辑感。使用现有像素“白”标记。

布局变化 7 / 动效 5 / 内容密度 3。一个页面主题，章节表面保持一致；用影像与版式制造对比。按钮使用胶囊形，影像保持直角，功能展示使用小圆角。

## 内容与功能

1. 品牌首屏：主张、云海影像、宣传片播放入口。
2. 项目理念：文章、知识、影像、时间的整体关系。
3. 阅读与知识：文章、学习笔记、公式、目录、搜索与归档。
4. 创作：Markdown、公式、代码、多栏排版的宣传片演示画面。
5. 摄影与生活：影像叙事、影集和时间线。
6. 站主工作台：计划、任务、专注、复盘、随心录；明确权限边界。
7. 宣传片章节：播放器、视频规格与演示素材说明。
8. 收束：品牌与页面导航。

交互包括锚点导航、移动导航、功能切换、视频弹窗与章节跳转。支持键盘、减少动态效果偏好与移动屏幕。

## 实现方式

使用独立静态 HTML、CSS 和 JavaScript，图片、字体和视频自托管，无数据库或账号接入。使用 Sites 发布为仅本人可访问的预览网站，保留源码与修改说明。

素材复用 `promo-film/public/assets` 与刚完成的成片；图片进行网页格式优化，视频提供适合网页加载的版本。界面宣传画面使用已完成影片的抽帧，注明演示性质。

## 开发顺序

1. 完成品牌首屏与代表内容，启动并展示首次预览。
2. 加入完整章节、播放器与移动布局。
3. 完成有明确用途的入场、滚动和悬停动效。
4. 检查文案、资源、脚本语法与关键页面状态。
5. 发布可访问的网站，交付链接、源码和操作说明。

不添加未经确认的正式博客域名、开源地址、客户评价或使用量。日程和随心录按站主专属能力介绍。
